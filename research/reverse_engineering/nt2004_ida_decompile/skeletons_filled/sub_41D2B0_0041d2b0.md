## sub_41D2B0_0041d2b0 — ConfigIniLoad

**Summary:** Loads and parses the game's `Config.ini` file. Detects Windows version (2000/NT/XP) to set up user-specific application data directories. Reads configuration sections `[COMPONENTS]`, `[INSTALL]`, `[AUTOLAUNCH]`, and `[VERSION]` to populate all game paths (sound, vehicles, tracks, saves, replays, etc.) and video/audio settings. Called once during game startup.

**Guard conditions:**

The function first checks the OS version via `sub_41E8F0`. If the system is Windows 2000, NT, or XP (line 66) AND the user is not an admin (`!sub_41EA80`, line 67), the flag `v37` is set to 1, triggering user-specific app-data directory creation under `CSIDL_APPDATA` (SHGetSpecialFolderPathA with CSIDL 5 = APPDATA). The file open at line 116 is the primary guard: if `fopen` fails, `sub_41E340` attempts to create the config file and parent directories; if that fails too, the function logs an error and returns 0. The main parsing loop (line 136) reads lines from the config file looking for section headers `[COMPONENTS]`, `[INSTALL]`, `[AUTOLAUNCH]`, and `[VERSION]`. Within each section, keys are matched by name — only recognized keys are processed; unknown keys are silently skipped. Numeric values are clamped or validated (e.g., GridSize at `this+0xE4` is clamped to [0, 48] at lines 372-380). When `v37` is set (Win2K/NT/XP non-admin), replay/log/save directories are created under the user's app data folder with `_mkdir` and default files are copied via `sub_41D0F0`.
