**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |

**Guard interpretation:** When `this+0x5DD8 != 3` AND (control mode == 2 OR speed < 0.001 OR visible opponents < 4), the AI transitions to state 4 (resetting). In state 4, the function resets the AI car to the racing line, computes corrected speed, disables driving assists, and transitions back to state 3 (active). If NOT in state 4 but control mode == 1 AND needs-reset flag is set AND car is 2+ laps behind, triggers a stuck-reset via sub_4271B0.
