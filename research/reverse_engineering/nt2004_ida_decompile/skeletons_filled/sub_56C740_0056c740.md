**Guard interpretation:** The receive loop operates under several guards: `select()` result determines if data is available (`v72` flag). For UDP mode (`a3` true), data received via `recvfrom` is dispatched immediately. For TCP mode, received data is appended to a per-connection 2048-byte circular buffer; when buffered data >= 4 bytes and >= the expected message size (encoded in first 2 bytes), the complete message is extracted and dispatched. Winsock errors are mapped to human-readable disconnect reasons and reported via `sub_56E010`. The outer loop runs `v83` iterations (at least 1) to allow re-polling.
