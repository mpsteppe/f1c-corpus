**Guard interpretation:** When match length (0x56) < 3, no useful match exists, so emit as a literal byte (increment frequency tables for literal encoding). When compression mode (0x7E) != 2 (i.e., not in "no compression / stored block" mode), proceed with the LZ77 match search via ZlibDeflateLongestMatch. The mode = 2 guard blocks match searching entirely for stored blocks.
