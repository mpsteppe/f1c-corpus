**Guard interpretation:** 
- `a2 == -2`: Player-relative mode — uses off_5FD348 (player data) as target. Requires sub_4BBF20(&unk_766220) to return true. Special distance handling and speed modification via sub_427B50.
- `a2 >= 0`: AI-vs-AI mode — reads target car from unk_62BF68 + 25304*a2. Computes speed based on distance and relative position.
- `dword_75CBB4 == 3`: Adjusts scaling factor — if player is ahead (sub_42DBA0 returns true and ranking comparison confirms), v41 changes from 10.0 to 2.0, making AI cars more aggressive/gap-sensitive.
- `a3 >= 0`: Comparison against another car — computes speed for car a3, returns the minimum of own speed and a3's speed (conservative/safe speed).
- Recursive: If adjacent car exists and is active (sub_4EED40 true) and dword_75CBAC != 2, recursively computes its speed and returns the minimum.
