**Guard interpretation:** 
- v49 == 16 (high-color mode) → format IDs converted to packed values (909200416, 909200449, 909201952, 909201985), any other format returns error
- v49 < 8 (low bit depth) → additional driver state flags set
- v47 == 0 and v49 < 8 → extra config applied
- this[0] != 41 (not RGB32) and bit 16 set → sub_54F468 called and state transitions applied (20→21, 50→51, packed→+33)
- this[0] is 20 or 909201952 or 21 or 909201985 → special bit flag set
- this[0] == 20 → state flag set and mode changed to 22
- Gamma values (Buf+76/Buf+77 float) <= 0.000001 → identity gamma LUT; else pow() curve
