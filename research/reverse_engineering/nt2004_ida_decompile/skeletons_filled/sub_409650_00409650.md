## sub_409650_00409650 — Cockpit Camera Sway Controller

**Summary:** Computes cockpit camera sway angles (pitch, yaw, roll) from input device readings, applying non-linear response curves (pow with configurable exponent) and per-axis smoothing. Handles cockpit/nosecam/TVCockpit view modes and race-session damping.

**Called by:** sub_40B4A0 (0040b4a0)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x10 | R | — | Camera view mode index (0=cockpit, 1=nosecam, 2=TVCockpit) |
| this | 0x38 | RW | — | Camera sway angle X (yaw) output |
| this | 0x3C | RW | — | Camera sway angle Y (pitch) output |
| this | 0x40 | RW | — | Camera sway angle Z (roll) output |

**Written-by note (persistence):**
- this 0x38: recalculated per frame with smoothing; external poke would be overwritten next frame
- this 0x3C: recalculated per frame with smoothing; external poke would be overwritten next frame
- this 0x40: recalculated per frame with smoothing; external poke would be overwritten next frame
