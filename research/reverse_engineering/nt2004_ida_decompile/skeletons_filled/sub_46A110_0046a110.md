## sub_46A110_0046a110 — AdvanceToNextLevelAndLoad

**Guard interpretation:** If this+0x8 (cursor) is null or cursor's dereferenced value is null, reset cursor to head (this+0x0). If head is also null, return 0. Otherwise proceed with the current node. After processing, advance cursor: if next node exists, use it; if null, reset to head. The dword_75CBA8 == 5 path is short-circuited early; otherwise a range iteration from unk_62BFBC to byte_75483C marks all entries invalid before rebuild.
