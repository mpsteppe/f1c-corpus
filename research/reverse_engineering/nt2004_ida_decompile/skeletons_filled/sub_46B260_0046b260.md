## sub_46B260_0046b260 — ApplySessionConfigFromDialog

**Summary:** Reads all multiplayer/session configuration from a setup dialog (track selection, difficulty, sliders, server name) and applies them to the game state. Clears and rebuilds the track list, clamps user input to valid ranges, and stores settings globally.
