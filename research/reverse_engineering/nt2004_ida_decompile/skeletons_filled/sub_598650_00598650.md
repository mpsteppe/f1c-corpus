**Guard conditions:** Entry guard requires both bit 1 and bit 2 of `*(this+0x9C)` to be set — returns 0 immediately if either is clear. Within the loop, entities with `entity+96 == 0x8000000` take a special early path via sub_5A9070. Entities with `entity+0 == 0` (null name) skip to flag processing. The `entity+64 & 0x100` flag prevents re-creation of already-processed texture blocks. The `dword_7E8D38 && (entity+64 & 0xC)` check enables additional texture type flags.
