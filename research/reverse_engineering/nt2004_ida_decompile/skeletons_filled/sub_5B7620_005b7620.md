**Guard conditions:** 
- GetSystemInfo returns processor type 486 or 586 → use CPUID detection path
- CPUID vendor string check fails → "Non-compatible CPU" error, skip benchmark
- CPUID succeeds → run benchmark loop (set high priority, read RDTSC, wait 0.25s, read RDTSC again)
- Vendor = GenuineIntel: family 5=Pentium, family 6=Pentium Pro/II/III/Celeron, family 15=Pentium 4
- Vendor = AuthenticAMD: family 5=K5/K6, family 6=Athlon/Duron, family 15=Opteron
- Vendor = CyrixInstead: family 5=MediaGX, family 6=6x86/6x86MX
- Measured MHz >= 1500 → CPU tier = 4 (highest)
