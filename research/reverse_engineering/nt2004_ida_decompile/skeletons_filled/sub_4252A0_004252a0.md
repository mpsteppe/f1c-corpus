**Guard interpretation:** The spotter system uses slot indices -1 as sentinel for "no car in this position." The 0x5E0C/0x5E10/0x5EE0 fields use the max unsigned value (0xFFFFFFFF) as sentinel. Race session type (0x5DD8) gates logic: 7 = green-flag racing (full spotter), 5 = caution (limited). The three-wide flag (0x5EB4) triggers special proximity handling.
