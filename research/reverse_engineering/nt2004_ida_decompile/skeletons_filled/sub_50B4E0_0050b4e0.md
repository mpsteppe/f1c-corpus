**Guard interpretation:** View mode derived: if `*(*this + 25296) & 2`, mode = `a2` parameter, else mode = 3. If mode unchanged AND `a3` flag not set, entire function skipped (early return). Mode switch: case 0 (drivable) — disables most HUD overlays and replay widgets, enables mirrors only for non-onboard cameras. Case 1 (TV replay) — enables replay DVR widgets based on `dword_768108` and `dword_7682B8` levels. Case 2 (full replay) — enables all replay widgets unconditionally. Case 3 (minimal) — minimal UI with only essential widgets. Camera name check: if current camera is "Drivable", "Onboard", or "Swingman", mirrors are enabled for player car.
