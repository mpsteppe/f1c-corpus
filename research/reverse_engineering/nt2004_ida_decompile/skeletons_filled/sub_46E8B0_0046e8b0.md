**Written-by note (persistence):**
- this 0x134: Recalc every frame — heading angle updated from stick input; external poke overwritten immediately
- this 0x144-0x150: Recalc every frame — camera position recalculated; external poke overwritten immediately
- this 0x158-0x160: Conditional write — updated when camera mode changes or heading changes; external poke overwritten
- this 0x168: Written once when camera stuck detected; external poke survives until unstuck

**Guard conditions:** Early return if `byte at +0x11C` is zero (camera not active). If `*(this+0x1A4) == 0` (no speed), skip orientation update.
