**Guard interpretation:** Outer guard: `dword_75CBB0` selects session type (≤6 = practice/qualifying, 7 = race). Within race (state 7), inner switch on `dword_75CBB4` (sub-state 0-5) drives phases: 0=pre-race wait, 1=countdown start check, 2=formation/countdown active, 3=racing, 4=race-over display, 5=results. When `*(this+0xE0)` equals 2 (race finished), state transitions are blocked — only telemetry updates run.
