## sub_4D0D50_004d0d50 — RaceEventMessageHandler

**Summary:** Network message dispatcher for race events. Decodes a packet header (top nibble for category: 1=player event, 2=race control, 3=sound, 4=race state, 6=setup) and dispatches to specific handlers based on message subtype (low 6 bits of byte 2). Handles green flag, pace car, track order, and player position updates.

**Guard interpretation:** Primary dispatch: top 4 bits of `*this` select category (1,2,3,4,6). Within each category, `this[2] & 0x3F` selects message subtype. Individual messages have additional guards: car index bounds checks (index < 48/49), car status flags (`dword_630030[index] == 2`, `dword_632238[index] & 2`), race state checks (`dword_75CBAC & 1 == 0` for non-caution messages), and game state checks (`dword_75CBB4` for qualifying/race states). Message 0x27: `this[8] == 1` must PASS to trigger green flag (BLOCKED otherwise).
