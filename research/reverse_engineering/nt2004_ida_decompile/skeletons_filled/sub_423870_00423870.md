| Base | Offset | Test | Value | Field / meaning |

**Guard interpretation:** Camera update proceeds through multiple guarded paths. `*(this+0x50)+0x40C8 != 1` PASSES the initial track-check path. `*(this+0x5B88)+0x148 == 1` determines whether the tracked object is a type-1 object (likely player car) — this affects view switching and LOD logic. `this+0x516C == 10` is a replay-mode check — if replay, uses different speed multiplier. `this+0x5EB4 == 1` triggers auto-advance of camera target pointer. Distance thresholds (10.0, 35.0, 45.0, 60.0, 70.0) determine LOD level (0-5) via cascaded if-else chain on `this+0x23764` (camera distance).
