## sub_453D00_00453d00 — Force Feedback / Controller Rumble Computation

**Summary:** Computes force feedback (controller rumble / steering wheel FFB) effects for 10 effect slots based on vehicle physics state: speed, lateral/longitudinal forces, suspension travel, and race events (collision, off-track). Applies per-effect smoothing, clamping, and deadzone processing, dispatching final values via DirectInput-style SetEffect/StartEffect calls.

**Written-by note (persistence):**
- this 0x418: set based on system enable flag; external poke may survive
- this 0x41C: set based on effect enable/disable; external poke may survive briefly
- this 0x420: set based on strength override; external poke may survive
- this 0x428: incremented per active effect; recalculated per frame
- this 0x48C-0x49C: recalculated per frame per effect slot; external poke overwritten
- this 0x4A8-0x4B4: recalculated per frame; external poke overwritten
- this 0x4BC: set once to 1000000; persists unless re-init
- this 0x4D0-0x4E0: cleared after effect dispatch; external poke may survive briefly
- this 0x4E4: recalculated per frame; external poke overwritten
- this 0x560-0x574: accumulated per frame then zeroed; external poke overwritten next frame
