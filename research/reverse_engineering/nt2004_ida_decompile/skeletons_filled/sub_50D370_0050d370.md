## sub_50D370_0050d370 — Car model texture loader and path resolver

**Summary:** Loads car model textures for rendering: resolves file paths for car body (wccarbody), driver (wccardriver), driver helmet (wcdriverhelm), driver arms (wcDriverArm), and rims (wcrims) textures. Constructs BMP/TGA file paths using base directories, appends car number suffix (_%02d), and loads textures via sub_505E80.

**Called by:** sub_4B9460 (004b9460), sub_509B10 (00509b10)
