## sub_553C30_00553c30 — Steward::Restart

**Summary:** Race-steward (race-session controller) restart/initialization. **Guard conditions:** Session-time source selection: if byte_B722E4 (time-accelerated session) then session time = time-scale days × 86400 and duration limit forced to 0x7FFFFFFF. Otherwise, if dword_BE1204 == 2 the start clock comes from sub_521040(&dword_BE120C); if (session type 0 or 6) and *dword_B72314 != 4 and not time-accelerated, start clock = dword_B6FF58 × 3600; if byte_B6FF7C the start clock is taken from local system time. `StartMode` config is compared case-insensitively: `StandingStart` → dword_B64138 = 0 (PASS), `FormationRollingStart` → dword_B64138 = 1; other strings leave the previous value. Duration is only accepted when config value parses successfully (sscanf `%f`/`%d:%d:%f` with >=1/>=2 fields) or a record database value is present; otherwise the existing/default value remains. Night duration clamp: when byte_B73588 == 1, the scaled duration is forced to at least 600.0 for session types 3/4.
