## sub_41C040_0041c040 — Config::LoadOrCreate

**Summary:** Global config loader (`config.cpp`). Creates the game's config directory/`Config.ini` under the user's application-data folder when running from a special path, then parses `Config.ini` sections `[COMPONENTS]`, `[INSTALL]`, `[AUTOLAUNCH]`, `[VERSION]`, populating directories, video/audio/CPU settings and autolaunch fields on the config object.

**Guard conditions:** The config-copy block runs only when the resolved path equals one of the special-location tokens AND sub_41B080() returns false (config not already in user folder); then the `GTR2\` folder is created if `_access` reports it missing, and `Config.ini` is copied only on that first-missing branch. Loading: if the file cannot be loaded (sub_614460 fails) it tries to create it (sub_41B6F0); failure to create → log `Could not create config file` and return 0; success-but-cannot-reload → log `Successfully created, but could not subsequently load` and return 0. Only recognized section headers (`[COMPONENTS]`/`[INSTALL]`/`[AUTOLAUNCH]`/`[VERSION]`) are parsed; `GRIDSIZE` is clamped to [0,104]; `WINDOWEDMODE`/`RUNBENCHMARKS`/`VSYNC` bools are set true only when the parsed int != 0. Directory path values get a trailing `\` appended if absent. Returns 1 on success.
