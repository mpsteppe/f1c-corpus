## sub_5E6A50_005e6a50 — Flag-gated update routine (0 or 128)

**Summary:** Gate-and-update routine: checks several flag bits on *this and on the object at this+0x30, then either executes resource operations on the object at this+0x2C (sub_5FFF80/sub_5FFCF0 when a4 is set, sub_6004D0 otherwise) or verifies subordinate state, finally incrementing global counter dword_FB2E94 and returning 0; every blocked path returns 128.

**Written-by note (persistence):**
- this 0x0: Conditional — bit 0x40 is set only when (0x4000 & a4) and cleared only when the resource's byte lacks bit 4; no other bits are written. An external poke to bits other than 0x40 survives indefinitely; a poke to 0x40 survives until a call that sets or clears it.
- this 0x2C: The pointer itself is only read; the flags dword of the object it points to (this[11]) is modified conditionally in the 0x40 branch (OR 4, then OR 0x104 plus AND ~0x100 when a4 is set).

**Guard conditions:** `(*this & 4)` non-zero → immediate `return 0` (already-handled path). `(v5 & 2) == 0` → `return 128`. Byte at this[12] with bit 8 set, or bit 2 set in the byte found at *(this[12]+392) → `return 128`. `(v5 & 0x4000) && a4` → bit 0x40 is set in *this. If *this bit 0x40 is set (work path): flags updates run; `(a4 != 0)` → sub_5FFF80 + sub_5FFCF0, else → sub_6004D0 (v11 forced 16); then if the resource byte lacks bit 4, bit 0x40 is cleared in *this; `v10 == 16 && v11 == 16` → `return 128`. If bit 0x40 is clear (verify path): v9 = (v8 & 4) ? dword at (this[16]+44) : this[11]; `dword at v9+152 == 0` or `(v8 & 0x80)` set → `return 128`. Falling through → `++dword_FB2E94` and `return 0`.
