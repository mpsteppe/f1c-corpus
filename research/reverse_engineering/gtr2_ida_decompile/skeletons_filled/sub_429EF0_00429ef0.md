**Guard interpretation:** The function aborts when `*(a1+14820) > 1`; with the parent mode equal to 1 it takes the countdown/start path (decrement 0x5004 by 0.025, advance when it underflows), otherwise the main AI path — which requires `sub_427DB0(a1)` true AND parent mode still 1, else it returns. State 3 resets to 0 when the squared distance exceeds 0x5438 threshold; state 2 resets to 0 and returns; state 7 resets to 0 only when its timer value `< 0.2`. States 4/5 follow a separate branch: the phase flag 0x540C is cleared when either the counter 0x5148 reaches `dword_91BCB0` (mode != 6) or state 0x4BB4 == 2; the target is applied only if `sub_4FAE10(a1)` succeeds and 0x540C is set, otherwise the 0x5144 timer is pushed 4 seconds ahead. The mode-4 block runs only when `*(a1+5008) == 4`; its inner steering branch additionally requires the current time ≥ 0x4F8C.
