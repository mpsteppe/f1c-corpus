## sub_63160F_0063160f — class teardown (vftable reset + conditional buffer free)

**Summary:** Class teardown/reset helper: installs off_730210 as the object's vftable pointer and, when the flag dword at this+8 was nonzero, releases the owned heap buffer at this+4 via _free. Tail-called from the std::bad_alloc initializer path.

**Guard interpretation:** The flag at this+8 is tested before the vftable store. If it was 0, the free is BLOCKED (skipped) and only the vftable pointer is written. If it was nonzero, `free(*(this+4))` runs — the owned buffer is released. Either way the function returns void and the vftable store always happens.
