## sub_4D6060_004d6060 — Query virtual rect (slot 0xA0) or own coords, draw and return bounds

**Summary:** Asks virtual slot +0xA0 for a rect/entry pointer; if it returns one, validates the rect (non-zero width, height > 0) and draws it via the sub_4D5E10 dispatch with a handle resolved from unk_B6E2A0, then PositionUpdate; if the virtual call returns null it instead draws from this+0x4..0x10 through sub_4DD980. Either way the caller's four output pointers receive the resulting bounds.

**Called by:** sub_4B2BE0 (004b2be0), sub_4B7CA0 (004b7ca0)

**Guard conditions:** Branch on the virtual slot +0xA0 result. If non-null: draw requires width v20 >= 0, non-zero width (v10[1] != v10[0]), height v21 > 0, and node[7] nonzero — only then are the draw, PositionUpdate, and output writes executed. If the virtual call returns null: the fallback draw runs when both spans v13 = this+0x10 − this+0xC and v14 = this+0x8 − this+0x4 are > 0, but the four outputs (*a2..*a5) are written in this branch even when the draw is skipped.
