## sub_67AC78_0067ac78 — write-info entry (row init + transform application)

**Summary:** Entry point that prepares a PNG write: if the rows-initialized flag (0x40 in the flags at this+0x5C) is clear it first runs the row-buffer initialization sub_6BA4FC, then applies the write-side transformations to the info structure through sub_67B630 and returns its computed rowbytes value.

**Called by:** sub_648787 (00648787)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x5C | R | — | PNG write flags; bit 0x40 marks that the row buffers have been initialized |

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 0067b630 | PacketFieldEncoding [structural] | applies write transformations to the info structure (color type, bit depth, channels/pixel depth) and computes/stores rowbytes |
| 006ba4fc | AudioBufferSizeCalc [structural] | initializes write row buffers (allocates row and previous-row buffers, computes per-pass layout) and sets the rows-initialized flag 0x40 |

**Guard conditions:** Reads flags byte at this+0x5C, bit 0x40: if clear the row-buffer initialization sub_6BA4FC runs first; if already set that initialization is skipped. sub_67B630 is then called unconditionally with the info pointer and its return value is passed back to the caller.
