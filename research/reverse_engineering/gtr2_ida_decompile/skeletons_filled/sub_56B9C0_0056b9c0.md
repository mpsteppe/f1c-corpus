## sub_56B9C0_0056b9c0 — Conditional refresh of field 0xC0C

**Summary:** Updates this[771] (0xC0C): when the global mode dword_BE1204 equals 2 it stores the value returned by sub_5210A0(&dword_BE120C); in every other state it writes the double sentinel dbl_FB1D18. Called from sub_51B2F0.

**Called by:** sub_51B2F0 (0051b2f0)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0xC0C | RW | — | slot (float index 771) receiving either the helper's return value or the dbl_FB1D18 sentinel |

**Written-by note (persistence):**
- this 0xC0C: conditional but written on every call (both branches store); the value is refreshed per call, so an external poke would be overwritten the next time this runs.

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|
| 00be1204 | dword_BE1204 | R | global mode/state dword; only the value 2 selects the helper path, anything else yields the sentinel |
| 00be120c | dword_BE120C | R | global passed by address to sub_5210A0 — the helper reads/derives the stored value from it |
| 00fb1d18 | dbl_FB1D18 | R | sentinel constant written when the mode check fails (same sentinel stamped by sub_56AAE0) |

**Functions called:**

**Guard conditions:** Single branch `dword_BE1204 == 2`: PASSES (helper path) only when the global is exactly 2 — sub_5210A0(&dword_BE120C) is called and its result stored at 0xC0C. All other values (0, 1, 3, …) are BLOCKED from the helper path and instead store the dbl_FB1D18 sentinel. There is no other validation and no early return.
