## sub_56B780_0056b780 — Pack per-slot and engine data into compact record at 0xB90

**Summary:** Builds a compact packed record at this+0xB90: four per-slot (stride 296) quantized fields are folded into one dword (8 bits each) and one word (4 bits each), a byte summarizes three float fields (0xA4/0xB8/0xCC/0xE0) as 2-bit codes, and — if the gate byte at 0xC14 is set — a 25-entry table (stride 28 at 0xC18) contributes a nonzero-entry bitmask, a clamped two-nibble byte at 0xB97, and three fixed-point shorts at 0xB9C. Returns pointer this+0xB90. Called from sub_577180.

**Guard interpretation:** Per-slot loop (4 iterations, stride 296): each slot yields a 2-bit code — `dword < 24 ? dword>>3 : 3` — folded into the 0xB90 dword together with two more rounded 3-bit values, and a rounded 4-bit value into the v14 nibble array; all are then packed into 0xB90/0xB94/0xB96 unconditionally. The optional section is gated by byte 0xC14: when it is zero the routine clears 0xB98/0xB97 and the three shorts and returns; when nonzero it iterates 25 entries (stride 28 at 0xC18) and only nonzero entry bytes contribute — setting bit i in 0xB98, writing the clamped nibble pair to 0xB97 (each qualifying entry overwrites it, so the last nonzero entry wins) and calling sub_4164C0 for the entry's float data. The 0xB9C/0xB9E/0xBA0 shorts thus hold the last processed entry's converted data, or zero.
