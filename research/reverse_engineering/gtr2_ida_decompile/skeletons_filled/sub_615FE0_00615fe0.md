**Guard conditions:** The scan runs only when _getcwd succeeds. The path-rebuild block runs only when the depth counter (obj+0x21C) is zero, and inside it only when the byte at obj+0x218 (a5) is non-zero; a relative path additionally appends the separator and the supplied name only when Str differs from ".". The chdir result gates everything else: on failure (result == -1) the depth counter is decremented and nothing is scanned; on success subdirectory recursion (when the a3 byte is set) skips "." and ".." and only entries with the directory attribute (0x10) set are descended into, while only entries with the attribute clear are formatted into the list (sub_615E60). The final result-list snapshot (obj+8 = obj+0) happens only when the depth counter falls back to zero. An empty or null Str is replaced by "."; paths starting with "\\\\" or containing ":" are treated as absolute.
