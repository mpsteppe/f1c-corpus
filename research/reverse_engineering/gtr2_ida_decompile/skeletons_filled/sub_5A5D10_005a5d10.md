## sub_5A5D10_005a5d10 — submit work item via QueueUserAPC

**Summary:** Submits an asynchronous work item: invokes virtual slot vtable+0x3C on this, queues an APC carrying this as its data onto the thread handle stored at this+8, then — only if sub_5A5A20 reports success — invokes sub_5A6A30(a2) and the virtual slot vtable+0x5C (the item-processing callback used by the queue-drain routines). APC-based worker/queue submission path.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| obj | 0x3C | R | — | Vtable slot 0x3C (index 15) — first virtual call on this before the APC is queued (pre-submit hook) |
| obj | 0x5C | R | — | Vtable slot 0x5C (index 23) — virtual call after the wait/check succeeds (processing callback) |
| this | 0x0 | R | — | Vtable pointer, used to resolve slots 0x3C and 0x5C |
| this | 0x8 | R | — | Thread HANDLE (dwData[2]) passed to QueueUserAPC as the target thread |

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|
| 00606bd0 | pfnAPC | R | APC routine function pointer queued via QueueUserAPC; receives the object pointer as its data argument |
| 006f11e0 | QueueUserAPC | R | kernel32 import — queues the APC routine onto the thread handle at this+8 |

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 005a5a20 | sub_5A5A20 | Check/wait helper; its boolean result gates the rest of the submission (false → aborts and returns 0) |
| 005a6a30 | sub_5A6A30 | Post-APC step invoked with the caller's argument a2 |

**Guard conditions:** `sub_5A5A20()` is called after QueueUserAPC; if it returns 0/false the function returns 0 and skips both sub_5A6A30(a2) and the virtual slot vtable+0x5C. PASS (continues to those two calls, returns 1) only when sub_5A5A20 returns non-zero.
