**Guard conditions:** `sub_539670` result must be non-null for the `_CPIT.GTR` / id-1 name path (otherwise skipped); within it the name pointer falls back to WindowName. The switch handles 1..11; any other id goes to the shared exit which releases Block/v30 and returns 1. For ids 3,4,6,7,9,10,11 the texture load path first tries sub_5E4940, and on failure (nonzero return) the handle is released via sub_5E4BF0 and zeroed. At LABEL_58 the handle for the id is tested: if already nonzero the function returns 1; if zero it calls the default loader `off_16C933C(a2)` and returns its result. Case 9 additionally requires `sub_53A250(0)` truthy and a matching `Pit Board Location` string equal to `Left` before using 10.0 (otherwise 1010.0).
