## sub_52C430_0052c430 — CheckCarLinedUp

**Summary:** Alignment check for a car/start-grid state: it reads the car object's vectors, computes orientation dot products and squared-distance terms, and returns 0 when the car is misaligned. Depending on the two flag arguments, a failed check either displays "Not Lined Up Properly" (or "False Start" when the false-start global is enabled) or fails silently; when the check passes it clears the message and returns 1.

**Guard interpretation:** The a2 path with dword_B704D4 set PASSES to feedback only when obj+0x39E4 is not 1: a small direction error (<= 225) routes to sub_52BC40, a larger one to the 'False Start' message; when the flag equals 1 the branch is BLOCKED and the function returns 0 silently. Independently, when a2 is clear and the car vector length squared exceeds 1.0 the function returns 0 immediately. Overall PASS (return 1) requires all alignment terms within thresholds (direction length², two dot products v11/v10); the a3 flag only controls whether the 'Not Lined Up Properly' message is shown (on failure, when length² < 400) or cleared (on success).
