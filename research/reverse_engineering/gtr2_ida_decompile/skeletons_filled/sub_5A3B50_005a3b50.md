## sub_5A3B50_005a3b50 — AcceptTimeStampedSample

**Summary:** Validates and stores an incoming time-stamped sample on this object: rejects it if the object ID (this+0x0) does not match a2 or if the sample time is 2.0 or more seconds newer than the previously stored time (this+0x8); otherwise marks the object active, writes the sample time, computes an interpolated time (half the interval plus a4), and copies up to 254 bytes of payload.

**Called by:** sub_5A5000 (005a5000)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | R | — | Object/link ID compared against incoming a2; identity key for accepting samples |
| this | 0x8 | R | — | Previously stored sample time, subtracted from a3 to compute the interval |
| this | 0x10 | RW | 1 | "Have sample" / active flag, set to 1 on each accepted sample |
| this | 0x18 | RW | — | Stores the accepted sample time a3 |
| this | 0x20 | RW | — | Interpolated time: (a3 − old 0x8) * 0.5 + a4 |
| this | 0x128 | RW | 0 | Payload length: a6 when 0 < a6 < 255, otherwise forced to 0 |

**Written-by note (persistence):**
- this 0x10: Written on every accepted call (set to 1); a poke survives only until the next accepted sample, which overwrites it with 1.
- this 0x18: Recalculated (overwritten with a3) on every accepted call; not persistent.
- this 0x20: Recalculated on every accepted call from live inputs; not persistent.
- this 0x128: Overwritten on every call (a6 or 0); not persistent.

**Guard conditions:** Two rejection guards, both return 0: (1) a2 must equal *(DWORD*)this (this+0x0) — any ID mismatch is BLOCKED before any write; (2) the interval v6 = a3 − this[1] (this+0x8) must be < 2.0 — a sample 2.0 s or more newer than the last stored time is BLOCKED (return 0, no state change). On PASS: byte this+0x10 set to 1, this+0x18 = a3, this+0x20 = v6*0.5 + a4, and then length a6 is checked: if a6 <= 0 or a6 >= 255 the length field this+0x128 is set to 0 and the payload copy is SKIPPED; otherwise this+0x128 = a6 and a6 bytes from a5 are copied to this+0x28. The function returns 1 in both of those cases.
