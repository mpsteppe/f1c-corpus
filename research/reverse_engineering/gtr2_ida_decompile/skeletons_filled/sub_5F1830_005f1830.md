## sub_5F1830_005f1830 — Format code + bpp → texture format ID (inverse mapper)

**Summary:** Inverse of the texture format mapper: given an internal format code a2 and a bits-per-pixel value a3, writes the corresponding texture format ID (integer D3D formats 20/21/22/23/25/26/41 or the DXT1..DXT5 fourccs 827611204/844388420/861165636/877942852/894720068) into *a1. Unmatched combinations leave the output untouched.

**Guard conditions:** `if (a1)`: a null output pointer skips the entire body (BLOCKED). a3 (bits per pixel) selects the accepted code set: a3 == 32 accepts codes 8 → 21 and 14 → 22; a3 == 24 accepts code 7 → 20; a3 == 16 accepts code 6 → 23, code 5 → 25, code 3 → 26; a3 == 8 accepts code 4 → 41; a3 == 0 accepts any of 8 → 21, 14 → 22, 7 → 20, 6 → 23, 5 → 25, 3 → 26, 4 → 41 regardless of bpp. Combinations not matching the selected bpp fall through to the trailing switch, which resolves code 9 → DXT1, 10 → DXT2, 11 → DXT3, 12 → DXT4, 13 → DXT5 fourccs. Any other code reaches no write at all (output BLOCKED). Return value is a2 passed through.
