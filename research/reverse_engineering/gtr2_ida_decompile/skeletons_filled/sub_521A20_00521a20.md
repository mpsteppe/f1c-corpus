## sub_521A20_00521a20 — List walk re-binning items against a float threshold

**Summary:** Stores the threshold a2 at this+0x30, then traverses the intrusive list headed at this+0x20 (cursor kept in this+0x28, each element laid out as [item pointer, next pointer]). Per item: if v6 == 0 OR v5 == 0 OR a2 < item[+860] OR a2 > item[+12], the item is re-binned — PASS into the update block. Inside it: if v5 != 0 AND a2 > item[+12] → sub_51BFA0(item+856, item+8) then sub_599CB0(item); else if v6 != 0 AND a2 < item[+860] → sub_51BFA0(item+8, item+856) then sub_599C90(item); else → sub_59A9C0(item).
