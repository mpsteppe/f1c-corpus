**Guard interpretation:** If this+0x39D4 > 1 the function returns immediately, doing nothing. Type-7 entries are skipped (only pre-processed/copied) when the car is not the player object (this != off_757C18+16) and this+0x3CC8 != 3; the same condition guards the second-pass impulse distribution. The detailed contact solve runs only for type-10 entries whose entry base index is < 4, whose magnitude exceeds this+0x4AEC, that have an object pointer, and whose object byte at +42 is set; it is skipped entirely when dword_BE2758 is 0. Impact feedback (sub_52FF30) requires bit 0 of the vtable byte at +22580; sub_5300D0 runs only when sub_5762D0 is nonzero. The rear-impact flag this+0x4AF0 is set only for type-10 entries whose direction dot product is < -0.707.
