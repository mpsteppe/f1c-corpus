## sub_6D9938_006d9938 — send_tree — emit run-length-coded code lengths

**Summary:** Emits the run-length-coded form of a tree's Len words into the output bit stream: short runs repeat bl_tree[curlen] count times; longer runs of a nonzero length send bl_tree[curlen] once (when the length changed) plus the REP_3_6 code with count-3 in 2 extra bits; long zero runs send REPZ_3_10 (count-3, 3 bits) or REPZ_11_138 (count-11, 7 bits). Bits are packed through the accumulator at 0x16B0, flushing 2 bytes to the output buffer when fewer than the field width of bits remain free. Matches zlib's send_tree.

**Guard conditions:** if tree[0].Len (a3+2) == 0 → max_count=138, min_count=3, else 7/4. Loop runs only when max_code (a2) >= 0. Run continues while ++count < max_count && curlen == nextlen (LABEL_47). When count < min_count: a do/while emits the same bl_tree[curlen] code count times. When count >= min_count: curlen != 0 → if curlen != prevlen emit bl_tree[curlen] once and count--, then emit REP_3_6 code and count-3 in 2 extra bits (flush when bit count > 14); curlen == 0 → count > 10 emits REPZ_11_138 + count-11 in 7 bits (flush when bit count > 9), else REPZ_3_10 + count-3 in 3 bits (flush when bit count > 13). Every code emit checks free bits <= 16-field_len before accumulating, otherwise flushes both accumulator bytes via the 0x8 buffer and 0x14 counter and shifts. After an emit: count=0, prevlen=curlen, limits recomputed: nextlen == 0 → 138/3; curlen == nextlen → 6/3; else 7/4.
