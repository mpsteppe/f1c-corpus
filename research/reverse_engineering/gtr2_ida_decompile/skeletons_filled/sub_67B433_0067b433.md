## sub_67B433_0067b433 — enable transformation bit 0x1

**Summary:** Turns on transformation bit 0x1 in the png struct's transformations word and returns the struct pointer. The PNG loader enables it for color (RGB/RGBA, 8- and 16-bit) image types just before the info update, so the flag belongs to the read-side transform set (channel-order family).

**Written-by note (persistence):**
