## sub_5D73C0_005d73c0 — Rebuild rotation matrix from wrapped Euler angles

**Summary:** Wraps the three input angles with fmod(·, 2π), stores them into 0x54/0x58/0x5C, and rebuilds the 3x4 rotation/translation matrix: the 3x3 block (0x4–0x2C) is composed from sin/cos of the angles using one of two conventions selected by mode 0x44 == 2. Only the non-2 path also recomputes the translation row (0x34–0x3C = rotation · stored position 0x48/0x4C/0x50) and sets w = 1.0.

**Guard interpretation:** `this+0x44 == 2` → PASS branch: rotation matrix built with the first sin/cos convention (distinct products of sin/cos of the three wrapped angles) and the translation slots 0x34–0x40 are left untouched. Any other value → else branch: the alternative convention is used and additionally the translation row 0x34–0x3C is recomputed as rotation · (0x48,0x4C,0x50) with 0x40 = 1.0f. Either way the angles at 0x54–0x5C are refreshed at entry, so the guard only changes which matrix convention and whether translation is rebuilt.
