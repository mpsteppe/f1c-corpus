## sub_5F06E0_005f06e0 — Linked-list node remover (optional payload delete)

**Summary:** Searches an intrusive linked list (head at this+0, tail at this+4, aux pointer at this+8, count at this+0xC) for the node whose payload pointer equals a2; unlinks it, fixes up head/tail/aux pointers and the count, optionally destroys and frees the payload when a3 requests it, then frees the node itself. Returns 1 when a node was removed, 0 when the key is null or absent.

**Called by:** sub_5F0DA0 (005f0da0)

| *(obj+0x4) | 0x4 | R | — | Next-node link of a list node |
| *(obj+0x4) | 0x8 | RW | 0 | Owned-payload byte flag of a list node; cleared unless a3 requests payload deletion |

| this | 0x4 | RW | — | List tail pointer; moved back to the predecessor when the tail node is removed |

| this | 0xC | R | — | List element count, decremented on each removal |

**Written-by note (persistence):**
- *(obj+0x4) 0x8: written conditionally (only when a3 == 0) and the node is freed moments later — a poke there is meaningless and does not survive the call.
- obj 0x4: next-link rewritten each removal while unlinking; the list structure persists after the call, so the change survives until further list operations.
- this 0x0: rewritten only when the removed node was the head; otherwise untouched, so a poke survives until a removal of the head node.
- this 0x4: rewritten only when the removed node was the tail; otherwise untouched.
- this 0x8: rewritten only when the removed node matched this aux pointer; otherwise untouched.

**Guard conditions:** `if (a2)`: a null key returns 0 immediately (BLOCKED). `if (*this)`: an empty list returns 0 (BLOCKED). Traversal `while (*(_DWORD *)v4 != a2)` walks next links; hitting a null next pointer returns 0 (key not found). Payload destruction happens only when a3 is nonzero (when a3 == 0 the node's +8 flag byte is first cleared, preventing the payload free) and only if the payload pointer and the +8 flag are both nonzero. The node allocation is always freed once found.
