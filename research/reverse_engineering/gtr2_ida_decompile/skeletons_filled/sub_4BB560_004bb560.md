## sub_4BB560_004bb560 — Session list builder (GDB/24H save-slot scan)

**Guard interpretation:** When `*(_DWORD*)dword_B72314 == 4` the scan uses "*.GDB" and the prefix directory is taken from dword_91CA78 when `this[149]` (this+0x254) == 65 ('A'), else from dword_91CA80; any other state uses "24H*.GDB" with no prefix. Per file: `sub_616930("Game Name")` returning null routes to the plain add path; on state 4 the fallback name is passed through sub_5100A0 and the icon byte is set from `sub_534F50(unk_B76270) - 2` (0→0xBC, 1→0xBE with a "Custom" downgrade to 0xBD). State-4-only extra: "Custom" + sub_41D9E0 result not in 1..2 downgrades the icon. After the loop, the list count is written back at v1[139] (this+0x22C); when it is < 1, sub_4D4060(1,1) runs.
