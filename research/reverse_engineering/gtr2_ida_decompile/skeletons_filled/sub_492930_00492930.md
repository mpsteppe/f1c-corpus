## sub_492930_00492930 — Multiplayer session join retry tick (CINet join flow)

**Summary:** Per-frame tick for the "joining a session" state: retries CINet::JoinRoom over the room IP list, on success transitions to CLIENT TEAM SELECT, on subscription errors raises the renew/proceed popups, and on unknown failures shows the "Join Failure Page". Also re-drives the join progress UI and the "Please Wait..." banner.

**Guard interpretation:** `this[70]` (room-IP index at +0x118) is initialized to -1 (v45=-1) and only the `>= 0` case enters the retry re-arm block that walks CINet room IPs; when the index is negative the retry block is skipped. Inside that block a NULL object, a negative sub_4CE1B0 status, or a NULL sub_4CE170 string also skip the attempt. On the join-result switch: case 0 (success) transitions to CLIENT TEAM SELECT; cases 0xF and 0x13 go to the failure page; case 0x10 shows the subscription popup then falls into the failure path; default goes straight to cleanup. The `dword_B640C0 != 5` checks are nested guards that suppress the six debug log lines while app state is 5.
