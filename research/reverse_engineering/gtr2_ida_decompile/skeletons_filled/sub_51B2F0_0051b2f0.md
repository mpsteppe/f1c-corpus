## sub_51B2F0_0051b2f0 — Network event dispatcher (class/subtype switch)

**Summary:** Dispatches a packed network event record (`*(_DWORD *)this` holds class in bits 29-31, subtype in bits 18-23, slot in the low byte) to per-slot entity handlers operating on the record array at unk_9204A0 (stride 22616, slots 0..104) and its parallel arrays. Each arm validates the slot index and the record state field, and many class-4 arms are additionally gated by global mode flags.

**Guard conditions:** Top-level dispatch on `header >> 29`: only classes 1, 2, 3, 4 and 6 are handled — any other class (including 0, 5, 7) returns immediately. Per class, the subtype switch returns without action for unhandled subtypes (class 1 default, class 4 default, class 6 default). Slot checks: most arms require the low byte < 0x68 (104); class-1 and class-2/subtype-9 arms require < 0x69. State-field checks: class-1 requires record[3705] == 2 (subtypes 1-6) or == 2 with slot<0x69 (subtypes 0/7); class-3 subtype 0 requires record[3705] == 3; class-2 subtype 2 requires field >= 2; class-4 subtype 8 requires field >= 2; class-6 subtype 5 requires state == 2. Global gates: byte_B6F118 suppresses the subtype-1 random branch; dword_BE1204 == 2 blocks subtypes 0x12/0x13/0x14/0x15/0x16/0x17/0x18/0x19/0x1A/0x21/0x22/0x23/0x24/0x28/0x29; (dword_B640C4 & 1) must be 0 for 0x15/0x21/0x22/0x23/0x26 and nonzero for 0x25/0x27/0x28/0x29; dword_B64134 must be 5/6/7 for 0x15 and < 5 (or dword_FADE9C > 0) for slot 104 in subtype 8; dword_BE2758 must be nonzero and (dword_925CD4[...] & 2) set for subtype 9. Subtype 2 additionally zeroes this[0xE] and this[0x10] only when (header & 0x3FF00) == 0x600.
