**Guard conditions:** The whole body runs only when the distance from the center to the offset point (sqrt of the three squared components) is greater than 0.0, so the direction can be normalized; inside, the second stage requires the normalized Z component to be non-zero (otherwise the function returns silently). First sweep: for each sampled parameter the angle between the two normalized vectors is compared — if it is <= the previous best angle the loop breaks (no crossing found, fall-through writes the ±0.1 X caliper points); if it is >= the flt_B70E88-based threshold, an interpolated parameter is computed, the point is formed via Vector3ScalarMultiply + Vec3Add and the off_16C9604 callback fires with the point's X/Y and a2. Second sweep: angle <= previous best angle writes the second-sweep points (0xB64–0xB78) and returns; angle >= the flt_B70EAC-based threshold breaks out and the fall-through computes both interpolated points and calls the off_16C98A0 callback. The interpolation factor uses min(flt_B70E88, flt_B70EAC) scaled by the sweep radius, stepped in 0.031830989 increments.
