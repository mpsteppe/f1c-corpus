## sub_60AA40_0060aa40 — configure object (store id/flag, detach registered sub-objects, set float param)

**Summary:** Configuration/reset routine: unconditionally stores the id a2 into this+0xCC and the flag a9 into this+0xED; if the global manager (dword_FB40C8) exists, clears the five managed reference slots 0xD0/0xD4/0xD8/0xDC/0xE0 by calling their detach setters with 0, and stores the float a7 at this+0xE4.

**Called by:** sub_5F84A0 (005f84a0), sub_60ABB0 (0060abb0)

| this | 0xD0 | RW | 0 | first managed sub-object reference; cleared to 0 and detached via sub_60A820(this, 0) |
| this | 0xD4 | RW | 0 | second managed reference; cleared to 0 and detached via sub_60A500(0) |
| this | 0xD8 | RW | 0 | third managed reference; cleared to 0 and detached via sub_60A3A0(this, 0) |

| this | 0xED | RW | — | char parameter a9 stored unconditionally (flag byte) |

**Written-by note (persistence):**
- this 0xCC: written unconditionally with a2 each call; an external poke survives until the next call, then is overwritten.
- this 0xD0: written to 0 only when the manager global is present (both directly and by the detach helper); an external poke survives until the next call with a manager present.
- this 0xD4: written to 0 only when the manager global is present; external poke survives until the next such call.
- this 0xD8: written to 0 only when the manager global is present; external poke survives until the next such call.
- this 0xDC: written to 0 only when the manager global is present; external poke survives until the next such call.
- this 0xE0: written to 0 only when the manager global is present; external poke survives until the next such call.
- this 0xE4: written with a7 only when the manager global is present; an external poke survives until the next such call (or indefinitely if the guard never passes again).
- this 0xED: written unconditionally with a9 each call; an external poke survives until the next call, then is overwritten.
