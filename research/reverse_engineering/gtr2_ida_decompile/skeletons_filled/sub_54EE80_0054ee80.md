## sub_54EE80_0054ee80 — Find previous acceptable entry ID by backward scan

**Summary:** Searches the table (count at this+0x340, ID per 8-byte record at this[2*i]) for the entry whose ID equals a2, then scans backwards from the preceding index for the nearest entry that passes a validity filter — per-ID record flag byte set, and either record type != 2 or the record's float value within 3.0 of dbl_FB1D18. Returns that entry's ID, or -2 when nothing suitable exists. The backward scan is scalar for indices < 4 and a 4-wide unrolled variant otherwise.

**Guard conditions:** 
- If the entry count this[208] (this+0x340) <= 0 → target index v3 stays -2 (never a valid match).
- Forward search: increments v3 while `a2 != this[2*v3]`; if `v3` reaches the count without a match → v3 = -2 → v4 = -3 → immediate return -2.
- Backward scan accepts an entry only when its record flag byte is non-zero AND (record type != 2 OR |float(value) - dbl_FB1D18| < 3.0); entries of type 2 whose value is 3.0 or further from the reference are SKIPPED.
- If the scan walks below index 0 → return -2 (no acceptable predecessor).
- Success returns the accepted entry's ID (`this[2*v4]`); the chosen index is always < the originally matched index.
