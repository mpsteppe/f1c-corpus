## sub_5936E0_005936e0 — Keyframe-curve update (walk, interpolate, timers)

**Guard conditions:**
- Walk loop: while a3 >= next-node key (node+0) the cursor (this+0x3C) advances to that node and the next pointer (node+0xC) is reloaded. PASS = a3 < next key → interpolation path (factor v7 = (a3 − cur key) / (next key − cur key), both channels lerped). BLOCKED = next pointer becomes null (list end) → clamp path: both channels copied from the last node unchanged.
- Time step: field +0x38 read; if it is >0 or ==0 it is used as-is, if negative it is replaced by 0.0, then scaled into the per-call step (v18 = value·0.0000011574074 + 0.000011574074).
- Timer A (+0x44) vs floor (+0x40): if >= floor and > 0 → decrement by (rate + step)·a2, then clamp up to floor if it fell below; if < floor → snapped immediately to floor. Same structure for timer B (+0x48) vs floor, decremented by step·a2 only.
- Progress accumulator (+0x496): += a2 · a4 · 0.000023148148; result clamped: < 0 → 0, > 1 → 1.0f (0x3F800000).
- Final smoothing: if a2 < 499.99997 the derived value is blended toward the newly computed target with coefficient a2 · 0.0020000001; otherwise the target is stored unblended into +0x38.
