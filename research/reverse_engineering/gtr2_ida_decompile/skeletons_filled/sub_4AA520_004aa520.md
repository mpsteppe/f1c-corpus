## sub_4AA520_004aa520 — DispatchByStateByte

**Summary:** Reads the state byte at this+0x40 and, for state 0 or 1, looks up an object by ID (6 or 7 respectively) and performs a follow-up operation on its field +28; then always runs the pre-handler sub_4D8010 and delegates to sub_496BF0 with the forwarded arguments.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x40 | R | — | State selector byte: 0 selects lookup ID 6, 1 selects lookup ID 7, anything else skips the lookup. |

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 00496bf0 | sub_496BF0 | Final delegation receiving (this, this, a2, a3); its return value is returned. |
| 004cd450 | sub_4CD450 | ID lookup (6 for state 0, 7 for state 1) returning a pointer (0 = none). |
| 004d2f20 | sub_4D2F20 | Follow-up operation invoked with the looked-up object's field at +28. |
| 004d8010 | sub_4D8010 | Pre-handler always invoked with (this, a2, a3) before the delegation. |

**Guard conditions:** State byte this[0x40]: 0 → lookup with ID 6; 1 → lookup with ID 7; any other value bypasses both the lookup and the +28 follow-up (jump to LABEL_8). The +28 operation runs only when the lookup result is non-zero AND its field at +28 is non-zero. sub_4D8010 and sub_496BF0 run unconditionally.
