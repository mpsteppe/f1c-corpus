## sub_5F0380_005f0380 — Font string extent measurer

**Summary:** Measures the rendered pixel width of a string for the font object: walks the characters, sums per-glyph widths (using per-glyph advance bytes when flag bit1 is set), applies the X scale according to the calling flags, and optionally outputs the line height (base height-2, Y-scaled) through a4. Read-only text metrics helper used across UI/game code.

**Called by:** sub_4DE730 (004de730), sub_4E1950 (004e1950), SubtractionWithGuard [exact] (004e4750), sub_4E6AA0 (004e6aa0), sub_562B70 (00562b70), sub_562C80 (00562c80), sub_5680F0 (005680f0), sub_5688F0 (005688f0)

**Guard conditions:** `(a5 & 0x40) == 0`: scaling path — X/Y factors are read from this+0x98/this+0x9C; if SET, factors stay 1.0 (unscaled). `if (a4)`: height (this+0x68 - 2) is written only when the pointer is non-null; `(a5 & 0x80) == 0` → scaled by Y factor, SET → raw value. `if (a3)`: width is accumulated only when the pointer is non-null. Per character: `v10 >= 0x20 && v10 < *(this+124)` — characters below 0x20 or at/above the slot count contribute nothing (skipped). `(this+0x10 & 2)`: SET → advance is rec+4 byte plus signed rec+7 plus 1; clear → rec+4 byte only. `(a5 & 0x40)`: SET → each character's width is scaled/rounded and added individually; clear → raw widths are summed and only the total is scaled once at the end (`*a3 * X scale`).
