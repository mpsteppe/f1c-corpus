## sub_6182E0_006182e0 — array_ensure_one_more_slot

**Summary:** Growable-container `reserve`-style helper: if the array at +0x8 lacks capacity for one more element (count at +0x14 + 1 exceeds capacity at +0xC), allocates a larger array, grows the capacity in steps of the stride at +0x1C until it covers count+1, initializes the new block via sub_618030, copies the existing elements, frees the old array, and updates pointer/capacity. Returns 1 on success, 0 if allocation fails.

**Guard conditions:** If `count+1 <= capacity` (+0x14+1 <= +0xC), returns 1 immediately with no allocation — the container already has room. Otherwise it grows capacity in stride (+0x1C) increments until it is >= count+1; if `operator new` returns null (or the constructed pointer is null) it returns 0 (failure), aborting without touching the old array. Success path returns 1.
