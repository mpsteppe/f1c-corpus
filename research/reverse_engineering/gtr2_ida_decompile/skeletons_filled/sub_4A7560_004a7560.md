## sub_4A7560_004a7560 — toggle pointed state value (0/1 or 0/3 by type)

**Summary:** Toggles a state dword reached through this[70]: for object ids other than 276 or 636 it flips the value between 0 and 1, for those two ids between 0 and 3, then notifies via sub_494640. All work is guarded by this[70] being nonzero and the byte-field predicate sub_4CD650(this) returning zero.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x114 | R | — | this[69] — object/type id; 276 and 636 take the 0/3 toggle variant, all others the 0/1 variant |
| this | 0x118 | RW | — | this[70] — pointer to the dword being toggled; the pointed-to value is rewritten (0↔1 or 0↔3) |

**Written-by note (persistence):**
- this 0x118: the pointer field itself is not written; the dword it points to is toggled each time the guards pass. An external poke of the pointed dword survives until the next passing call, which flips it again.

**Functions called:**

| 004cd650 | ByteFieldGetterAt100 [exact] | Reads byte field at offset 0x100 of this; nonzero result blocks the whole toggle (early return 0) |

**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|
| this | 0x118 | == | 0 | this[70] (pointer) must be nonzero to proceed; the pointed dword's value 0 selects the other branch of the toggle |
| this | 0x118 | == | 3 | Pointed dword equal to 3 maps to 0 in the 276/636 variant; any other value maps to 3 |

**Guard interpretation:** Entry requires `this[70] != 0` AND `sub_4CD650(this) == 0`; a nonzero byte-field result (or null pointer) skips everything and returns 0. Inside, id `this[69]` decides the toggle domain: ids **276 and 636** use 3 (value 3 → 0, anything else → 3), every other id uses 1 (value 0 → 1, else → 0). sub_494640 runs after either toggle; the function always returns 0.
