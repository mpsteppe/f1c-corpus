**Guard conditions:** Selector switch on `((*(dword*)a2 >> 18) & 0x3F) - 1`; only 0..5 have cases, anything else returns the selector. Every case first checks the int16 index v6 (from a2+8) against its pool bounds: 0 ≤ v6 < this[9]/[12]/[15]/[18]/[21]/[24]; out-of-range → return with nothing applied. Case 3: v6 ≥ 420 → direct sub_419950; v6 < 420 → record must still have index -1 and the dword_921100 lookup must be non-zero (else return) before sub_417E90 + off_16C95A8. Case 4: v6 ≥ 210 → direct sub_419950; otherwise the parity-selected lookup must be non-zero (else the whole case falls through and returns 0) before sub_417E90 → sub_57C120(4/5) → sub_419950. Case 5: v6 ≥ 840 → directly sub_419950; otherwise v6 < 840 with a non-zero dword_921628 lookup → sub_417E90 → sub_57C120(v20+6) → sub_419950, and a zero lookup skips the update. Default selector values → nothing.
