## sub_64651B_0064651b — Scalar deleting destructor

**Summary:** MSVC-style deleting destructor: destroys the node's contents via sub_6464C0, then frees the object block itself when the low bit of the flag argument is set. Returns the object pointer.

**Called by:** sub_64A450 (0064a450)

|------|--------|-----|------------------------|---------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 006308d3 | j__free | CRT free; releases the object block when the caller requested deletion. |
| 006464c0 | sub_6464C0 | Recursive node destructor; frees the object's owned buffers and child subtrees. |

**Guard conditions:** `a2 & 1` checked: bit 0 set → after destruction the object block is freed with j__free; bit 0 clear → contents are destroyed but the block is left allocated. No other branches; the object pointer is always returned.
