## sub_6461A1_006461A1 — Create object if header tag matches, then initialize from header

**Summary:** Validates the header DWORD's high word against two magic values; when it matches, allocates a 32-byte object, constructs it (sub_67652E) and loads/initializes it from the header (sub_67654F), handing the object to `*a2`. Non-matching tags succeed with `*a2` left null.

**Called by:** sub_672E89 (006672e89)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | R | — | Header DWORD: high word (`& 0xFFFF0000`) checked against the two magic tags that trigger object creation |

**Globals referenced:**

|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 00630739 | ??2@YAPAXI@Z | operator new — allocates the 32-byte object block |
| 00646093 | sub_646093 | Deleting destructor for the new object when initialization fails (called with flag 1) |
| 0067652e | sub_67652E | Constructs/initializes the freshly allocated block, returning the object pointer v2 |
| 0067654f | sub_67654F | Loads the object from the header a1 (second arg 0); negative return aborts |

**Guard conditions:** (1) `!a1 || !a2` → -2005530516; `*a2` cleared at entry when non-null. (2) Creation runs only when `*a1 & 0xFFFF0000` equals -131072 or -65536; any other tag jumps straight to success with `*a2 = 0`. (3) Allocation returning null or sub_67652E returning null → -2147024882. (4) sub_67654F < 0 → the object is destroyed via sub_646093(v2, 1) and the negative code is returned. (5) Otherwise `*a2 = v2` and 0 is returned.
