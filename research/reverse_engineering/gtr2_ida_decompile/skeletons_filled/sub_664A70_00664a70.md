## sub_664A70_00664a70 — VM name-attach pre-pass + operation executor

**Summary:** Pre-pass for the VM engine's operation executor: walks a linked list of identity/name nodes (a10) to pick the name string matching the current object/context type id (this[4]), stores it onto the target VM object referenced through table entry a4 — concatenating with "; " when the object already carries a name, with conditional extra flag bits — then runs the actual operation via sub_663EC6 and returns its result (written back through a11).

**Called by:** sub_663EC6 (00663ec6), sub_666E91 (00666e91)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x8 | R | — | VM state pointer (this[2]); object table and its counts live off this |
| this | 0xC | R | — | VM state object-id table count (state+4), used to bound-check id a4 before indexing |
| this | 0x10 | R | — | current object/context type id; compared against the id resolved by sub_6460B4 (exact match selects v39, high-16-bit match selects the fallback name v11) |
| this | 0x18 | R | — | VM state object table base (state+16), indexed by object id |
| this | 0x78 | R | — | VM state flags word (state+112); bit 0x200 gates adding flag 0x400 to the named object |
| this | 0x79 | R | — | VM state flag byte (state+113); bit 4 gates adding flag 0x100400 to the named object |
| this | 0x84 | R | — | nonzero skips the entire name-attach preprocessing loop |

**Functions called:**

**Guard conditions:** Skips entirely when a2 == NULL (goes straight to writing *a11 = v35). Fixup: (a5 == 0 && a9 != 0) remaps a7 = a9, a8 = &v34, a5 = 1. Name-attach loop skipped when a6 != 0, when a10 == 0, or when this[0x84] != 0. Inside the loop: a node is only processed when node->[1] == 17 and sub_6460B4 returns >= 0; a name is used only if this[0x10] equals the resolved id (primary) or equals it masked with 0xFFFF0000 (fallback v11, else v36). Bounds failures return negative errors: null object entry for a4 → 0x80004005; null remapped entry → 0x8007000E; failed merge allocation → 0x8007000E.
