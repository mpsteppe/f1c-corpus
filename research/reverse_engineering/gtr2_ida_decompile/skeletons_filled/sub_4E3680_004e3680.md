## sub_4E3680_004e3680 — Texture surface allocator (power-of-two + UV scale)

**Summary:** Frees any previously held surface buffer, then allocates a new 2D surface/texture via sub_5E47E0 using the next power-of-two dimensions of (a3, a4). On success it stores the original width/height, UV scale ratios (dim / next_pow2) and a valid flag; returns 0 after freeing if allocation fails.

**Called by:** sub_4E0280 (004e0280)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | R | — | pointer to surface/texture name string; null falls back to WindowName |
| this | 0x8 | RW | 0 | pointer to allocated surface/buffer; old value freed and nulled before reallocation |
| this | 0xC | RW | — | float UV scale factor U = a3 / next_pow2(a3), written on success |
| this | 0x10 | RW | — | float UV scale factor V = a4 / next_pow2(a4), written on success |
| this | 0x14 | RW | — | original width a3, stored on success |
| this | 0x18 | RW | — | original height a4, stored on success |
| this | 0x20 | RW | 8 | fixed 8, written before the allocation call (engine parameter, e.g. level/format selector) |
| this | 0x24 | RW | 1 | byte flag set to 1 to mark a successfully created surface |

**Written-by note (persistence):**
- this 0x8: freed and replaced on every call (old pointer freed via sub_5E4BF0) — an external poke does not survive and would be handed to the allocator's free on the next call.
- this 0xC: written only on the success path (recalculated per successful call) — poke persists only until the next successful call.
- this 0x10: same as 0xC — recalculated on every successful call.
- this 0x14: written only on success; overwritten by the next successful call.
- this 0x18: written only on success; overwritten by the next successful call.
- this 0x20: written unconditionally on every call before the allocation attempt — a poke is overwritten by the next call even if allocation fails.
- this 0x24: written only on success (=1); a poke to 0 survives until the next successful call.

**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|
| this | 0x0 | == | 0 | name string pointer; null selects WindowName as fallback |

**Guard interpretation:** Pre-check only: if the stored name pointer (this+0) is null, the default WindowName global is used instead — nothing is blocked by this. The outcome guard is on the allocation call: if sub_5E47E0 returns nonzero or the returned this+8 pointer is null, any buffer at this+8 is freed and the function returns 0. Otherwise (allocation present) it stores a3/a4, the UV ratios, sets the flag and returns 1.
