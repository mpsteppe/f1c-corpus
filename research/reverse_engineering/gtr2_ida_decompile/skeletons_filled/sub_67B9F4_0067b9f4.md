## sub_67B9F4_0067b9f4 — read filler expansion (gray/RGB row)

**Summary:** Expands each pixel of one decoded row by inserting a filler value (one byte at 8-bit depth, two big-endian bytes at 16-bit) before or after the sample group, turning gray rows into gray+alpha and RGB rows into RGBA. Updates the row descriptor's channels, pixel depth and rowbytes and returns the new row byte length.

**Called by:** sub_67CA0D (0067ca0d)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | R | — | row width in pixels — number of pixels to expand |
| this | 0x4 | RW | — | rowbytes — overwritten with the expanded row byte count and returned |
| this | 0x8 | R | — | color type: only 0 (gray) and 2 (RGB) are processed; any other value returns the width unchanged |
| this | 0x9 | R | — | bit depth: only 8 and 16 are processed; other depths return the width unchanged |
| this | 0xA | RW | 2 | channels — set to 2 (gray+filler) or 4 (RGB+filler) |
| this | 0xB | RW | 32 | pixel depth — set to 16/32 for 8-bit paths or 32/64 for 16-bit paths |

**Written-by note (persistence):**
- this 0x4: recomputed on every processed call as width × expanded pixel size — an external poke would not survive a call.
- this 0xA: overwritten with 2 or 4 on every processed call.
- this 0xB: overwritten with 16/32/32/64 depending on color type and depth on every processed call.

**Guard conditions:** The color type at this+8 must be 0 (gray) or 2 (RGB) — any other value (including palette) returns the current width untouched. Within those paths the bit depth at this+9 must be 8 or 16, otherwise the row is returned unchanged. The sign of the filler-side argument a4 chooses placement: a4 >= 0 writes the filler after each sample group, a4 < 0 writes it before. On success the row grows by one byte (8-bit: ×2 for gray, ×4 for RGB) or one sample pair (16-bit: ×4/×8), channels and pixel depth are updated, and the new rowbytes is stored and returned.
