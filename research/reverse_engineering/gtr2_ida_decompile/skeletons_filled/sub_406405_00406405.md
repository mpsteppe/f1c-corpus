## sub_406405_00406405 — Validate/lookup a search path against the global path lists

**Summary:** Normalizes the caller's path string (copy to a 256-byte buffer, uppercase, strip one trailing backslash) and searches for it in one of two global search-path lists chosen by the a3 flag. Returns 0 on a match (invoking the list-removal helper for the found node) or logs "Invalid search path %s specified" / "Search path %s not found" through the engine message logger and returns -1.

**Guard conditions:** Empty argument string (`*ArgList == 0`) BLOCKS the lookup — logs "Invalid search path %s specified" and returns -1. Trailing backslash (char 92) is stripped from the normalized copy. List selection: `a3 == 0` uses one global list, otherwise the other. Empty list or null first node BLOCKS — logs "Search path %s not found" and returns -1. The walk compares each node's name (node+4) with the normalized string using strcmp; a match calls the removal helper with delete flag 1 and returns 0; exhaustion of the chain (next pointer null) also falls through to the not-found path (-1).
