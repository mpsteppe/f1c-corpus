## sub_6CD068_006cd068 — type-tag dispatch with vtable method and build sequence

**Summary:** Switches on the low 20 bits of a descriptor's tag word: tags 1/3/4 forward fixed opcodes 5/8/9 to sub_6CCA8D; any other tag instead calls a virtual method at vtable+0x80 (filling v3), then chains two sub_6CB29C calls using descriptor fields, returning 0 on success or the first negative status.

**Called by:** sub_6A1C41 (006a1c41), sub_6ACF7B (006acf7b), sub_6B0326 (006b0326), sub_6B321C (006b321c)

|------|--------|-----|------------------------|---------|
| *(this+0x100) | 0x0 | R | — | Descriptor word; its low 20 bits (mask 0xFFFFF) form the switch type tag |
| *(this+0x100) | 0x8 | R | — | Sub-block pointer inside the descriptor; passed (and passed +8) to the first sub_6CB29C call |
| *(this+0x100) | 0xC | R | — | Dword field of the descriptor; passed to the second sub_6CB29C call |

| this | 0x100 | R | — | Pointer to the descriptor object that supplies the type tag and the argument fields (+0, +8, +0xC, +0x10) |

| 006cca8d | sub_6CCA8D | Shared event dispatcher; invoked with fixed opcodes 5, 8, or 9 for tags 1, 3, 4 |

**Guard conditions:** Switch on (dword at *(this+0x100) & 0xFFFFF): tag 1 → returns sub_6CCA8D(this,5,0); tag 3 → returns sub_6CCA8D(this,8,0); tag 4 → returns sub_6CCA8D(this,9,0). Any other tag proceeds to the vtable call at vtable+0x80, which must return >= 0; then each sub_6CB29C call must also return >= 0 — the first negative result is returned immediately, success returns 0.
