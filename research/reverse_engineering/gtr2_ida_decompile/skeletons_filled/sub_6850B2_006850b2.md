## sub_6850B2_006850b2 — weight-matching neighbor reassignment

**Summary:** Normalizes an array a3 of a4 node indices against the 4-cell neighbor list a2: if the listed nodes all share the same double weight (node+0x20), the whole array is replaced by one neighboring node whose weight matches; otherwise each entry is individually swapped for a neighboring node with equal weight. Returns 0.

**Guard conditions:** Common test: a neighbor slot is usable only when slot != -1 AND its node's double at +0x20 equals the compared node's double. a4 <= 1: scans the 4 slots (rotated order starting at (0-1)&3); if no match after all 4 → return 0 without changes; on match fills a3[0..a4-1] with that neighbor. a4 > 1: first checks a3[1..a4-1] all have weight equal to a3[0]; if yes → same 4-slot search and fill path; if not, per-entry i scans 4 slots starting at (v16+i)&3 and replaces a3[i] only when an equal-weight slot is found, otherwise that entry is left unchanged.
