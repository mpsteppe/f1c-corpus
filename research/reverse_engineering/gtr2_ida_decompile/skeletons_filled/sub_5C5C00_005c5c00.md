## sub_5C5C00_005c5c00 — deleting destructor (scalar, vtable reset + conditional free)

**Summary:** Destructor for a C++ class: resets the object's vtable/class pointer (`this[0]`) back to the global pointer in `off_72A1F8`, and if the flag bit 0 of the second argument is set, frees the object memory via `j__free`. Returns the object pointer, the standard MSVC scalar-deleting-destructor shape.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | RW | — | Object vtable/class pointer slot; overwritten with the pointer value loaded from `off_72A1F8` during destruction |

**Written-by note (persistence):**
- this 0x0: written unconditionally on every call; after the call the object is either freed (when `a2 & 1`) or left with the base-class vtable pointer. An external poke would not survive if the destructor runs again; if freed, the memory is invalid.

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|
| 0072a1f8 | off_72A1F8 | R | Global holding the vtable/class pointer loaded and stored into `this[0]` (restores base/class identity during destruction) |

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 006308d3 | j__free | Frees the object's memory block when the delete flag (`a2 & 1`) is set |

**Guard conditions:** Flag check `(a2 & 1) != 0` gates the `j__free(Block)` call: set → object memory is freed; clear → object memory is retained and only the vtable/class pointer is rewritten. The vtable store itself is unconditional.
