## sub_662412_00662412 — Chunked arena bump allocator

**Summary:** Allocates `a2`+2 dwords (8-byte header + payload) from a chunked arena: reuses the current block at this+0x88 when its remaining space (this+0x8C) suffices, otherwise operator-new allocates a new block of max(a2+2, 0x2000) dwords, links it to the old block, and the request is carved from it; returns a pointer past the 2-dword header.

**Guard conditions:** Computes v3 = a2 + 2 dwords. If current remaining this+0x8C >= v3, the current block is used (header written: block pointer + remaining size) — no allocation. Otherwise a new block of v4 = a2+2 dwords (minimum 0x2000 dwords) is allocated via operator new; if it returns NULL the function returns NULL with this+0x88/0x8C untouched. On success the new block is linked (result[0] = old block pointer, result[1] = -old remaining), fields updated, and the carve (`remaining -= v3`, `cursor += 4*v3`, return cursor+8) proceeds identically in both paths.
