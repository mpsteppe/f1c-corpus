## sub_67B3C8_0067b3c8 — info getter: transparency (tRNS)

**Summary:** Retrieves tRNS transparency from the info structure: requires validity bit 0x10 at info+8; for palette images (color type 3) it outputs the palette-transparency byte array at info+0x30 and the 16-bit color block at info+0x34; for non-palette images it reports only the color block and forces the palette-array output to 0. An optional fourth pointer receives the 16-bit transparency count from info+0x16. Returns 16 when data was reported, otherwise 0.

**Guard conditions:** Returns 0 immediately unless a1 (png struct) and a2 (info) are both non-null and validity bit 0x10 at info+8 is set. Then, branching on the color type byte at info+0x19: palette (== 3) — if a3 is non-null it receives the byte array pointer from info+0x30 and the result becomes 16; if a5 is non-null it receives info+0x34. Non-palette — if a5 is non-null it receives info+0x34 and the result becomes 16; if a3 is non-null it is forced to 0. Finally, if a4 is non-null it receives the 16-bit count from info+0x16 and the function returns result OR 0x10 (so at least 16, i.e. the tRNS validity value, whenever a4 was provided); without a4 the raw result (16 or 0) is returned.
