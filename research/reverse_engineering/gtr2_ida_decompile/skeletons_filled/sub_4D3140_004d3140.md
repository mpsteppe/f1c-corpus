## sub_4D3140_004d3140 — StateDependentPanelLayout

**Summary:** State-driven layout/measure routine for a named UI panel: resolves a caption name (0xA0 field or default WindowName), applies an alternative name sourced from the object at 0xF4, then dispatches to one of three layout helpers (sub_4E08C0+sub_4E0730, sub_4E0680, sub_4E07F0) selected by the state value at 0x110, clamping the in/out bounds against metrics from sub_4CFCC0/sub_4CFD30. Always returns 0.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| *(this+0xF4) | 0x40 | R | — | name/caption string read from the referenced object when the byte at this+0x64 is zero |
| *(this+0xF4) | 0x50 | R | — | name/caption string read from the referenced object when the byte at this+0x64 is non-zero |
| this | 0x30 | R | — | manager/owner object passed to sub_4DF1B0 and every sub_4E0xxx layout helper |
| this | 0x64 | R | — | byte selector choosing which string (+0x40 vs +0x50) to read from the 0xF4 object |
| this | 0xA0 | R | — | configured name string; null falls back to WindowName, empty aborts the routine |
| this | 0xF4 | R | — | pointer to an object supplying the alternative caption name (+0x40 or +0x50) |
| this | 0x110 | R | — | state selector: 0, 1, 2 pick layout branches; any other value does nothing |

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|
| 006f16bc | WindowName | R | default window/panel name used when the 0xA0 string (or the 0xF4-sourced string) is null |

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 004cfcc0 | sub_4CFCC0 | per-index metric getter (called with 2 and 3) giving two reference dimensions (v9, v10) used as clamp maxima |
| 004cfd30 | sub_4CFD30 | per-index bounds getter (called with 2 and 3) supplying v11 and v34[2] |
| 004df1b0 | sub_4DF1B0 | applies the resolved caption/name to the 0x30 manager object |
| 004e0680 | sub_4E0680 | state-1 layout call: (manager, name, v11, a3+v11, v9, v10, 1) |
| 004e0730 | sub_4E0730 | state-0 follow-up layout call on the manager |
| 004e07f0 | sub_4E07F0 | state-2 layout call: (manager, name, v11, a3+v11, v10-…, v10, 1) |
| 004e08c0 | sub_4E08C0 | state-0 measure/layout call: (manager, name, &v33, v34, 1) producing bound outputs |

**Guard conditions:** (1) name = this+0xA0 else WindowName; strlen(name)==0 → early return 0 (everything blocked). (2) this+0xF4 pointer: null → skip the sub_4DF1B0 name application; non-null → read string at +0x50 if byte this+0x64 != 0, else at +0x40; null string falls back to WindowName; sub_4DF1B0 runs only if a non-null name is finally available. (3) state this+0x110: 0 → state-0 path, 1 → state-1 path, 2 → state-2 path, any other value → return 0 without further calls.
