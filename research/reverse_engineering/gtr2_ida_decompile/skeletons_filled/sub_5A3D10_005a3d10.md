## sub_5A3D10_005a3d10 — ReadFieldBitsReversed

**Summary:** Reads a bit-packed field from a bit array and returns it with the bit order reversed: for table entry a2 (4-byte record at this+0x8 base, word0 = base bit index, word1 = bit count) it gathers count bits ending at (base + count − 1) downward, placing the highest source bit into result bit 0.

**Called by:** sub_5A5000 (005a5000), sub_5A6C10 (005a6c10), sub_5A6C20 (005a6c20)

| this | 0x8 | R | — | Pointer to the 4-byte-per-entry field descriptor table; entry a2 gives base bit index (word0) and bit count (word1) |

**Guard conditions:** Only check is the bit count v3 (word at entry+2, v2[1]): when it is 0 the loop is SKIPPED and the function returns 0. Otherwise all `v3` bits are read (loop while v5 < v3); index a2 is used directly with no bounds validation.
