## __stbuf_0063963e — stdout/stderr console buffer setup

**Summary:** MSVC-style CRT stream initializer: for console stdout/stderr streams it allocates a 4096-byte buffer (falling back to a 2-byte inline buffer), wires the buffer pointers/size into the stream control block, and marks the stream as buffered.

**Called by:** _vfprintf (00634640), _fprintf (0063469d), _fputs (00634eb4)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | RW | — | Current buffer cursor pointer; set to the chosen buffer start (heap buffer or inline fallback) |
| this | 0x4 | RW | 2 | Buffer size/count; 4096 for the heap buffer, 2 for the inline fallback |
| this | 0x8 | RW | — | Buffer base pointer (same value as offset 0x0 at setup) |
| this | 0xC | RW | — | Stream flags/state word (16-bit): tested for 0x10C and OR'd with 0x1102 at the end |
| this | 0x10 | R | — | OS file descriptor passed to _isatty to test whether the stream is a console |
| this | 0x18 | RW | 2 | Duplicate buffer size stored alongside the count; 4096 or 2 matching the chosen buffer |

**Written-by note (persistence):**
- this 0x0: written on the setup pass; afterward the stdio layer advances it on every write, so an external poke is overwritten by normal stream output.
- this 0x4: written only during this setup (4096 or 2); survives until the stream is reconfigured, but any poke is clobbered the next time the stream is re-buffered.
- this 0x8: written only during setup; static for the life of the stream unless re-buffered.
- this 0xC: read for the 0x10C test in this function, later OR'd with 0x1102 here; thereafter stdio mutates it during I/O, so pokes will not persist.
- this 0x18: written during setup only; static until reconfiguration.

| 00912e10 | unk_912E10 | R | Static stream control block compared against the argument to identify the stderr stream (v1 = 1 slot) |
| 00fb8350 | dword_FB8350 | W | Counter incremented once per successful stdout/stderr identification, just before the buffer allocation attempt |

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 00634c1d | _malloc | Allocates the 4096-byte (0x1000) stream buffer when no cached buffer exists for this stream |
| 006417ac | __isatty | Tests the descriptor at stream offset 0x10; nonzero result is required to proceed with console buffering |

**Guard conditions:** `_isatty(fd)` must be nonzero → otherwise return 0 (stream is not a console). The stream must equal either unk_912DF0 (v1 = 0) or unk_912E10 (v1 = 1); any other pointer returns 0. After bumping the counter, if `*(WORD*)(this+0xC) & 0x10C` is nonzero → return 0 (stream already has its buffering/status bits set). Allocation: if the cached buffer-pointer slot already holds a value, or `malloc(0x1000)` succeeds → 4096-byte heap buffer; otherwise → 2-byte inline buffer at this+20. On success the flags are OR'd with 0x1102 and the function returns 1.
