## sub_5E5650_005e5650 — set/clear flag bit 0x20

**Summary:** Reads the flags dword at this+0, sets bit 0x20 when the argument is non-zero or clears it when zero, writes the result back, and returns it. Same shape as sub_5E5190 for a different bit.

**Called by:** sub_411100 (00411100)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | RW | — | flags dword; bit 0x20 is toggled to match the argument and the updated dword is returned |

**Written-by note (persistence):**
- this 0x0: rewritten unconditionally on every call, but only bit 0x20 changes — an external poke to other bits survives; a poke to bit 0x20 is overwritten on the next call.
