## sub_6A6F97_006a6f97 — BindPs14PhaseSlots

**Summary:** Prepares the two six-entry ps_1_4 slot arrays: splits the collected special-object index list (this+0x450, count this+0x480) into a special list (bits set in a2) and a regular list while enforcing per-list constraints, binds both lists into the slot arrays at 0x22C/0x230 through six sub_6A6DC1 passes (modes 0, 1, 2), then, when a3 == 0, rewrites dependent-read instructions to use freshly allocated registers. Returns 1 on success, 0 on any constraint violation or binding failure.
