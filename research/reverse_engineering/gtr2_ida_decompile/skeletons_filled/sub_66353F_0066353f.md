## sub_66353F_0066353f — Grid layout consistency check for element index arrays

**Guard conditions:** If a3 != 2, immediately returns (a4 == 1). If a5*a4 == 0 the body is skipped and 0 is returned. Row pass: mismatch of element[1] (resource id) between adjacent row cells → return 1; placement mismatch (resource flag 0x40: element[3]+(col>>2) and element[4]+(col&3) must equal the next element's [3]/[4]; otherwise element[18] must be equal) → return 1. Column pass: any of the same mismatches → return 0; if a4 == 0 → return 1; after all rows/columns pass → return 1.
