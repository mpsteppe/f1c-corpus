## sub_6863CE_006863ce — bucket adjacency build with sort/dedupe

**Summary:** Rebuilds per-bucket adjacency lists: clears all four list slots per bucket, counts edges by walking each bucket's node lists with sub_686341, allocates arrays with sub_681169 (returning 0x8007000E E_OUTOFMEMORY on failure) sized by the counted values, re-walks to fill them, then sorts each list with sub_682274 using comparator sub_6CD35F and compacts adjacent duplicates, storing the unique counts. Calls sub_686074 as a pre-step and returns 0 on success.

**Called by:** sub_68C799 (0068c799), sub_6C3EEA (006c3eea)

**Guard conditions:** Bucket loops run only for this[3] != 0. Edge counting/filling happens only for buckets whose *(WORD*)(bucket+2) & 0xFFF0 != 0. In the walk, list entries == -1 are skipped, and an entry is redirected to node[entry]+0x38 when that field != -1. Allocation happens only when the respective count (+0x14 or +0x1C) is nonzero; both allocations reset their count to 0 before the fill pass and return 0x8007000E on a null result. Sort/dedupe runs only when the (refilled) count != 0; final counts are replaced by the unique-entry totals; everything else returns 0.
