## sub_6462BB_006462bb — Buffered stream writer (Write)

**Summary:** Writes `a3` bytes from `lpBuffer` into the object's output stream, dispatching on a mode field: mode 1 stages data through a 64 KB (0x10000) buffer and flushes staged blocks to a Win32 file handle with WriteFile; mode 2 copies into a growable in-memory buffer accessed through a virtual interface. Returns 0 on success or 0x80004005 (E_FAIL) on write/allocation failure.

**Called by:** sub_64719B (0064719b), sub_647A8C (00647a8c), sub_647AC0 (00647ac0), sub_6481DD (006481dd), sub_648560 (00648560), sub_649048 (00649048), sub_64970E (0064970e), sub_649862 (00649862)

**Written-by note (persistence):**
- this 0x1C: written on every mode-1 write call (incremented on append, reset to 0 or to the tail remainder during flush); not recomputed elsewhere, so an external poke survives until the next write to this stream.
- this 0x20: only ever incremented (`+=`) inside the write paths, never recomputed from scratch; an external poke survives until the next write, and subsequent counts continue from the poked value.

**Guard conditions:** Mode field this+0x10 read into v5: if 0 → early `return 0` (silent no-op, nothing written). If 1 → buffered path; when fill(0x1C)+a3 > 0x10000 it flushes full 0x10000 blocks with WriteFile and memcpys the remainder back into the staging buffer; a WriteFile failure returns -2147467259 (0x80004005, E_FAIL); otherwise plain memcpy append and fill += a3. If 2 → memory path: if total(0x20)+a3 ≤ virtual capacity → direct memcpy at buffer+total; else grow target = max(total+a3, 2×capacity) via sub_677187; growth result < 0 → that failure is returned; then memcpy and total += a3. Any other mode value → return 0x80004005. In all success paths *lpNumberOfBytesWritten = a3 (or the flushed block size) and 0 is returned.
