## sub_56DF50_0056df50 — release tracked object by ID across lists

**Summary:** Lazily initialises a record (a2) on first use, then searches three global object lists for the record's ID and releases the matching slot with a swap-remove against a global index bookkeeping array; if no slot matches or the slot is already free, falls back to a secondary registration/release helper. Returns the matched slot/index value as a char.

**Called by:** sub_572490 (00572490), sub_57BDB0 (0057bdb0), sub_57BE70 (0057be70)

**Guard conditions:** Several gates: (1) first dword of a2 must be non-zero, else immediate return. (2) the byte at a2+64 must be 0 to run the initialisation block; if already 1 the whole body is skipped (returns the record ID dword as char). (3) the list-search only runs when the global mode dword (dword_BE1204) != 2; per-list count checks (algn_91BF9C[52], [64], [76]) skip empty lists, and all-empty returns 0. (4) a match releases its slot only if the slot dword != -1; slot == -1 or no match falls through to the fallback helper (sub_52F560) path instead of the removal helper (sub_52F4B0).
