## sub_5454B0_005454b0 — ParseSurfaceMaterial

**Summary:** Parses one track-surface (material) definition entry: boolean/value keywords (LEGAL, RUMBLE, WET, BUMPAMP, BUMPWAVELEN, SINK), flag keywords (SPARKS, SCRAPING, WALLSKIDS), and a SOUND material-name dispatch that selects three sound/effect ids (RUMBLE, WET, DIRT, GRASS, GRAVEL, TIREWALL, SOLIDWALL, GUARDRAIL, etc.). Values are stored into the object and the accumulated string is uppercased, whitespace/comma-normalized and returned.

**Guard conditions:** Every field write is gated by a keyword-presence test: sub_5429C0/sub_6137E0/sub_613240 must return nonzero, otherwise the field is left untouched. this+0x5C is additionally gated on the parsed value comparing equal to 'TRUE' (case-insensitive). The SOUND dispatch runs only when sub_6137E0 matched, and within it the first matching name sets all three ids — a 4-byte name check (→18/35/41), then WET (→19/36/41), DIRT (→21/38/46), GRASS (→20/37/46), GRAVEL (→22/39/46), RUMBLE (→23/35/41), TIREWALL (→46/46/46), SOLIDWALL or GUARDRAIL (→41/41/41); names that match nothing leave the ids unchanged. The final normalization (uppercase, drop spaces, collapse duplicate commas) runs only when sub_6131C0 returns nonzero.
