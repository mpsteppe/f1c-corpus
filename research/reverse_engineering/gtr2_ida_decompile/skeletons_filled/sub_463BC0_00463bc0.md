## sub_463BC0_00463bc0 — mouse recenter and relative/absolute position update

**Summary:** Warps the OS cursor to the window-rectangle centre (SetCursorPos), computes the pending deltas from the stored position against that centre, then updates the object's cursor state: byte at 0xC0 == 0 clamps the new x/y into the stored bounds (absolute mode); nonzero instead re-centres the tracked position and warps the cursor to that centre (relative/captured mode). Finally recomputes the scaled outputs at 0x28/0x2C from the scale factors at 0x20/0x24. Returns the x delta.

**Guard interpretation:** The whole update first requires cursor movement: if the Rect centre equals the stored x and the y delta is zero, only the unconditional stores run (this[4]/this[5] = bounds centres, this[6]/this[7] = 0) and 0x28/0x2C are left alone. With movement, the 0xC0 test splits the paths: ==0 stores the raw centre coordinates (v6/v5) as the new position, then clamps them into [this[2],this[3]] and [*this,this[1]]; !=0 ignores the raw centre and sets the position back to the bounds centre ((max+min+1)/2) and re-warps the OS cursor there. Both paths finish by recomputing the scaled outputs; the return value is the x delta captured before the branch.
