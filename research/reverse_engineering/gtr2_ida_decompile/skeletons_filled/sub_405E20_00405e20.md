## sub_405E20_00405e20 — Compute named node's animated displacement over a time interval

**Summary:** Scans the node list at this+0x20 for the entry whose name (entry+4) matches the requested string, samples that node's embedded track at time 0.0 and again at time this+0x14, and writes the per-axis delta (position at t minus position at 0) into the 3-float output. Output is zeroed first if no matching entry with keyframes is found. System: engine animation evaluation.

**Called by:** sub_4F4510 (004f4510), sub_4F4930 (004f4930)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x14 | R | — | Sample time (a1[5]) — second track sample point for the delta |
| this | 0x18 | R | — | Node count (a1[6]) bounding the name-search loop |
| this | 0x20 | R | — | Pointer (a1[8]) to the array of node entries scanned for the name |

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 004058b0 | sub_4058B0 | Samples the node's embedded track at 0.0 and at the requested time to get start/end positions |
| 00631c0d | __stricmp | Case-insensitive comparison of each entry name (entry+4) against the target name |

**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|
| this | 0x18 | > | 0 | Node count must be positive for the search loop to run |

**Guard interpretation:** Count (this+0x18) <= 0 BLOCKS everything — output stays zeroed. If the loop completes without a name hit (`v3 == count`), no sampling occurs and the zeroed output is returned. When matched, sampling/marking is further gated on the found entry's keyframe count (`v6 > 0`); only then are both sub_4058B0 samples taken and the x/y/z delta written to the output.
