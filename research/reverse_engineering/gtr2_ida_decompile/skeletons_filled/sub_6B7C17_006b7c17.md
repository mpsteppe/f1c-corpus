## sub_6B7C17_006b7c17 — Flush interlaced scanline block into IDAT stream

**Summary:** PNG row-flush step: counts consumed rows in this+0xD4; when a full pass/block is done it advances the interlace pass (0x114, up to 7 passes), recomputes per-pass dimensions from the pass tables, and clears the pass buffer, then runs the compression step, raises "zlib error" on failure, emits pending compressed data as an IDAT chunk, and finalizes the codec stream.

**Guard interpretation:** The block-completion body runs only when the incremented row counter this->0xD4 reaches this->0xC0. Inside the pass-scan loop, the pass buffer clear is reached only when the computed this->0xC4 (columns) is nonzero AND the computed row count is nonzero (both checked): if 0xC4 == 0 the pass is empty, LABEL_8 is BLOCKED and the loop advances to the next pass (also blocked once the pass index reaches 7). On the codec path, status >= 2 triggers the fatal "zlib error" raise, status 0 emits an IDAT chunk (only when this->0x74 == 0), and the loop exits on status 1.
