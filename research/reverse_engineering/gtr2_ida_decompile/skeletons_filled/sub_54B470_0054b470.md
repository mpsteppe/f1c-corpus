## sub_54B470_0054b470 — Savegame/window name builder from game mode and session type

**Summary:** Builds the game's savegame window name by appending a mode tag (ARCADE, or ARC/PRO/SIM selected by mode flag) and a session-type tag (PRACT, QUICK, WEEKEND/24H, CHAMP, MULTI, TIMET) into the global string buffer WindowName, then formats the final result as "Game%s%s" (WindowName + ".sve") via the sprintf-style helper sub_632041. This is the naming engine for per-mode savegame files.

**Guard conditions:** 
- `byte_B722CC != 0` → arcade path: appends "ARCADE" and SKIPS the entire mode selector and session-type switch.
- Otherwise mode selector dword_B72338: `== 0` → "ARC"; `== 1` → off_71EE7C; any other value → unk_71EE80.
- Then switch on `*(DWORD*)dword_B72314`: 1 → "PRACT"; 2 → "QUICK"; 3 → `byte_B722E4 ? off_71EE64 : "WEEKEND"`; 4 → "CHAMP"; 5 → "MULTI"; 7 → "TIMET"; default (0, 6, ≥8) → nothing appended.
- Final format call runs unconditionally on all paths.
