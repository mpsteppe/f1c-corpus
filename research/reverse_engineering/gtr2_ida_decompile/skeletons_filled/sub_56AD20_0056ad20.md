## sub_56AD20_0056ad20 — Multi-condition state predicate (slots + entry scan)

**Summary:** Read-only predicate over a large object: immediately accepts if either of two "dword set but its byte flag clear" pairs holds (0x670/0x6B0, 0x6B4/0x6F4); otherwise it counts nonzero first-bytes of up to 4 slots (stride 296) starting at 0x210 and, only if at least 4 are nonzero, scans up to 8 entries (stride 68) at 0x6F8, rejecting only if every entry has dword == 0 or byte +64 nonzero. **Guard conditions:** Early accept: if `(*(this+0x670) && !*(this+0x6B0)) || (*(this+0x6B4) && !*(this+0x6F4))` the function returns 1 immediately. Slot scan: starting at this+0x210 with stride 296, the loop continues only while the slot's first byte is nonzero; it increments a counter and, once the counter reaches 4, breaks to the entry scan. If the slot loop ends first (a zero first byte before 4 slots were counted), it returns 1. Entry scan: starting at this+0x6F8 with stride 68, it iterates while `entry.dword == 0 || entry.byte[+64] != 0`; if it manages 8 iterations it returns 0; if an entry has dword != 0 AND byte+64 == 0 it exits and returns 1. Net: returns 0 only when ≥4 slots are nonzero AND no qualifying entry is found among the first 8; any other case returns 1.
