## sub_5E5B70_005e5b70 — Mode-bit setter (0x1000/0x2000)

**Summary:** Updates a packed flags dword at *this so its 0x1000/0x2000 bit pair encodes the requested mode a2: 4096 (0x1000) selects bit 12, 0x2000 selects bit 13, clearing the other; any other value performs no store.

**Called by:** sub_4102A0 (004102a0), sub_411260 (00411260), sub_412060 (00412060)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | RW | — | Packed flag dword; bits 12/13 (0x1000/0x2000) hold a two-state mode, all other bits preserved by mask 0xFFFFCFFF |

**Written-by note (persistence):**
- this 0x0: Conditional write — stored only when a2 equals 4096 or 0x2000; any other a2 leaves the dword untouched. An external poke therefore survives calls made with other values and is overwritten only when one of the two matching modes is requested.

**Guard conditions:** `a2 == 4096` → stores `(*this & 0xFFFFCFFF) | 0x1000` (bit 12 set, bit 13 cleared). Else `a2 == 0x2000` → stores `(*this & 0xFFFFCFFF) | 0x2000`. Else no store; the function merely returns a2 unchanged (return value is a2 in the first and fall-through paths, the new dword value in the 0x2000 path).
