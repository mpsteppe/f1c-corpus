## sub_6866FF_006866ff — format object label (name + owner id)

**Summary:** Builds a text label in buffer a3 (size a4) for the object referenced by a2: writes the object's name string with a snprintf-style call (sub_632041), using the "%s" format normally or the off_73D088 format when the name is empty or its second byte is nonzero; then appends either "?" (when the id at +0xC is -1) or the unsigned id at +0xC of node a2 or its owner (a2+0x38). Force-terminates the buffer at a3+a4-1 and returns the second call's result.
