## sub_545B60_00545b60 — Special-effect emission loop (per-car)

**Summary:** Iterates a list of effect entries (count at context+56, array at context+60), and per entry type (0, 2, 6, 20) spawns jittered effect instances via sub_543B10/sub_5438E0 using a shared emission state (last position/time at this+0x38..0x44 and density values at this+0x28..0x30). Emissions are throttled by frame counters, mode flags and a position/time debounce.

**Guard conditions:** The entire loop is skipped (immediate tail-call) unless sub_5210F0() is true and the entry count at context+56 is > 0. Per entry: type 0 is BLOCKED when this+0x2C == 0.0 or when (dword_B7129C <= 2 and dword_BE1204 != 2 and dword_91E230 % 20 != 0); type 2 uses the same rule with this+0x28; types 6/20 are BLOCKED when this+0x30 == 0.0 (type 6 additionally needs dword_B7129C > 1, dword_BE1204 == 2 or counter % 20 == 0; type 20 also needs sub_542540 true, and passes only when sub_542CD0 is false). Types 0/2 are additionally debounced by PASSING only when |a2 - this+0x44| > 0.15 or the squared XY distance from the last emission > 1.0; the target id (-1 / a6 / 104) is chosen from byte_B71410 and byte_B71428.
