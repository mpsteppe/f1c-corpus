**Guard conditions:** The season-GDB block runs only when SeasonRacesSectionFinder(0) returns non-zero; inside it each line is printed only when its key exists ("Location", "First Grand Prix", "Length" always, "RaceLaps" only when the session index != 4, "Track Record" only when present). Track Record tokens are copied into 48-byte rows, the count is capped at 4, and the remaining rows are printed only when more than one token was found. After that, sub_53A7E0(&v54,&v53,&v52,0) == true selects the championship branch, where each status line appears only when its value is positive (v53 > 0, v52 > 0, v54 > 0). When sub_53A7E0 returns false, the records list is walked from dword_B7630C: an entry is used only when its name (entry+8, or WindowName) matches the current track name, the best-time update additionally requires (v47 > entry[8] or v47 == -1.0) AND entry[8] != 0.0 AND dword_B72338 == entry[6]; a missing time prints "-:--.---" instead of "%i:%06.3f".
