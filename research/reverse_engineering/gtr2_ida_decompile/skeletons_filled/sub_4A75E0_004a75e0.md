## sub_4A75E0_004a75e0 — folder-list panel renderer (bitmap rows + highlight overlay)

**Summary:** Draws a list/panel of "folder" bitmap rows: loads the two folder sprites (G_Folder0000.bmp / G_Folder0100.bmp), loops over entries computing row positions from stored layout fields, draws a sprite per row via sub_4D5E10, and — when the flag at this+0x254 is set — draws an extra segment/highlight for the row that intersects the current cursor/selection using line-drawing primitives. Clears the flag afterwards.
