## sub_5D89B0_005d89b0 — Build 3-vector from scalar via indexed transform (mode 3)

**Summary:** Builds a 3-component float vector at `a3` from scalar `a1` and flag word `a2`: a mode-3 transform (sub_5E86C0) expands the scalar into three components, indexed factors from sub_6006C0 scale each axis componentwise, and a flag bit optionally applies an extra overall scale (v7). With `a2 == NULL` the input triple is zeroed.

**Guard conditions:** `v7 = sub_600770(2)` runs unconditionally. If `a2 == NULL` the input triple is zeroed (a1=v5=v6=0) and no transform is done — output collapses to zero. When `a2 != NULL`, flag test `(*a2 & 0x08000000) == 0` BLOCKS the extra scaling; when the bit is set, a1, v5, v6 are each multiplied by v7. Output = componentwise product of per-axis factors (v8,v9,v10) and the (possibly zeroed/scaled) components.
