## sub_6DA010_006da010 — compress_block — emit literals/matches

**Summary:** Emits the pending literal/match pair buffer of the current block as a DEFLATE block body: for each entry, distance 0 sends the literal code from the passed ltree; otherwise sends the length code (via _length_code) plus extra length bits, then the distance code (via _dist_code) plus extra distance bits. Finishes by sending the end-of-block code from ltree and storing its bit length in the field at 0x16AC. Matches zlib's compress_block.

**Called by:** sub_6DAAC0 (006daac0)

- this 0x16AC: written once per call (end-of-block bit length); an external poke is overwritten on the next call.
- this 0x16B0: rewritten continuously — OR of every emitted code plus flushes; an external poke is consumed by the next emitted field.
- this 0x16B4: recalculated per emitted field (plus width, minus 16 or width on flushes); an external poke changes only the base and is superseded by the next update.

**Guard conditions:** The whole loop is skipped when the pending count (0x1698) == 0. Per entry: the distance word (0x169C) == 0 takes the literal path → single ltree[byte].code emit; nonzero takes the match path → length code ltree[257+_length_code[byte]], extra length bits only when extra_lbits[code] != 0 (value = length - base_length[code]), then distance code dtree[_dist_code[dist-1]] and extra distance bits only when extra_dbits[code] != 0 (value = (dist-1) - base_dist[code]). Every field emission checks free bits (0x16B4) <= 16 - field_len before accumulating; otherwise both accumulator bytes are flushed through the 0x8 buffer/0x14 counter and the value is shifted again. After the loop, ltree[256] (end-of-block) is always sent and its bit length stored to 0x16AC.
