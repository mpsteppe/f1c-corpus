## sub_6B7E46_006b7e46 — Adaptive PNG row filter selection and emit

**Summary:** PNG per-row filter stage: computes filtered candidate scanlines for the enabled filters (None/Sub/Up/Average/Paeth) from the current (0xDC) and previous (0xD8) rows, optionally cost-weights them through gamma-style tables when mode 0x180 == 2, selects the minimum-sum candidate (or the forced filter when 0x115 names one), updates the filter history, and feeds the winning buffer to the deflate step (sub_6B7D98). a2 supplies the row size (+4) and pixel depth (+0xB).

**Guard interpretation:** When this->0x180 == 2, every candidate sum is post-processed with the u16 weight tables (0x184/0x188/0x190/0x194) before comparing — the PASS path applies weighting; when it is any other value the raw byte sums are compared and the weighting blocks are BLOCKED (skipped). Selection itself is driven by this->0x115: an exact single value (8/16/32/64/0x80) forces that filter's output directly; with several bits set every enabled candidate's sum is computed and the minimum wins (the Paeth buffer 0xEC also persists as the starting minimum when bit 0x80 is set). After selection the filter history at 0x184 is shifted forward and the chosen buffer's tag byte is appended when this->0x181 is nonzero, then the row is handed to sub_6B7D98.
