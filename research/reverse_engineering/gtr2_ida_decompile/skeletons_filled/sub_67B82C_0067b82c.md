## sub_67B82C_0067b82c — row shift transform (reduce sample precision)

**Summary:** Right-shifts the sample values of one decoded image row by per-channel true-bit counts taken from a 5-byte color struct (red/green/blue/gray/alpha), implementing the "shift to fewer bits" read transformation for 2/4/8/16-bit depths. Palette rows are skipped, and rows whose every channel shift is already 0 are left untouched.

**Guard conditions:** If the color type byte at this+8 equals 3 (palette) the function returns immediately without touching the row. Otherwise the shifts are computed as (bit depth − true bits) for each channel: three shifts from a3[0..2] for RGB rows (color type bit 2), one shift from a3[3] for gray rows, plus one from a3[4] when the alpha bit (bit 4) is set. Any computed shift ≤ 0 is clamped to 0; if no channel ended up with a positive shift no data is modified. With at least one positive shift the row is processed by depth: 2-bit packed pixels via `(byte >> 1) & 0x55`, 4-bit packed pixels via mask/shift, 8-bit samples shifted per channel across the whole width, and 16-bit big-endian samples shifted as 16-bit values.
