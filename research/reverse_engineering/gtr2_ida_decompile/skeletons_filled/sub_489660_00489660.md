## sub_489660_00489660 — FinalizeStartupAndSwitchWindow

**Summary:** Startup finalizer: initializes the Game Filter field, starts and waits for the UI thread (sub_4887A0), then — if the window-state field this+0x350 isn't already 3 — positions the helper dialog (dword_B6CE6C) over the state-mapped window, shows the helper and hides the old window, records state 3, and destroys the startup/loading window (dwInitParam). Returns 1.

**Called by:** sub_489700 (00489700)

**Guard conditions:** The window-swap block runs only when `this[212] != 3` (state already 3 → skipped). Inside, the helper window is repositioned only if the decompiler's `v6` condition holds (`GetWindowRect` + `SetWindowPos`); the helper is shown (`ShowWindow(v4,5)`) only if v4 (dword_B6CE6C) is nonzero, and the old state window hidden (`ShowWindow(v5,0)`) only if v5 is nonzero; then state is set to 3. The startup window is destroyed only when `dwInitParam != 0`, and it is then zeroed. Function always returns 1.
