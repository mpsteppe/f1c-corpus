## sub_4D3E00_004d3e00 — AdvanceProgressValue

**Summary:** Progress/timer step: increments the counter at 0x22C, runs the update step sub_4D0B20(this), then recomputes 0x230 as round(0x22C / 0x240 × 0x234) — or 0 when the divisor at 0x240 is zero; always returns 0. Increment twin of sub_4D3DA0.

**Called by:** sub_4D4540 (004d4540), sub_4D4750 (004d4750), sub_4D4870 (004d4870)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x22C | R | — | counter incremented by one at entry; the ratio numerator |
| this | 0x230 | RW | 0 | computed progress value: 0 when 0x240 is 0, else rounded 0x22C/0x240 × 0x234 |
| this | 0x234 | R | — | multiplier applied to the 0x22C/0x240 ratio |
| this | 0x240 | R | — | divisor; zero → 0x230 forced to 0 (no division) |

**Written-by note (persistence):**
- this 0x230: recalculated on every call (or zeroed when the divisor is 0); an external poke survives only until the next call.

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|
| 006f16c8 | flt_6F16C8 | R | float constant involved in the 0x230 progress computation |

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 004d0b20 | sub_4D0B20 | update step run on this before the progress value is recomputed |
| 0063099c | __ftol2 | compiler runtime helper converting the rounded double result to int for storage at 0x230 |

**Guard conditions:** If this+0x240 == 0 → 0x230 is left/set to 0 (division skipped). If non-zero → 0x230 = ftol(0x22C/0x240 × 0x234 + 0.5) using the incremented 0x22C. No early returns; always returns 0.
