## sub_64653C_0064653c — Surface descriptor assign/copy (format-aware masking)

**Summary:** Copies a surface/pixel-buffer descriptor from a source object into this one: releases old owned buffers, steals the source's buffer pointers and format code, copies a block of dimension fields, masks two dimension fields according to the pixel-format FourCC (DXT vs packed-YUV formats), and recomputes derived spans. Returns 0.

**Guard interpretation:** The format code at +0x0 controls only the masking of +0x18/+0x1C. PASSES to 2-bit clearing (~3 on both +0x18 and +0x1C): codes 827611204 ("DXT1"), 844388420 ("DXT2"), 861165636 ("DXT3"), 877942852 ("DXT4"), 894720068 ("DXT5"). Also gated earlier: the +0x4/+0x8 buffers are freed only when both the pointer and its ownership flag (+0x38/+0x3C) are nonzero, and both ownership flags are always cleared to 0 at the end; the function has no failure path and always returns 0 after recomputing the spans at +0xC/+0x10/+0x14.
