**Guard conditions:** Dispatch on `*(this+0x330)`: only 471, 472, 475, 476, 479, 480, 486-495 and 501 are handled; any other id returns the id unchanged (default: early return). Event 476 requires ALL of: `sub_4735A0()` truthy, `sub_4DE2F0(this[12]) == this` (this object owns the field), `this[199] != 0` and `strlen(text) > 0`; length is capped at 159. Event 501 requires `sub_4DE2F0(this[12]) == this`, `this[199] != 0` and `strlen(text) > 0`; only then CINet::Chat is called.
