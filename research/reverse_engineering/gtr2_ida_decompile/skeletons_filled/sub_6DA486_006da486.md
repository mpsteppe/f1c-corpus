## sub_6DA486_006da486 — bi_windup — byte-align the bit stream

**Summary:** Flushes the deflate bit accumulator to a byte boundary: with more than 8 pending bits it writes both accumulator bytes, with 1..8 pending bits it writes one byte, and finally always clears the accumulator and the bit count. Used before stored blocks / at end of stream; called by sub_6DA4DD (copy_block) and sub_6DAAC0 (flush dispatcher).

**Called by:** sub_6DA4DD (006da4dd), sub_6DAAC0 (006daac0)

**Guard conditions:** bit count (0x16B4) > 8 → write both accumulator bytes (counter += 2); 0 < count <= 8 → write the low byte only (counter += 1); count == 0 → nothing written. In all cases accumulator word (0x16B0) and bit count (0x16B4) end at 0, aligning the stream to a byte boundary. Returns the state pointer passed in (EAX).
