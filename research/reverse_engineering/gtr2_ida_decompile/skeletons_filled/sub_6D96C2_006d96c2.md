## sub_6D96C2_006d96c2 — Huffman bit-length computation (gen_bitlen)

**Summary:** Computes optimal code bit lengths for a Huffman tree being built: walks the heap from heap_max+1 up to entry 572 assigning each node Len = (parent's Len)+1, clamped to max_length with an overflow count, accumulates opt_len and static_len including extra bits, then redistributes the overflow through bl_count and rescans the heap to write the final lengths. Structure matches zlib deflate's gen_bitlen.

**Guard conditions:** a2 (the deflate-state-like block) is what gets mutated. The 32 bytes at a2+2868 (16-word bl_count) are cleared first; tree[heap[heap_max]].Len is set to 0 (root). Main pass runs only if heap_max+1 < 573, iterating a2's heap at a2[725+idx] (heap_max itself is a2[1299]). Per node: bits = parent Len+1; if bits > max_length (0x18) then bits = cap and overflow++; node index <= max_code (0x4) is a leaf, so bl_count[bits]++, xbits applied when >= base (0x10), opt_len (a2[1448]) += freq*(bits+xbits), static_len (a2[1449]) += freq*(xbits+stree Len) only when the static tree (0x8) is non-null. If overflow != 0: loop { find highest nonzero bl_count below max_length, bl_count[bits]--, bl_count[bits+1] += 2, bl_count[max_length]--, overflow -= 2 } until overflow <= 0. Then, if max_length != 0: for bits = max_length down to 1, consuming bl_count[bits] entries while walking the heap backwards; nodes with index > max_code are skipped; a node whose stored Len != bits gets opt_len += freq*(bits-Len) and Len = bits.
