**Guard conditions:** The opponent count v47 comes from "Opponents" via atol: < 0 → 0; > 103 → 103, otherwise unchanged (the same 103 is the slot loop bound). During slot initialization, an entry is only mapped to a vehicle descriptor when its index is < dword_BE1BD4. The loop runs while the candidate count v42 > 0 and stops once v28 >= v39.
