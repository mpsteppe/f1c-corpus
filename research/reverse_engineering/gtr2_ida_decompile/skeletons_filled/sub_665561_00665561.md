## sub_665561_00665561 — Elementwise asin/acos evaluator (bulk lanes)

**Summary:** Evaluates the builtin inverse-trig function elementwise over an array of register ids: either dispatches to the native VM opcodes 0x10A00000/0x10B00000 for the outputs a4/a5, or runs an explicit polynomial implementation (the classic arcsin approximation with coefficients -0.0187293, 0.0742610, -0.2121144, 1.5707288 plus -2, π and π/2) over 28 scratch lane buffers chained through sub_6641F3. Returns 0 or a negative error (0x8007000E when the scratch allocation fails).
