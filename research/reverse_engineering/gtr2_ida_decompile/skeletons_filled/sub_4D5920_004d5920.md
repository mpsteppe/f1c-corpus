## sub_4D5920_004d5920 — Item-list text renderer (hover-aware, color-coded)

**Summary:** Walks a linked list of items (count at a2+12, payload nodes linked through +4) and draws each item's text name with per-item colors: an optional item flag at +44 selects a hit-test path (sub_4D3810 against screen metrics) that switches between normal, highlighted, and fallback color pairs taken from this+0x138..0x154; the text is emitted via sub_568D20 with coordinates scaled by this+0x148 and global screen constants.

**Called by:** (none static — top-level or indirect-only)

**Guard conditions:** The whole loop is gated by count *(a2+12) > 0; per iteration index v4 must satisfy 0 <= v4 < count and the list head/node pointers must be non-null (a null node yields v6 = 0 and the item is still rendered, name defaulting to WindowName). If the item's +44 flag is set, drawing uses the hit-test branch: sub_4D3810(v6, v14, v13) must return non-zero to keep the highlighted pair (this+0x140/0x154); on failure the fallback pair this+0x138/0x14C is used. When +44 is clear, the normal pair this+0x13C/0x150 is used and the hit-test is skipped.
