## sub_67C5F0_0067c5f0 — BuildColorTransformLUTs

**Summary:** Builds gamma/scale color-transform lookup tables for a texture image object: for source depth >8bpp it allocates the row-pointer table at 0x144 and fills 16-bit LUT rows (bit-reduction count stored at 0x12C), otherwise it builds a single 256-entry 8-bit LUT at 0x138. Both paths derive their values from the gamma exponent at 0x130 and the scale factor at 0x134.

**Called by:** TextureImageColorTransform [structural] (0067c8f7)

| this | 0x117 | > | 8 | source color depth in bits; above 8 selects the 16-bit LUT path |

**Guard interpretation:** When this+0x117 > 8 the high-depth branch runs (allocates the 0x144 row table and 16-bit rows, stores the shift count in 0x12C); when <= 8 the code takes the else-branch and builds the single 256-entry 8-bit LUT at 0x138. Either branch only executes at all when this+0x130 (gamma) is non-zero.
