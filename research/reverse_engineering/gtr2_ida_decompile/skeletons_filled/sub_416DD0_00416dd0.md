## sub_416DD0_00416DD0 — Per-element float update with mode/time gating

**Summary:** Applies a float argument to every element of a managed list via sub_416370, and conditionally issues per-element refresh calls (sub_416B10) when a global mode (dword_BE1204) is 1 and a 0.3 time-delta window has elapsed; in mode 2 it instead sweeps a global entry array (stride 22616, up to 105 entries) applying the same value.

**Called by:** sub_42EF60 (0042ef60)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | R | — | element count; bounds every per-element loop (also tested `<= 0`) |
| this | 0x8 | R | — | pointer to the array of element pointers (this[2]) |
| this | 0x7C | RW | — | last-update timestamp (float); compared against a2 with the 0.3 hysteresis before being rewritten |

**Written-by note (persistence):**
- this 0x7C: written only when dword_BE1204 == 1 AND a2 exceeds the stored value by more than 0.3 — a poke survives otherwise, and is overwritten by a2 whenever the time-gated branch triggers.

**Guard interpretation:** Branching on dword_BE1204: == 2 → global sweep over the registry while dword_920480 < 105. Otherwise, per-element loop runs while i < *this (PASSES only for count > 0); after it, if dword_BE1204 == 1 and stored timer this->0x7C + 0.3 < a2 → the timer is rewritten and elements whose per-element mode field (+0x20) != 7 get sub_416B10 (the flagged ones with +0x0C == 1 are skipped). If the time gate does NOT trigger → plain loop where elements with +0x20 != 7 AND +0x0C != 1 get sub_416B10.
