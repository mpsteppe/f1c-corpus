## sub_6B7D98_006b7d98 — Deflate one input row and manage IDAT emission

**Summary:** Feeds one input row/buffer (a2) into the compression state at this+0x64 and pumps the codec until the input is consumed, emitting an IDAT chunk whenever new compressed data is pending, swapping the alternating pass buffers, flushing via sub_6B7C17, and — once the incremented row counter reaches the threshold at 0x124 — triggering the full chunk flush.

**Called by:** sub_6B7E46 (006b7e46)

**Written-by note (persistence):**
- this 0x64: written unconditionally on every call (from a2); external poke overwritten immediately
- this 0x68: written unconditionally on every call (0xF4 + 1); external poke overwritten immediately
- this 0x70: written only when new IDAT data is emitted (conditional on 0x74 == 0); poke survives until next emission
- this 0x74: written only when new IDAT data is emitted; poke survives until next emission
- this 0xD8: swapped with 0xDC only when it is nonzero; a zero value stays put, otherwise recalculated each call
- this 0xDC: written only as the counterpart of the 0xD8 swap; otherwise untouched

**Guard conditions:** Pump loop continues while the codec's remaining-input count (this+0x68) is nonzero — i.e. until the row is fully consumed; each nonzero status from sub_6B8942 raises the stored error and then "zlib error" (BLOCKED path = fatal error). IDAT emission is guarded by `this->0x74 == 0` (no pending block written yet). The buffer swap at 0xD8/0xDC only happens when this->0xD8 is nonzero. The final flush is gated: only when the threshold this->0x124 is nonzero AND the incremented this->0x128 counter >= that threshold does sub_67A35B run; otherwise the function returns the new counter value.
