## sub_4898F0_004898f0 — ListFindLastUnflaggedNode

**Summary:** Linked-list walker: starting from `this`, follows the next pointer at offset 0 while the flag byte at offset 0x15 of the next node is zero, and returns the last node visited before the first flagged node. Companion traversal for the list destructor that uses the same +0x15 stop flag.

**Guard conditions:** If the node at `*this` already has its +0x15 flag set, the loop is skipped and `this` itself is returned (BLOCKED — no advancement). Otherwise the walk advances (`v2 = *v2`) until it reaches a node whose +0x15 flag is nonzero, returning the previous node (the flagged node itself is never returned).
