## sub_5C5F20_005c5f20 — repositioning-node resolver (descriptor variant, with SEH cleanup)

**Summary:** Variant of the repositioning-node resolver: it queries the source descriptor `a3` (vtable slot +4 for a 4-byte field, then `sub_5BE610` to extract the node name/descriptor into locals), logs the node name and Position/Rotation/Scale mask when verbose (`this + 0xC`), looks the node up by name inside actor `a4`, and on success stores the node pointer at `a4+528` and a computed mask at `a4+548`. Returns 1 for a valid actor, 0 otherwise (logging `"Passed actor seems to be not valid!"` when verbose).
