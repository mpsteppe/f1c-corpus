## __write_lk_00638633 — Low-level file write (CRT _write core)

**Guard conditions:** If `nNumberOfBytesToWrite == 0` → returns 0 immediately (nothing to write). Descriptor flags byte: if `flags & 0x20` (append mode) → seek to end before writing. If the flags byte has its high bit set (text mode) → take the translation loop that expands each '\n' to '\r\n' in 1024-byte chunks, counting inserted CRs in v12; each chunk is written with WriteFile, and the loop stops when a short write occurs or all input is consumed. Otherwise → single direct WriteFile of the whole buffer. Error handling: on WriteFile failure, `LastError = GetLastError()`; if any bytes were written, returns `bytesWritten - insertedCRs`; if LastError == 5 → errno=9, doserrno=5; other errors → _dosmaperr. If nothing was written and no error: if `flags & 0x40` is set and the first buffer byte is 26 (Ctrl-Z) → returns 0; else errno=28, doserrno=0, returns -1.
