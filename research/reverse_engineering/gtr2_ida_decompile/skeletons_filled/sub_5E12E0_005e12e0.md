## sub_5E12E0_005e12e0 — ParseMeshInstanceBlock

**Summary:** Parses one scene-description block (a token stream consumed via sub_5DF240/sub_5DF630/sub_5DF0E0 keyword readers) and builds/initializes a 0x28C-byte renderable node: allocates the node, loads a MESHFILE, applies visibility/render/shadow/reflect/actor flags and orientation, then attaches it to the parent. Recurses for nested INSTANCE blocks; used by the object-placement parser system.

**Guard conditions:** 
- `sub_5DF750(a5) != 1` gates the entire parse loop: if the token stream is already finished (state 1), no parsing happens and the node proceeds to attach/finalize.
- Loop continues `while (*a5 != 3)`; `sub_5DF750(a5) == 1` breaks it. Token 3 = block end.
- Integer handle from strtol is rejected when `(v9 & dword_FB2318) != v9` → remaining tokens are drained, node destroyed (sub_5DBA90 + free), return 0.
- INSTANCE / LIGHT / PROJECTOR: if the keyword matched and the sub-parser returns nonzero → return -1 (hard failure).
- MESHFILE: `sub_5DCC20(...) != 0` (mesh load failed) → return -1.
- SHADOWCASTER / SHADOWOBJECT act only when the arg string is exactly TRUE, STATIC or DYNAMIC; the shadow-add branch additionally requires ((parent 0x10000 && node&0x10 == 0) || (parent 0x20000 && node&0x10 != 0)) and `a1[71] > 0.0` to call sub_5DB470, whose nonzero return aborts with -1; texture path aborts when String nonempty && node[116] set && sub_5E6040 nonzero.
- SHADOWOBJECT fallback: when not in the shadow branch — if mesh flag 0x100000 set, OR in 0x1000000; otherwise set pending flag v52=1.
- SHADOWRECEIVER is honored only when `(*(_DWORD *)a1 & 0xF0000) != 0` and ArgList == "TRUE".
- After the loop: if `v52 && !v6[136]` (shadow pending, no shadow target) → cleanup via sub_5DBB20, destroy, free, return 0.
- Attach: a4 != 0 → sub_5DAC60(a4, node, 0); else sub_5DB5F0(node). Then, if v6[156]==0 (no parent) and v6[157] list non-null with first element nonzero → node flag bit 8 set.
