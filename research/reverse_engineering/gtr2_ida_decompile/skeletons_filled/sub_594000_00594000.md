**Guard conditions:** `fopen(FileName,"wb")` — success (non-NULL) passes into the writer; failure is BLOCKED, and only if `sub_5612D0(byte_FAE910, 1, ..., 2921)` returns nonzero it logs `Could not write to file %s` then returns -1. Session loop runs exactly 7 iterations (`v6 < 7`). The time-limit lookup runs if `sub_53A250(0)` is nonzero, and again if the `DefaultScoring` node exists (`v24 != 0`); it accepts the first of `%sTime`/`%sDuration` nodes found and atofs it into the 180.0 default. Sampling loop runs only when duration `v22 > 0.0` (steps of 10.0). Interpolation branch requires the next node pointer non-NULL **and** `next.time > current.time`; otherwise the first node's conditions value is used directly. Per-minute block loop breaks as soon as `(node.time - duration) * 0.016666668 > v25` (180.0 or the config limit).
