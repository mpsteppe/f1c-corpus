## sub_522830_00522830 — Window-limited list scan then dispatch

**Summary:** Requires a positive element count at this+0x6DC, then scans the list from head this+0x6D0 counting entries while each payload's leading float key stays within (reference float at this+0x2C2434) + 2.0. If the scan stops early it fetches the element at the reached index via sub_47F6E0 and dispatches it through sub_520FF0; if the whole list was covered it resets the cursor to the head and dispatches the first entry's payload.
