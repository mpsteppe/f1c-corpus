## sub_587F80_00587f80 — Engine definition loader (vehload)

**Summary:** Loads the engine definition file (vehload.cpp): opens the file, iterates its sections, and parses the engine keys (fuel consumption/estimate, engine inertia, idle/launch RPM logic, rev limit, RPM-torque curve, emission/sound, starter timing and thermal constants) into the vehicle object, converting RPM to rad/s and °C to Kelvin while validating the values with log messages. The number of parsed RPM-torque points is stored when at least one was read.

**Guard conditions:** The function returns -1 immediately when sub_614460 fails to open the file, and jumps to the cleanup path when the first sub_613DE0 section read returns 0. The parse loop breaks when sub_612EB0 returns 1; the engine keys are processed when it returns 0. IdleThrottle is clamped into 0..1. Validation messages (all skipped when dword_B640C0 == 5): "Bad engine idle range" when the idle upper value <= lower, "Bad engine launch range" for the launch pair, "Too many RPM-torque points" when the point counter >= 127, "RPM-torque brake > throttle" when the brake value < torque value, and "RPM-torque curve out of order" when a new RPM is <= the previous point's RPM. The EngineEmission shadow copy runs only while v21 == 0 (i.e. before an EngineSound key has been parsed); the RPM-torque point count is stored only when at least one point was read.
