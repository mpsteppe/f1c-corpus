## sub_6B8F20_006b8f20 — deflate_stored (level-0 block encoder)

**Summary:** zlib `deflate_stored()`: emits uncompressed stored blocks — refills the window when the lookahead runs dry, drains the lookahead into strstart, flushes a stored block whenever the pending block fills the buffer or the distance limit is reached, and finally flushes the remainder with the finish flag. Returns the zlib block/finish status codes (0 need_more, 1 block_done, 2 finish_started, 3 finish_done).

**Guard conditions:** The max block size is clamped to min(0xFFFF, pending_buf_size - 5). When lookahead <= 1 the window is refilled (sub_6B8DC8); if the lookahead is then 0 the loop breaks. Two block-flush cases: (a) when the advanced strstart is neither zero nor at block_start + max size, the MAX_DIST distance is checked — if strstart - block_start < w_size - 262 the loop continues without a flush, otherwise a block is flushed; (b) when the strstart has reached block_start + max size, it is clamped to that max (excess moves back into the lookahead) and a block is flushed. After each flush the loop continues only when avail_out is still nonzero. On the exit path, when flush (a2) is 0 the function returns need_more (0) with no final flush; otherwise the remainder is flushed with last = (a2 == 4), and the return depends on avail_out: finish_started (2) or need_more (0) when output space ran out, finish_done (3) or block_done (1) otherwise.
