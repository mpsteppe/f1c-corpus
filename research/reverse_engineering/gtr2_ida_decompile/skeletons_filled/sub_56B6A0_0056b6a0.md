## sub_56B6A0_0056b6a0 — Clamp normalized input to [-1,1] (optional filter path)

**Summary:** Takes a normalized input value a2 and stores a clamped copy at this[746] (0xBA8). If the owning object (reached through the pointer at this+0) has dword +0x39E4 == 1, the value is instead pushed through the helper object at this+0x9FC (sub_42F560) and the filtered result (sub_42F5C0) is what lands in 0xBA8; otherwise a plain clamp to [-1,1] is stored. Called from sub_53F8A0 and sub_583360.

**Called by:** sub_53F8A0 (0053f8a0), sub_583360 (00583360)

**Guard interpretation:** If owner+0x39E4 == 1, a2 is clamped: >1.0 becomes 1.0, values in [-1.0, 1.0] pass unchanged, anything else (including NaN: `a2 > -1.0` false and `a2 == -1.0` false) becomes -1.0; the clamped value goes to sub_42F560 and the result of sub_42F5C0 is stored at 0xBA8. If owner+0x39E4 != 1, no helper is used: a2 > 1.0 → 0xBA8 = 1.0; a2 >= -1.0 → 0xBA8 = a2; otherwise (and for NaN) → 0xBA8 = -1.0.
