## sub_6449B5_006449b5 — Texture requirement checker (caps clamp, size/mip normalization)

**Summary:** Validates usage flags and pool, resolves the pixel format through the record database (sub_644568 + sub_64467B), then clamps and normalizes requested width/height/depth against a caps structure fetched via the object's vtable (slot +0x1C): power-of-two rounding, DXT multiple-of-4 alignment, mip-count computation, and writes results back through the pointer arguments. Returns 0 or a D3D-style negative error code.

**Called by:** sub_644D6A (00644d6a), sub_644D91 (00644d91), sub_644E91 (00644e91)

**Struct fields accessed:**

| this | 0x0 | R | — | Vtable pointer of a2, dereferenced to reach the +0x1C capability query |

**Guard conditions:** (1) `!a2` → -2005530516. (2) `a7 == -1` normalized to 0. (3) `(a7 & 0xFFE039EC) != 0 || a9 >= 4` → -2005530516 (usage/pool validation). (4) Pool a9==3: format defaults to 21 when unset, no record resolution; otherwise resolution result 0 → -2005530518. (5) Size defaults: width/height both absent (-1) → 256/256; one absent → copies the other; zero → 1; depth -1/0 → 1; type a10==5 forces square (height = max). (6) Caps clamps: type 4 → all three extents clamped to v36; else width→v34, height→v35; type 3 additionally uses aspect `v15` (1 when caps bit 0x20 set, else v37) for width vs height*v15. (7) Capability mask v16 from a10 (3→2, 4→0x40000, 5→0x20000, default a10); if `v38 == 1 && (v33 & 0x100) && format not one of 827611204/844388420/861165636/877942852/894720068` → v16 = 0; when `(v16 & v33) != 0` all three extents are rounded up to powers of two. (8) If format is one of those five values (DXT1–DXT5 FourCCs), width/height are rounded up to multiples of 4. (9) For a9 != 3: if the type capability bit (`v23`: 3→0x4000, 4→0x8000, 5→0x10000) is missing from caps, or bit 0x100 is set with any non-power-of-two extent → mip count forced to 1; else mip count = bit length of the largest extent (depth included for type 4), never below 1; if the result != 1 and `(a7 & 0x400)` is set → 0. (10) Writes back only to non-null pointers: *a3=width, *a4=height, *a5=depth, *a6=mips, *a8=format.
