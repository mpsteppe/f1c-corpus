## sub_617ED0_00617ed0 — elapsed-time query (counter delta to seconds)

**Summary:** Timer read: takes the stored counter snapshot at +0x20/+0x24, re-reads the performance counter only when the timer is active (freq at +0x0 non-zero) and bit 0 of the byte at +0x48 is set, then computes the 64-bit delta against the previous snapshot and converts it to seconds as `low/freq + high*(2^32/freq)`. The new counter value is saved back into +0x20/+0x24.

**Guard interpretation:** `if (*this == 0 || (this[18] & 1) == 0)` — when the frequency dword is zero (timer not initialized) OR bit 0 of the +0x48 flag is clear, the function uses the existing stored counter pair and does NOT call QueryPerformanceCounter (BLOCKED).
