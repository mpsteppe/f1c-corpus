## sub_6B9659_006b9659 — deflateReset (reset deflate stream state)

**Summary:** zlib `deflateReset()`: validates the stream (state, alloc, free callbacks present), zeroes the totals, clears the error message, re-seeds the pending cursor from pending_buf, normalizes the wrap flag and derives the status (initial vs busy), sets data_type/adler, re-initializes the tree state, and reloads the level parameters via the hash-reset helper. Returns 0 (Z_OK) or -2 (Z_STREAM_ERROR).

**Guard interpretation:** Entry BLOCKS with -2 (Z_STREAM_ERROR) when the stream is NULL, or when the state, the allocation callback or the free callback (checked at 0x20/0x24 nested state and the callback slots) is NULL. Otherwise reset proceeds unconditionally. For the table rows: a negative wrap (0x34 < 0) is clamped to 0 first — that clears the "trailer already written" marker; then wrap != 0 selects status 113 (busy) while wrap == 0 selects status 42 (initial). Neither branch is blocked; they only steer the derived status.
