## sub_618610_00618610 — encryptomatic_encipher_buffer

**Summary:** Core byte-processing loop of the Encryptomatic V1.0 component: for each of `a3` input bytes at `a2`, it mixes the byte with a substitution table (`Block`) indexed by the state byte at +0xC, uses the low nibble of the input byte as `Seed` to trigger the RNG worker thread (SetEvent + WaitForSingleObject on `hEvent`), folds the worker's result (low nibble masked off with 0xFFFFFFF0) into the output byte, and advances the counter (+0x8, XOR-mixed into the state) and the nonlinear state (+0xC, doubled with sign-bit feedback). Returns the output buffer pointer (+0x10).

**Guard interpretation:** `this+0xC >= 0` (sign bit clear) PASSES with plain state doubling (`state = 2 * state`); a negative state (bit 31 set) takes the extra `+1`, feeding the shifted-out bit back into the state (the decompiled test `v6 = *(this+12) >= 0; v7 = 2*(this+12); *(this+12) = v7; if (!v6) *(this+12) = v7 + 1`).
