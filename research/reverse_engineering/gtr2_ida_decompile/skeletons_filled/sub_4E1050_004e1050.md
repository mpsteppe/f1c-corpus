**Written-by note (persistence):**
- this 0x28: written conditionally every call — forced to 2 when different; an external poke to any other value is overwritten on the next call.
- this 0x70: recomputed every call from sub_4DE470 — external poke does not survive.
- this 0x108: incremented every call by dbl_FB1D08 — external poke does not survive.
- this 0x10C: reassigned every call from dbl_FB1D08 — external poke does not survive.
- this 0x118: recomputed every call (reset to 0, or += 0x10C) — external poke does not survive.
- this 0x188: written conditionally — zeroed when state is 1/2/4/6/9, and refilled via sub_4DFAA0 only when zero; a nonzero external poke survives only while the state avoids the zeroing cases.

**Guard interpretation:** When the state id at 0x70 equals 2 (reached from the state-1/2 and state-6 branches), execution jumps to LABEL_25 and invokes vtable slot +0x48 on the active sub-object before the shared exit. For every other state value the extra call is BLOCKED — the path returns directly through off_16C98E0 without it. (Separately, 0x28 is force-written to 2 when it differs; that is a write, not a branch.)
