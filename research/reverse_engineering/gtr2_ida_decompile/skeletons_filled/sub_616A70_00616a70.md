## sub_616A70_00616A70 — find-or-insert named entry (case-insensitive)

**Summary:** Searches an internal container (starting at this+0x24) for an entry whose name matches the input object's name (`a2+8`, falling back to `WindowName`) using `_stricmp`; on a hit it returns the comparison result (0), on a miss it allocates a 12-byte entry, initializes it with the name and a monotonically increasing index (this+0x34), and registers it via `sub_5FDFB0`.

**Called by:** sub_616F97 (00616f97)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x24 | R | — | Container entry pointer (this[9]); seeds the search cursor |
| this | 0x2C | RW | — | Search cursor (this[11]): initialized to the entry pointer, advanced along its +4 link while scanning |
| this | 0x30 | R | — | Field of the container substructure passed to the insert helper (no direct access in this function) |
| this | 0x34 | RW | — | Running entry counter (this[13]): read as the new entry's index, then incremented on insert |

**Written-by note (persistence):**
- this 0x2C: rewritten on every call (cursor reset to the list head, then advanced node by node during the search) — an external poke is overwritten on the next call.
- this 0x34: incremented only when a new entry is inserted (conditional, not per frame) — a poke survives until the next successful insert.

**Functions called:**

|---------|------|---------|
| 005fdfb0 | sub_5FDFB0 | Registers/inserts the new node into the container structure (called with the container at this+0x24, the node, and flag 1) |
| 00616520 | sub_616520 | Initializes the new 12-byte node: zero dword, -1, name copy, stored index |
| 00630739 | ??2@YAPAXI@Z | operator new — allocates the 12-byte entry |
| 00631c0d | __stricmp | Case-insensitive comparison of searched name vs entry name |

**Guard conditions:** `v3 = this[9]`; search loop only runs if `v3 && (*v3 != 0)` — otherwise jumps straight to insert. In the loop: name match (`_stricmp == 0`) → break, returns 0 (already present). No match and cursor advanced to a null/nonexistent next node → exits to insert. Insert path: if `operator new(0xCu)` returns null → node null is passed to `sub_5FDFB0(v4, 0, 1)`; otherwise the node is initialized first. Return value is the low byte of the insertion helper's result; on a found entry the raw comparison result (0) is returned.
