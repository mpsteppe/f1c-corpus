## sub_405130_00405130 — Scalar deleting destructor (destructor + conditional free)

**Summary:** MSVC scalar deleting destructor: runs the class destructor (sub_5A8840) on the object, then frees the object's heap block if the delete flag (bit 0 of a2) is set. Runs as part of C++ object teardown.

**Called by:** (none static — top-level or indirect-only)

| 005a8840 | sub_5A8840 | Class/base destructor body — performs object cleanup before the optional free |
| 006308d3 | j__free | CRT free — releases the object's memory when the deleting flag is set |

**Guard conditions:** Checks `a2 & 1` (the delete flag). If bit 0 is set, the object passes through `j__free(Block)` (heap deletion). If bit 0 is clear, the free is skipped — the destructor-only path (e.g. stack or placement object) returns Block unmodified.
