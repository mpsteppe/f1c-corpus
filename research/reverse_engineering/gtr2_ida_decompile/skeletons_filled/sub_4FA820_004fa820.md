## sub_4FA820_004fa820 — per-frame update over all entries

**Summary:** Frame update driver: when the driver pointer at this+0x12C is non-null it calls sub_4FA6A0 with the caller's a2/a3 arguments, then loops over the 768-byte entry array (count this+0x120, base this+0x124) calling sub_4F3330 — the mirror-camera updater — on each entry.

**Called by:** sub_4FB770 (004fb770)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x120 | R | — | entry count (loop bound) |
| this | 0x124 | R | — | base pointer of the 768-byte-stride entry array |
| this | 0x12C | R | — | driver/enable pointer; null skips the entire update |

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 004f3330 | sub_4F3330 | updates the mirror-camera offsets of one entry (state 4/5 rear view, 7/8 side mirrors) |
| 004fa6a0 | sub_4FA6A0 | first-stage update receiving the a2 and a3 arguments from the caller |

**Guard conditions:** The whole body is gated on `this[0x12C]` being non-null; null returns immediately with no calls. The per-entry loop then runs only while the count at this+0x120 is positive (zero/negative count skips the sub_4F3330 sweep).
