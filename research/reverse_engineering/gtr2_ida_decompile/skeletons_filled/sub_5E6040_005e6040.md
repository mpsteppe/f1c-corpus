## sub_5E6040_005e6040 — Create and initialize named sub-object

**Summary:** Allocates a 0x1E4-byte object, constructs it, configures it from name string a2 and constant size 128, marks a flag at object+4 as 1, then runs a setup routine with floats 0.0/1.0. On setup failure it destroys and frees the object and returns -1; on success it sets bit 0x20000 in *this and returns 0.

**Called by:** sub_5E12E0 (005e12e0)

| this | 0x0 | RW | — | Flags dword; bit 0x20000 set on the success path |
| this | 0x28 | RW | — | Holds the pointer to the newly created object (this[10]) |
| this | 0x2C | RW | 1 | Set to 1 after construction (code stores dword 1 at +4 of the object held by this+0x28) — per-object state/enable flag |

**Written-by note (persistence):**
- this 0x0: Conditional — only bit 0x20000 (OR-ed in) is written, and only on the success path; the rest of the dword is preserved. An external poke to that bit survives only until a successful call.
- this 0x28: Written once per invocation, unconditionally, with the freshly allocated object pointer (null if allocation failed). Any external poke is overwritten by the next call.
- this 0x2C: Written with 1 on every invocation right after construction; an external poke is overwritten by the next call.
