## sub_54E350_0054e350 — Steering animation foot IK/controller setup

**Summary:** Sets up the animated steering feet: creates the right and left foot IK solvers and rotation controllers from the skeleton's Bip01 bone chains, initialises the foot rest/previous/current position slots and the controller angle clamp range (±0.02 rad), and releases the partially created objects with "Failed to create ..." logs on any failure. The whole setup is gated on the two entry pointers being non-null.

**Guard conditions:** The whole setup is blocked unless this+0x20 and this+0x30 are both nonzero. Each creation stage only runs when the previous one succeeded: right-foot IK solver (v12) → left-foot IK solver (v15) → right-foot controller (v18) → left-foot controller (v22); on any failure the already-created objects are released through their virtual calls (`(**obj)(obj, 1)`), the affected pointers are zeroed, and the matching "Failed to create ..." message is logged — but only when dword_B640C0 != 5 and the sub_5612D0 logging gate passes. The final success block (rest/current/previous position copies, ±0.02 rad angle clamps, state 2, zeroed angles) executes only when all four objects exist.
