## sub_6183D0_006183d0 — bit_arena_alloc

**Summary:** Allocates `a2` bits in a bit-arena container: grows the backing bit buffer and the descriptor array as needed, appends a 4-byte descriptor {start bit = cursor (+0x10), length = a2} to the array at +0x8, clears (zero-initializes) the newly allocated bit range via sub_618040, advances the cursor by a2, increments the element count, and returns the new descriptor index through `a3`. Always returns 1.
