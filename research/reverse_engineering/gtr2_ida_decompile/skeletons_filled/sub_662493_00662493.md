## sub_662493_00662493 — Arena rollback / release (frees heap chunk only for fresh blocks)

**Summary:** Companion to the chunked arena allocator: given a payload pointer a2, restores the arena cursor (this+0x88) from the 2-dword header at a2-8 and restores remaining space (this+0x8C) from the header's second dword; if that value is negative (fresh heap block marker), it is negated to recover the prior remaining space and the block itself is freed, otherwise the block is kept as part of the arena.

**Called by:** sub_6714D6 (006714d6)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x88 | RW | — | dword index 34 — arena cursor; restored from the freed block's header word 0 (previous block pointer) |
| this | 0x8C | RW | — | dword index 35 — remaining space; restored from header word 1 or its negation |

**Written-by note (persistence):**
- this 0x88: conditionally overwritten — only when a2 (payload pointer) is non-NULL; external poke survives while no rollback call is made.
- this 0x8C: conditionally overwritten — only when a2 is non-NULL; external poke survives while no rollback call is made.

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 006308d3 | j__free | free — releases the heap chunk at a2-8 when the header marks it as a freshly allocated block (negative second word) |

**Guard conditions:** If a2 == 0, the function does nothing (both fields untouched). Otherwise header words at a2-8 are read: this+0x88 = header[0] always. If header[1] <= 0, this+0x8C = -header[1] and j__free(a2-8) is called (fresh-block path); if header[1] > 0, this+0x8C = header[1] and the chunk is NOT freed (in-arena carve path).
