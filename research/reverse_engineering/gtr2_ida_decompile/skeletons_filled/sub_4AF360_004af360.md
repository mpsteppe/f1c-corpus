**Guard conditions:** Auto-advance block: skipped entirely when `sub_4735E0(&dword_B6CBA8)` is nonzero; skipped when `flt_FADE20 - dbl_FB1D18` is non-negative (bit 31 clear); skipped when `|delta| <= dword_B73648`. Passes only when the delta is negative and larger in magnitude than the threshold, `dword_B640C8` is in 1..5 and `dword_B640C0 != 5`. The virtual call at +36 receives flag `v19` which is cleared to 0 if the session type is 3/4 with `dword_B640C8` in 1..5, or if `sub_4735E0` is nonzero. The skip-switch loop runs only when `(mode != 5 or v17) and v6`; per case it falls to `sub_49BEE0(...,0)` (skip) when the skip byte is 0 **and** mode != 4 (`goto LABEL_48`), and to the exit when the config key is missing or mode != 4. Post block: runs only when `dword_B640C8 != 0 and != 6`; session 0/6 instead re-sets WindowName and, for session 6 with `sub_4735A0()` and `sub_4735E0(&dword_B6CBA8)` both true, formats the `RESTART`/`RACE` texts. Default case of the session-index switch exits without action.
