## sub_67A96E_0067a96e — info-setter: sRGB rendering intent

**Summary:** Records the sRGB chunk on the PNG info structure: sets validity bit 0x800 (written through the high byte of the validity word at info+8) and stores the rendering-intent byte at info+0x2C. No-op when the png struct or the info pointer is NULL.

**Called by:** sub_648787 (00648787), sub_67A98E (0067a98e)

**Guard conditions:** Two NULL checks gate the writes: if a1 (png struct) is 0 the function returns immediately; inside, if a2 (info structure) is 0 it returns as well. Otherwise it sets the sRGB validity bit by OR-ing 0x8 into the byte at info+9 (dword bit 0x800) and stores the intent argument as a single byte at info+0x2C. The intent value is not range-checked.
