## sub_60B640_0060b640 — prime vertex streams by mask (per-stream queries, set ready flag)

**Summary:** For each bit in the stream mask a5 (defaulting to this+0x18 when a5 is 0) it queries the matching stream object (this+0x24..0x34 for geometry/bone/bump/texture0/texture1, this+0x20 for world/world-bump/screen/projected/lworld) via sub_60AD50 and stores each result in this+0x38..0x4C; when every active query returned nonzero it sets bit 0x80 in the flags dword at this+0x00.

**Written-by note (persistence):**
- this 0x0: conditionally written — only on the all-success path (v27 true and the lworld short-circuit not failing); an external poke otherwise survives until the next qualifying call.
- this 0x38: conditionally written — only when bit 1 is set and this+0x24 is non-null; otherwise untouched.
- this 0x3C: conditionally written — only when bit 2 is set and this+0x28 is non-null.
- this 0x40: conditionally written — only when bit 4 is set and this+0x2C is non-null.
- this 0x44: conditionally written — only when bit 0x10 is set and this+0x30 is non-null.
- this 0x48: conditionally written — only when bit 0x20 is set and this+0x34 is non-null.
- this 0x4C: conditionally written — only when one of bits 0x1000/0x8000/0x2000/0x4000/0x20000 is set and this+0x20 is non-null; later bits overwrite earlier ones.

**Guard interpretation:** this+0x00 as a signed dword is negative (bit 31 set) → entire body skipped, returns the initial value 1. Otherwise each bit of the mask (argument a5, or this+0x18 when a5 is 0) enables its stream query; a stream whose object pointer is null is skipped silently; each call returning 0 sets v27 = 0. Final: if the lworld (0x20000) branch is absent or its object null or its call returned nonzero → return v27, and when v27 is true additionally set bit 0x80 of this+0x00. If the lworld branch ran and its call returned 0 → return 0 and bit 0x80 is not set.
