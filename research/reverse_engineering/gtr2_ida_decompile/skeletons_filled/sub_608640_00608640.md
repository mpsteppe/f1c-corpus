**Guard interpretation:** Entry into the whole routine requires `(*a2 & 0x3000000) == 0` — entities already carrying 0x3000000 return 0 immediately (BLOCKED). The renderer virtuals returning nonzero abort with -1 (BLOCKED on failure). Inside the donor walk, an inner object is skipped when its flag word has bit 0x200 set; for the remaining objects, the per-entry loop is entered only when the entry count at +0x168 is > 0, otherwise the object is skipped via LABEL_25 to the next nested node. An entry matches a2 only when a2[22] equals entry+88 AND a2[1] equals entry+4; non-matching entries are skipped without copying. Success paths copy data and end with *a2 |= 0x3000000, returning 0.
