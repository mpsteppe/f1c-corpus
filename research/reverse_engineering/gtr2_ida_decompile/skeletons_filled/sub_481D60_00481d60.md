## sub_481D60_00481d60 — DedicatedServer.ini writer

**Summary:** Writes the dedicated-server configuration file (DedicatedServer.ini) from the current server settings: emits the [SETTINGS] block with all gameplay/session/live-reporting options, then the [TRACKS] list from the track-name list, using the configured default directory. Companion to the dedicated-server config reader.

**Called by:** sub_4839A0 (004839a0), sub_489700 (00489700)

| obj | 0x0 | R | — | head of the track-list container (this[0]): when null no track names are written |
| this | 0x0 | R | — | track list head; also the iteration base for the track-name loop |
