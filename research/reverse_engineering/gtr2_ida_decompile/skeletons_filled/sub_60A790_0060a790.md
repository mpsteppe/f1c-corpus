## sub_60A790_0060a790 — Conditional slot-1 reset when counter set

**Summary:** If the counter/flag at this[61] (0xF4) is nonzero, it calls sub_609B00(this, 1, 1) to program slot 1 back to 1 and then clears this[61] to 0; returns the setter result, or the stale counter value when no action was taken.
