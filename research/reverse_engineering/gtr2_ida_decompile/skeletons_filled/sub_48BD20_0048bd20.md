## sub_48BD20_0048bd20 — scan key codes, nudge value up/down, post update

**Summary:** Scans an array of a3 16-bit key codes (a2): DIK_RIGHT (205) increments and DIK_LEFT (203) decrements a value — directly through the counter at this+0x10C plus sub_4CDE30, or, when the byte at this+0x120 is set, through a virtual counter object fetched via vtable slot 0xBC and a virtual update via slot 0x9C. Finishes by forwarding the pair (this+0x138, float this+0x134) to sub_435990 with the global context; returns 1 if any adjustment was applied, else 0.

**Guard conditions:** Only runs the scan when the count a3 > 0. Returns 1 once any 203/205 was processed, otherwise 0.
