## _fread_006317b9 — CRT fread

**Summary:** ANSI CRT `fread`: reads `ElementCount * ElementSize` bytes from a FILE stream into a caller buffer, using the stream's own buffered data first and falling back to `_filbuf`/`_read` for the remaining bytes. Returns the number of complete elements transferred.

**Called by:** sub_6318A2 (006318a2)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | RW | — | First byte of the caller's destination buffer; receives file data (bulk memcpy from the stream buffer or single characters from `_filbuf`/`_read`) |

**Written-by note (persistence):**
- this 0x0: written during every read call as bytes arrive; the buffer is caller-owned and rewritten on each subsequent read, so an external poke would not survive the next read.

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 00635560 | _memcpy_0 | Copies the smaller of requested remaining bytes and Stream->_cnt buffered bytes from Stream->_ptr into the destination buffer |
| 006379c3 | __filbuf | Refills/reads a single character from the stream when the request is smaller than the stream buffer size; returns -1 on EOF |
| 00637c7f | __read | Low-level OS read directly into the destination buffer for large requests (at least one full buffer size), bypassing the stream buffer |

**Guard conditions:** `if (!(ElementCount * ElementSize)) return 0;` — zero-size request returns 0 immediately. `(Stream->_flag & 0x10C) != 0` selects the stream's own buffer size (`Stream->_bufsiz`), otherwise a default of 4096 is used. Buffered path: `cnt = Stream->_cnt; if (cnt)` copies min(remaining, cnt) via memcpy. Small path: while `v6 < bufsiz` calls `_filbuf`; `-1` (EOF) returns partial element count, otherwise the character is stored one byte at a time; `!(Buffera)` returns full ElementCount. Large path (`v6 >= bufsiz`): `_read` of `v6 - v6 % bufsiz` bytes; result 0 sets stream flag 0x10 (EOF) and returns partial count; result -1 sets flag 0x20 (error) and returns partial count. All early exits return `(v5 - Buffera) / ElementSize` (elements successfully read).
