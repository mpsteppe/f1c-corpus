## sub_60A3F0_0060a3f0 — Mode setter (channel 2) with manager notification

**Summary:** Same pattern as the channel-1 mode setter but on slot this[55]: when the new a2 differs and is not -1, it maps a2 (0→1, 1→3, 2→2) onto a virtual call to dword_FB40C8 at vtable+276 with (this[51], 2, mapped value), then stores a2 into this[55]. **Guard conditions:** The block PASSES only when `a2 != this[55]` AND `a2 != -1` (sentinel rejected); otherwise nothing is stored/notified and the current this[55] is returned. Inside: a2==0 notifies mapped value 1; a2==1 notifies 3; a2==2 notifies 2 (and returns the call result); any other a2 performs no notification and returns a2-2.
