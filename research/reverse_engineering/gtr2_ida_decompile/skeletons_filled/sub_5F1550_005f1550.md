## sub_5F1550_005f1550 — Desktop display mode acquire (Direct3D)

**Summary:** Queries the desktop display mode through the display device interface at this+0x2548 (vtable slot +32) into a local mode struct, stores the HRESULT at this+8 and logs "Could not acquire desktop didplay mode" (returning -1) on failure; on success it outputs width/height to a2/a3 and, when a4 is supplied, invokes the object's vtable+0xAC callback with the pixel format (mapping format 22 to 21 — the X8R8G8B8 → A8R8G8B8 substitution).
