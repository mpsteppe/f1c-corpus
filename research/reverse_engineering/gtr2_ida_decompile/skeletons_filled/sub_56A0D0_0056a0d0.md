## sub_56A0D0_0056a0d0 — Advance time-keyed state, clamp points, rebuild normals

**Summary:** Large update routine: selects a 36-byte state record for the incoming scalar a2 (a3 = -1 picks the index automatically), then per record either interpolates points toward a stored target with distance falloff and clamps them inside a radius, snaps points to a fixed 0.075 length, or resets them by copying stored triples. Afterwards it clears bit 0x800 in the section flag dwords and rebuilds vertex normals by accumulating triangle normals from up to 7 faces (TriangleNormalComputation). Called from sub_56AAE0 and sub_56DC50 — behavior matches a deformable mesh/point-chain simulation tick.

**Called by:** sub_56AAE0 (0056aae0), sub_56DC50 (0056dc50)

**Guard interpretation:** Entry test `a2 >= *this` chooses how the start index is found: with a3 == -1 the routine scans the 36-byte records for the first whose field at 0x20 exceeds *this; when `a2 < *this` it scans for the first record with field 0x20 in (a2, *this] and, if none exists (v5 == count), stores *this = a2 and returns early without any update. In the record pass, only records with field (v22-24) <= a2 are processed, and the dword at (v22-28) selects the action (0 = interpolate toward target and clamp into radius, 1 = copy stored triples, 2 = snap to 0.075 length). The final flag-clear plus normal-rebuild block runs only when v126 was set (some record was touched or the reset pass ran); the component loops additionally require their list counts to be > 0.
