## sub_6B96C8_006b96c8 — deflateInit2_ (initialize deflate stream)

**Summary:** zlib `deflateInit2_()`: validates the version byte and stream size, installs default allocation/free callbacks when the stream leaves them NULL, normalizes the level (-1 → 6) and the windowBits sign, validates method/memLevel/windowBits/level/strategy, allocates and wires up the deflate state (tables, buffers, size fields), then runs the deflate reset. Returns -6 (version), -2 (stream), -4 (memory) on failure.

**Called by:** sub_6B7931 (006b7931)

**Written-by note (persistence):**
- this 0x18: written once per init call (cleared, or error string on failure); poke survives until the next init
- this 0x1C: written once per successful init (state pointer); poke survives until the stream is torn down or re-inited
- this 0x20: written only when the slot was NULL (default allocator installed); a pre-set callback survives
- this 0x24: written only when the slot was NULL (default free callback installed); a pre-set callback survives
- this 0x28: written only alongside the default allocator installation (cleared); otherwise untouched

**Guard interpretation:** For the table row: when strm->zalloc (0x20) == 0 the PASS path installs the default allocator sub_6DAC77 into 0x20 and clears the opaque field at 0x28; a nonzero callback BLOCKS the default from being installed and is kept as-is. The sibling check on 0x24 behaves the same for the free callback. Other blocking guards: a NULL version string, a first version byte that differs from off_91AA4C, or stream_size != 56 returns -6 immediately; a NULL stream returns -2; source level, method, window bits, memLevel or strategy out of range returns -2; if any allocation (state or its tables/buffers) returns NULL the message at off_91AAA4 is stored and deflateEnd runs, returning -4.
