## sub_5F1370_005f1370 — Animation pose evaluator (time → keyframe interpolation)

**Summary:** Evaluates the animation at time a3: clamps the time to the clip duration, converts it into current/next key indices, then for each track element interpolates the quaternion and translation between the two keyframes and composes the transform; marks the object dirty (flag 0x1000) and, when a2 is given, sets flag 0x40 on the object referenced by a2[98]. **Written-by note (persistence):**
- this 0x0: bit 0x1000 is ORed in on every call (unconditional); other bits are untouched, so external pokes of the other bits survive, while a poke clearing 0x1000 does not survive the next evaluation.

**Guard interpretation:** Time is clamped first: `a3 > duration` → a3 = duration (overshoot BLOCKED from exceeding the clip). The key index is clamped after scaling: if the scaled index >= keyCount-1, an index equal to keyCount is pulled back to keyCount-1 (out-of-range BLOCKED); otherwise the index advances by one to form the "next" key. `this+0x14 > 0` gates the whole track loop (no tracks → only the dirty flags are set). Inside the loop, a track with index byte 255 is skipped entirely (PASS only for index != 255), and when the two keys' time delta is exactly 0.0 the interpolation factor is forced to 0.0 to avoid division by zero. `if (a2)`: the a2[98] flag 0x40 update only runs when a2 is non-null; the return value is a2 when null, otherwise the pointer at a2[98].
