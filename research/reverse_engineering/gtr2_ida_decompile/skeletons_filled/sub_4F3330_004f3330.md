- *(this+0xAC) 0x2C: recalculated every time the state is 4 or 5 (position = car pos + fixed local offset), so a poke survives only outside 4/5 states.
- *(this+0xAC) 0x30: same as 0x2C — rewritten per state-4/5 update from car position.
- *(this+0xAC) 0x34: same as 0x2C — rewritten per state-4/5 update from car position.
- *(this+0xAC) 0x38: rewritten per state-4/5 update as sourceAngle*0.01745433 (degrees→radians), so a poke survives only while state is not 4/5.

**Guard interpretation:** The rear-view branch runs only when state is 4 or 5 AND the camera pointer at +0xAC is non-null; the side-mirror branch runs only when state is 7 or 8 AND the camera pointer at +0xEC is non-null. Any other state (or null camera) is blocked — nothing is written, both branches are skipped. Within the branches, state 4/7 uses the first angle/offset pair of the selected vehicle record (fields at +236/+248, or +244) and state 5/8 the second (fields at +252/+264, or +260) — two variants per mirror, rear vs side.
