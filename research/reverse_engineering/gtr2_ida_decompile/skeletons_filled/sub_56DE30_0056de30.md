## sub_56DE30_0056de30 — build point/direction record and dispatch

**Summary:** Builds a stack record from an input point (a3), a scalar (a2) and a direction vector (a4): when a sub-object flag is set it offsets the point by the sub-object's stored position, then computes the direction magnitude and calls sub_56DC50 with the record if the magnitude is non-zero.
