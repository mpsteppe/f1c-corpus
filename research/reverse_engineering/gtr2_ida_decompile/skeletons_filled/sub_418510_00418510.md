## sub_418510_00418510 — Per-mode camera update with grid refresh

**Summary:** Mode-dispatch update for a view object: modes 0-6 advance the mode's camera computation via sub_471FC0(a2, this+0x10, flag) — flag 0 for 0/1/2/3/6, byte_B731B0 for 4/5 — and a failed update additionally runs sub_416B10 before the shared spatial-grid refresh; mode 7 syncs from the target object (bit 0x8 of target+0x5834 → sub_5840D0, then sub_5732F0) and copies the target's +0x3E64 triple into this+0x10/0x14/0x18, returning 1.

- this 0x14: same two writers, refreshed per mode call; poke not durable.
- this 0x18: same two writers, refreshed per mode call; poke not durable.

Modes 0/1/2/3/6 → PASS: sub_471FC0(a2, this+0x10, 0); nonzero result → sub_52FAB0 and return that result, zero result → sub_416B10 first, then sub_52FAB0 and return 0.
