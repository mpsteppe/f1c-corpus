## sub_4F3C10_004f3c10 — recenter scene object groups to view center

**Summary:** Rendering/view helper: computes the mid-point of a 6-float screen/viewport rect (averaged diagonal), adds the origin returned by sub_5DA7A0, then walks a scene-object collection (linked list in this+0x29C, count at +0x2A8) and translates every vertex of every object group by the negated center, marking each object dirty and updating the renderer.

**Guard conditions:** No field-versus-literal guard on entry. The outer loop is bounded by the count read at object+544 only when count > 0; the inner traversal walks the object list until the requested index is reached and falls back to `v6 = 0` (null node) when the index is out of range or the list runs out — a null node still goes through sub_5EA5B0/sub_5EAF10, so the pass effectively no-ops on the geometry but still processes. The only real gate is `result > 0`: a zero/negative object count returns immediately with nothing translated.
