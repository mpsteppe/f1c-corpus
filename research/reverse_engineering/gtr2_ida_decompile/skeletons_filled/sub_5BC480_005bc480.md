**Guard conditions:** No gating branches or early returns. Per-component min/max selection: lower corner keeps the smaller value (`this >= point` → take point, else keep this); upper corner keeps the larger (`this <= point` → take point, else keep this). The final Z-max branch writes this[5] either way, so all six fields are always updated. The growing box is expected to have been pre-initialized to +FLT_MAX / -FLT_MAX so the first point seeds it.
