## sub_4058B0_004058b0 — Sample keyed track at value (keyframe interpolation)

**Summary:** Evaluates a keyed float track at query value `a3`: binary-searches the 16-byte entry array for the bracketing key pair, computes the local interpolation factor, and delegates to a virtual evaluator method (vtable slot +4) to fill the 3-DWORD output `a2`. If no bracketing pair exists it copies the last entry verbatim (clamped). System: engine curve/track evaluation.

**Called by:** sub_405CA0 (00405ca0), sub_405E20 (00405e20), sub_4F8120 (004f8120), sub_5D0AA0 (005d0aa0)

**Guard conditions:** If `this+0` (count) is 0, returns `a2` untouched (empty track — nothing sampled). Branch on `a3` vs the middle key selects which half-range (mid→count or 0→mid) is searched by sub_405170. Interpolation path taken only when `v6 != -1 && v6+1 <= v4-1`; otherwise (key not bracketed, or bracketed by the final segment) the function falls back to copying the last entry's 3 DWORDs (`16*v4 + base - 16`) into `a2` — clamped sampling.
