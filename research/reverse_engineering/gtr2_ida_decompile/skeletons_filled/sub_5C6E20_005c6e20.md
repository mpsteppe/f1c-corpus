## sub_5C6E20_005c6e20 — Build per-sample tangent array (central differences)

**Summary:** For a byte sample list referenced by the object at this+0x4, rebuilds the float buffer at this+0x8 sized 4*count, setting first/last tangents to 0.0 and interior entries to the central difference 0.5*(x[i+1]-x[i]) + 0.5*(x[i]-x[i-1]) of the byte samples scaled by 1/255.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| *(this+0x4) | 0x0 | R | — | sample count (dword at +0 of the object pointed to by this+0x4) — drives buffer size and loop bound |
| *(this+0x4) | 0x8 | R | — | byte sample data base (dword at +8 of that object); samples read at stride 8 (x[i-1] at -8, x[i+1] at +8) |
| this | 0x4 | R | — | pointer to the source object holding the sample count and byte data |
| this | 0x8 | RW | — | output float buffer pointer; replaced with the resized buffer returned by sub_5A8CF0, then filled with tangents |

**Written-by note (persistence):**
- this 0x8: overwritten on every call with the pointer returned by the resize helper; an external poke survives only until the next call (and the buffer contents are recomputed each call).

**Guard conditions:** Loop branch per index: index 0 or count-1 → tangent set to 0.0; every other index → central-difference formula computed from neighbour bytes. With count of 0 or 1 the allocation size collapses and no interpolation entries are produced; no early return or error path exists.
