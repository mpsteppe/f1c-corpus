## sub_5D88C0_005d88c0 — Build 3-vector from scalar via indexed transform (mode 2)

**Summary:** Builds a 3-component float vector at `a3` from a scalar magnitude `a1` and a flag word `a2`: a mode-2 transform expands the scalar, indexed factor lookups (sub_600770/sub_6006C0) supply a scale and per-axis factors, and a flag bit optionally applies the scale again to the components. Fourth output dword is zeroed.

**Guard conditions:** If `a1 == 0.0` PASSES the fast path: skip sub_600770/sub_6006C0 and use factors v10=v11=v12=1.0 (v7 stays 1.0); otherwise the lookups run. If `a2 == NULL` the input triple is forced to zero (a1=v8=0, v4=0) and no transform runs — components come out zero. When `a2 != NULL`, flag test `(*a2 & 0x01000000) == 0` BLOCKS scaling: only the z path uses v9 unscaled (v4=v9); when bit set, a1, v8, v9 are multiplied by v7 before assembly.
