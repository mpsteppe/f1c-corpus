## sub_489910_00489910 — CompareEntitySlotOrder

**Summary:** Predicate comparing two entities by scanning a global ID table (dword_B6D678+0xA4, up to 208 entries): returns whether the a2 entity's id at +0x34C is found before this entity's id, with early exits driven by packed flag bits of the first dword (3-bit type at bits 29+, 6-bit subtype at bits 18-23, low byte 0xFF marker). Slot/order comparison helper in the entity management layer.

**Guard conditions:** Early exits inside the scan:
- If entity type `v3 >> 29 == 4` AND subtype `(v3 >> 18) & 0x3F < 2` → return 1.
- If this object's low byte is 0xFF and a2's low byte isn't 0xFF → return 1; if this object's low byte isn't 0xFF and a2's is 0xFF → return 0.
- If a scanned table entry equals this entity's id (+0x34C) → break → return 0 (this entity found first).
- If a scanned table entry equals a2's id → return 1 (a2 found first).
- After 208 iterations with neither id seen → return 1.
