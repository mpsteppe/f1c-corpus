## sub_498E00_00498e00 — DispatchByStateCode

**Summary:** State/opcode dispatcher: switches on the code at this+0x360 and, for recognized codes, compares the counter pointed to by this+0x348 against global thresholds dword_91CB60 or dword_91CB64 (some code groups use threshold+1) to set the status at this+0x33C to 0 or 2; every path then invokes the virtual method at vtable slot +0xB8.

**Called by:** sub_4B2AF0 (004b2af0)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| obj | 0xB8 | R | — | virtual method slot in the object's vtable (offset 184) called on every path |
| this | 0x0 | R | — | vtable pointer — base used to reach the +0xB8 slot |
| this | 0x33C | RW | — | status result: set to 0 when the counter is within threshold, 2 when above |
| this | 0x348 | R | — | pointer to the counter/value compared against the thresholds |
| this | 0x360 | R | — | state/opcode selector the switch reads |

**Written-by note (persistence):**
- this 0x33C: written only when the opcode matches a recognized case (0 or 2, recalculated from the comparison each such call); the default path leaves it untouched, so an external poke survives until the next recognized call.
