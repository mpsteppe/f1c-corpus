## __ftol2_0063099c — double→integer conversion helper (ftol2)

**Summary:** CRT helper that converts the double in ST0 to a 32-bit integer result in EAX (with truncation), refining the low 32 bits from the truncated 64-bit value and its fractional part. Used by the compiler for float/double → int conversions throughout the game and STL code (hundreds of callers).

**Guard conditions:** Branches on the truncated 64-bit value: if the low 32 bits are zero AND the high 32 bits masked with 0x7FFFFFFF are zero, the truncated result is returned as-is. Otherwise, if the high dword (v1) is >= 0 the fractional part a1 - (int64)a1 is computed and the low word is adjusted (borrow via __CFADD__ with 0x7FFFFFFF); if v1 is negative it returns through the alternate 64-bit computation using the negated fractional part. No explicit error/overflow trap path is present.
