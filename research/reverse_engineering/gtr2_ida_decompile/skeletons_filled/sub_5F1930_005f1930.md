## sub_5F1930_005f1930 — Display mode query dispatcher (bit-depth selected)

**Summary:** Returns a display-mode value for the requested bit depth: a2 = 16 queries the sub-device at this+0x25DC; a2 = 32 queries this+0x25CC when a3 is set or this+0x25C8 when clear; both go through the object's vtable slot +0xAC with a result out-pointer. Any other a2 returns the default 255 without querying.

**Called by:** (none static — top-level or indirect-only)

|------|--------|-----|------------------------|---------|
| obj | 0xAC | R | — | Vtable slot +0xAC of the object — display-mode query invoked with (this, device, 0, &result) |
| this | 0x0 | R | — | Vtable pointer used to fetch the +0xAC query slot |
| this | 0x25C8 | R | — | Sub-device pointer used for a2 == 32 with a3 clear |
| this | 0x25CC | R | — | Sub-device pointer used for a2 == 32 with a3 set |
| this | 0x25DC | R | — | Sub-device pointer used for a2 == 16 |

**Guard conditions:** `a2 == 16`: query runs on the this+0x25DC device and its result is returned. `a2 == 32`: query runs on this+0x25CC when `a3` is nonzero, otherwise on this+0x25C8; the result is returned. Any other a2 value performs no query at all and returns the default 255 (BLOCKED). The result local is initialized to 255, so even a device query that writes nothing yields 255.
