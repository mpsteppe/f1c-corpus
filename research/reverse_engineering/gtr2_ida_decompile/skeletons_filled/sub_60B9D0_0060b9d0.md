## sub_60B9D0_0060b9d0 — poll pending job, clear ready flag when done

**Summary:** When the ready flag (byte 0x80 at this+0x00) is set and a job object exists at this+0x1C, calls the object's poll method (vtable slot 0x30); if the poll returns 0 (done) it clears the ready bit, clears this+0x20, decrements the counter at this+0x10 and returns the updated flags, otherwise returns the poll result.

**Called by:** sub_60DBC0 (0060dbc0), sub_611330 (00611330)

|------|--------|-----|------------------------|---------|
| *(this+0x1C) | 0x30 | R | — | vtable slot 0x30 of the job object at this+0x1C — poll method; a 0 return means done |
| this | 0x0 | RW | — | flags dword; byte bit 0x80 is the test gate and is cleared (mask 0xFFFFFF7F) when the poll reports done |

**Written-by note (persistence):**
- this 0x0: conditionally written — only when the poll returns 0 (bit 0x80 cleared); an external poke otherwise survives until such a call.
- this 0x10: conditionally written — decremented only on the poll-done path.
- this 0x20: conditionally written — set to 0 only on the poll-done path.
