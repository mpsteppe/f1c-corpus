## sub_4888D0_004888d0 — TickMessageStateTimer

**Summary:** Per-frame tick that reads elapsed time (sub_617F80), and when the step is at least 0.334 decrements a floating countdown at this+0x50 (clamped to [-17, 45]) and services a pending-state code at this+0x60 — dispatching state handlers or disabling dialog control 1185 and writing UI state 2 into the other object (a2+0x364). Part of the UI/message timing state machine.

**Guard conditions:** Entire body is gated on `sub_617F80(this) >= 0.334` — smaller deltas skip all processing. Inside, the countdown this+0x50 is clamped: > 45.0 → forced to 45.0; < -15.0 → forced to -17.0; otherwise left as decremented. The pending-state machine runs only when this+0x60 is nonzero AND this+0x208 >= this+0x58; then: v4==1 → sub_47F2F0, v4==2 → writes 2 to (a2+0x364) and `EnableWindow(GetDlgItem(hDlg,1185), 0)`, v4==3 → sub_4886D0; all dispatch paths then set this+0x50 = -13.0 and this+0x60 = 0. If instead this+0x20C > this+0x5C - this+0x58, or (old this+0x50 > 0 && new value <= 0), the timer and state code are reset to 0.
