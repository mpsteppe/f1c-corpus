## sub_4E33D0_004e33d0 — build ".DDS" name and load resource; store fetched values

**Summary:** Builds a texture/resource name from the object's string (falling back to the global WindowName when that pointer is null), copies it into a local buffer, strips any existing extension by truncating at the last '.', appends ".DDS", and loads it through sub_5E7000 using the global resource context dword_FB1CE0. Loader outputs (v12, v11) are stored to this+0x14 and this+0x18, and this+0x20 is set to 8; on first-load failure the string helper runs on the buffer instead.

**Called by:** (none static — top-level or indirect-only)

| this | 0x14 | RW | — | Receives loader output v12 (one fetched dimension/value, e.g. width) |
| this | 0x18 | RW | — | Receives loader output v11 (second fetched dimension/value, e.g. height) |

**Written-by note (persistence):**
- this 0x14: Written unconditionally at the end of every invocation with the loader output v12; an external poke survives only until the next call overwrites it.
- this 0x18: Written unconditionally at the end of every invocation with the loader output v11; an external poke survives only until the next call.
- this 0x20: Written unconditionally (constant 8, and again in the success path); an external poke does not survive the next call.

**Guard interpretation:** If the name pointer at this+0x0 is ZERO, the object's string is not used — WindowName is substituted before strcpy; if NON-ZERO, the object's string is copied as-is. Additional branches: the backward scan truncates at '.' only if a dot exists after the buffer start (otherwise the name is left intact); and the first sub_5E7000 result gates the success path (nonzero → second load with a2 and `*v8 = 8`) vs the failure path (zero → string helper on ArgList). The tail writes (`*v8 = 8`, this[5] = v12, this[6] = v11) execute unconditionally.
