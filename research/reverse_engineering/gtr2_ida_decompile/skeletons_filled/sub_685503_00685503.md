## sub_685503_00685503 — link traversal with weight adjustment

**Summary:** Given node a2, follows its link record (node+0x48 indexes the link array at this+0x18) and returns the linked node index while adjusting a weight in/out parameter (a3 and/or a4). Handles three link type tags: 0x10100000 (single counterpart, negates *a3), 0x20400000 and 0x20500000 (two parallel half-lists, walks both directions checking an object-table eligibility bit and an unvisited marker). Returns -1 when the node has no link, is already visited, or no valid direction is found.

**Guard conditions:** Return -1 if node[a2]+0x48 == -1 (no link) or node[a2]+8 != -1 (already visited), or if the link's masked tag is none of 0x10100000 / 0x20400000 / 0x20500000. Tag 0x10100000: counterpart returned unconditionally (if a3 given, *a3 negated). Tags 0x20400000/0x20500000: a candidate direction passes only when the paired node has node+8 == -1 AND the object entry at *(this[4] + 4*(node+4)) has bit 0 of byte +5 set; that direction's first entry is returned and the weight at node+0x20 is folded into *a3 (0x205) or *a4 (0x204). After both directions fail: 0x205 with equal entries v7[2][v13] == v7[2][v13+v15] → *a3 doubled and first entry returned; otherwise -1.
