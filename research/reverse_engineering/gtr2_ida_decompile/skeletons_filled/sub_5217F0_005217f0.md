## sub_5217F0_005217f0 — Pose/distance/elevation validity gate

**Summary:** Compares an object pose (this[0..5] = position + orientation components) against a candidate pose (a2 for position, a3/a4/a5 for orientation). Returns true immediately when the orientation components differ beyond 0.1/0.1/0.05235987755982988 (3 degrees), or when the candidate is at least 50 units away (squared distance >= 2500.0); returns false when no reference point a6 is given or the candidate is closer than 1 unit (squared distance < 1.0). Otherwise it aggregates four global state-flag entries, computes the horizontal distances from a6 to both points, and finally reports whether the elevation slope to a2 differs from that to this by at least 0.001745329278001762 (0.1 degree).
