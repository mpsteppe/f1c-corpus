## sub_67B390_0067b390 — info getter: palette (PLTE)

**Summary:** Retrieves the palette from the info structure: requires the PLTE validity bit (0x8 at info+8), writes the palette pointer (info+0x10) and the 16-bit entry count (info+0x14) through the two output pointers, and returns the value 8. Returns 0 without writing when the png struct, info pointer or primary output pointer is NULL, or PLTE is not valid.

**Guard conditions:** Returns 0 if a1 (png struct) is NULL, a2 (info) is NULL, validity bit 0x8 at info+8 is clear, or a3 (palette output) is NULL. When these pass, the palette pointer from info+0x10 is stored to *a3 and the 16-bit count from info+0x14 to *a4 (a4 itself is not NULL-checked), and the function returns 8 (the PLTE validity value) as its success indicator.
