## sub_5D8400_005d8400 — Apply pending scale to matrix rows

**Summary:** If bit 1 of the flag word is set, clears it and scales the three matrix rows in place: row 0 (this[1..3]) by this[24], row 1 (this[5..7]) by this[25], row 2 (this[9..11]) by this[26]. Otherwise it is a no-op that just returns the flag word.

**Guard conditions:** Single branch: `(*(_DWORD *)this & 2) != 0`. Bit 1 set → PASS: clears bit 1, multiplies the nine row elements by the stored per-row scale factors and returns the updated flag word. Bit 1 clear (or any value without bit 1) → BLOCKED: nothing is written, the matrix and flag word are left exactly as they were.
