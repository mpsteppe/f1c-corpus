## sub_5FC620_005fc620 — Three-way float-key comparator (callback)

**Summary:** Classic comparison callback (qsort/sort style): takes two pointers, dereferences each to an object and compares the float at object offset 0x10, returning 1 when the first is greater, 0 when equal, -1 when less. Suitable for sorting object lists by that single float key.

**Guard conditions:** No state or side effects — pure comparator. First test: key(a1) > key(a2) → returns 1 (ordering decided). Second test: key(a1) >= key(a2) → returns 0 (equal). Otherwise returns -1. Nothing is blocked or skipped; all paths return an ordering code. (Note: if either key is NaN both comparisons fail and the result is -1.)
