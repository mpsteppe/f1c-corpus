## sub_685050_00685050 — grid cell node resolver

**Summary:** Looks up the node index for 2D cell (a3, a4) in an index array (base a2). If the cell is unset (-1) it assigns a node: node a5 directly claims the cell when its placement fields (+0xC/+0x10) are still -1; otherwise a conflict helper (sub_681AAA) picks a node using the node's double weight at +0x20. Returns the cell value.

**Guard conditions:** If cell value *v5 != -1 → no work, return existing value (cache hit). No path blocks the caller entirely; all branches end by returning *v5.
