## sub_609B00_00609b00 — Setting setter with change notification

**Summary:** Indexed setting setter: a2 (1–6) selects one of six value slots at this+204/208/212/220/224/228, writes a3 when the value actually changes, and — when the enable flag at this+236 is set — notifies the global manager dword_FB40C8 through its vtable slot +268 with (this+240, a2, new value). Returns whether a change occurred while notifications are enabled.

**Guard conditions:** Dispatch on a2: values 1–6 map to the six slots; any other a2 takes the default branch, which performs no write/notification and returns `0 & *(BYTE*)(this+236)` (always 0). For a matched case, the slot is written and the notification path (v3=1) only when the new a3 differs from the stored value; identical values change nothing and return 0. The virtual notification executes only when the enable flag at this+236 is nonzero; the return value is `changed AND enabled`, so 1 means a real change was applied and notification was attempted.
