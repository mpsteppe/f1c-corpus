## sub_4F8030_004f8030 — forward id lookup to active entries

**Summary:** Walks the object's 768-byte sub-record array (count this+0x120, base this+0x124) and calls the id-lookup helper sub_4F7DD0 on every entry whose byte +8 is non-zero, forwarding the caller's id a2; returns the entry count.

**Called by:** sub_4FA870 (004fa870), sub_4FA940 (004fa940)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x120 | R | — | sub-record count, used as loop bound and returned |
| this | 0x124 | R | — | base pointer of the 768-byte-stride sub-record array |

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

|---------|------|---------|
| 004f7dd0 | sub_4F7DD0 | per-entry id lookup; on a match it tail-jumps into the shared 004F59C0 code |

**Guard conditions:** Only the entry flag matters for dispatch: byte +8 of each 768-byte record must be non-zero for sub_4F7DD0 to be called (entries with a zero flag are skipped). The loop itself runs only while the count at this+0x120 is positive; zero/negative count returns immediately with nothing dispatched.
