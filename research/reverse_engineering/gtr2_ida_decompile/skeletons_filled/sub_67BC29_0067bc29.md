## sub_67BC29_0067bc29 — row gamma correction (lookup-table application)

**Summary:** Applies the gamma correction tables to one decoded row: 8-bit samples (and packed 2/4-bit gray samples, expanded via replicated-nibble lookups) are mapped through a 256-byte table, while 16-bit samples are mapped through a two-level 16-bit table. Alpha bytes are skipped and palette rows are left untouched.

**Called by:** sub_67CA0D (0067ca0d)

| this | 0x9 | R | — | bit depth — 2/4/8 select the byte-table paths, 16 selects the two-level table path |

**Guard conditions:** Outer gate: requires (bit depth ≤ 8 AND the byte lookup table a3 is non-NULL) OR (bit depth == 16 AND the two-level table a4 is non-NULL); if the matching table is absent the function returns without modifying the row. Inside, color type drives the pattern: gray rows use one sample per pixel (packed 2-bit/4-bit samples are expanded through the byte table with nibble replication, 8-bit directly), RGB rows map three bytes per pixel, gray+alpha maps only the gray byte, RGBA maps three bytes and skips the alpha byte. Palette rows and types without a case match are not touched. The 16-bit path indexes the two-level table as [second sample byte shifted right by a5][first sample byte] with 16-bit entries, writing results back big-endian.
