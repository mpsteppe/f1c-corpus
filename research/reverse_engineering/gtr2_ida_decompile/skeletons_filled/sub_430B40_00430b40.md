After the frame body, if sub_473630(&dword_B6CBA8) is again true the loop returns 0 (exit request). When byte_FADD28 is zero, a conditional block runs: if v3 is set, sub_414DD0(&dword_91BF20) fires only when sub_473630(&dword_B6CBA8) is false OR sub_4745A0(&dword_B6CBA8) is true; if v3 is clear, sub_414DD0, sub_51E980, sub_54AB10, sub_5206C0 and sub_4E8030 run unconditionally. byte_B72DB4 != 0 enables the sub_53DCD0 call. On loop exit by state change: state 4 returns 0 with no message; state 6 returns 1 silently; any other state returns 1 after logging "Next state %d was not expected" when the log gate (sub_5612D0) passes.
