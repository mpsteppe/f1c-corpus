## sub_6A6C14_006a6c14 — CollectSpecialObjectIndices

**Summary:** Scans all this[3] objects and collects the indices of those selected by the type predicate (sub_6A2293 nonzero) or type 0x72100000/0x11000000 into the array at this[276], storing the count in this[288] and returning the bitmask 1 << count. Returns -1 when more than 12 objects qualify.

**Called by:** sub_6AD36C (006ad36c)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0xC | R | — | this[3]: number of objects in this[6] |
| this | 0x18 | R | — | this[6]: object array; each object's type dword is tested |
| this | 0x450 | RW | — | this[276]: array receiving the indices of qualifying objects (capacity 12) |
| this | 0x480 | RW | — | this[288]: number of collected indices, written at the end |

**Written-by note (persistence):**
- this 0x450: the first v1 slots are written on every call (v1 = number of qualifying objects); entries beyond v1 are left untouched from the previous call. An external poke survives only if the same slot is not rewritten next call.
- this 0x480: rewritten on every call with the collected count (0 when none); external pokes do not survive.

**Guard conditions:** this[3] == 0 → no scan: this[288] = 0 and return 1 (bitmask 1<<0). An object is collected only when sub_6A2293(type) != 0 or type == 0x72100000 or type == 0x11000000; all others are skipped. BLOCK: more than 12 qualifying objects (v1 >= 0xC) → return -1 without completing. PASS: scan ends → this[288] = count, return 1 << count.
