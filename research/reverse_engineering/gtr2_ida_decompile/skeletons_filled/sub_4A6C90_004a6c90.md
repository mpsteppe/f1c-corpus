## sub_4A6C90_004a6c90 — scalar deleting destructor / object cleanup

**Summary:** Standard MSVC scalar deleting destructor wrapper: calls the object's cleanup routine (sub_4922B0), then frees the object memory when the delete flag bit is set. Returns the object pointer.

**Called by:** (none static — top-level or indirect-only)

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 004922b0 | sub_4922B0 | First-stage destructor: releases the object's internal resources/state |
| 006308d3 | j__free | Frees the object memory block when the delete flag is set |

**Guard conditions:** `a2 & 1` checked after cleanup. If bit 0 set → `j__free(Block)` is called (full delete). If bit 0 clear → memory is NOT freed (destructor-only form). No other branches; `Block` is always returned.
