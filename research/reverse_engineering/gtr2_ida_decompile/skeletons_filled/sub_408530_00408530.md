## sub_408530_00408530 — scalar deleting destructor

**Summary:** MSVC scalar deleting destructor: runs the object destructor via sub_408550, then frees the object memory if the low bit of the flags argument is set.

**Called by:** (none static — top-level or indirect-only)

**Guard conditions:** Checks `(a2 & 1) != 0`. If the low flag bit is set, the object memory (`Block`) is freed after destruction; otherwise the block is only destructed and returned to the caller (stack/embedded object case).
