## sub_6559A2_006559a2 — Vertex packer to 10:10:10:2 signed dwords (with error diffusion)

**Summary:** Converts one span of float attribute quads (source buffer obtained through optional this[0x54]/this[0x10] pre-passes) into packed 32-bit dwords — three signed 10-bit fields clamped to ±511 plus a 2-bit field clamped to ±3 — writing one dword per iteration through the this[0x20] buffer; fractional remainders are diffused into the float buffer at this[0x5C] when set. Traversal direction follows a2's parity and that parity is stored/returned via this[0x7C].

**Guard conditions:** Three gated pre-passes, each keyed on a this field: this[0x54] ≠ 0 → a4 = sub_64EB2A(this,a4); then this[0x10] ≠ 0 → a4 = sub_650093(this,a4); this[0x5C] ≠ 0 → sub_6503AF(this,a4) once before the loop, and the in-loop dithering writes only happen in that case. The main loop requires this[0x68] ≠ 0 and runs this[0x68] iterations; per iteration the first three components are clamped to ±511 and the fourth to ±3; if the fourth component's clamped value is ≤ -3 the loop aborts immediately (break — remaining elements of the span are not written) and the function returns this[0x7C]. With this[0x68] == 0 the function returns this[0x7C] without writing output.
