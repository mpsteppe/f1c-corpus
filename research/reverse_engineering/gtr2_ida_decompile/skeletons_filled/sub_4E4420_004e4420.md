## sub_4E4420_004e4420 — Rotated rectangle corner computation + 4-corner submission

**Summary:** Advances an angle (this+0x14) toward a target angle (this+0x18) using rate this+0x1C / this+0x20 with 360-degree wrap handling, then computes the four corners of an oriented rectangle (half-diagonal derived from this+0x44/this+0x48) centered at (this+0x40, this+0x3C) and submits each corner through sub_5EDF20.

**Called by:** sub_4E6080 (004e6080)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x4 | R | — | target object/handle passed as first argument to every sub_5EDF20 call; null makes the function a no-op |
| this | 0x10 | R | — | interpolation mode: 1 = positive direction, 0 = negative direction, any other value skips the angle adjustment |
| this | 0x14 | R | — | current angle in degrees (interpolated) |
| this | 0x18 | R | — | target angle in degrees |
| this | 0x1C | R | — | rate/numerator advancing the angle |
| this | 0x20 | R | — | rate denominator (rate per frame = 0x1C / 0x20) |
| this | 0x3C | R | — | rectangle center Y (used in the corner offsets) |
| this | 0x40 | R | — | rectangle center X (used in the corner offsets) |
| this | 0x44 | R | — | rectangle width W; half-diagonal = sqrt(W²+H²)/2 |
| this | 0x48 | R | — | rectangle height H; contributes to half-diagonal and corner angles |

**Functions called:**

| 0063099c | __ftol2 | compiler runtime: float/double → 64-bit integer conversion used to truncate the cos/sin corner coordinates |
| 00631ad0 | __CIasin | inverse sine used to derive the half-angle v14 = asin((W/2)/half-diagonal) |

**Guard conditions:** Outer guard: if this+0x4 is zero the function returns immediately (no drawing). Mode dispatch on this+0x10: value 1 takes the positive-direction branch, value 0 the negative-direction branch; any other value leaves the angle unadjusted. Inside each branch an FPU comparison of this+0x14 vs this+0x18 (flags c0|c3) selects the direct delta or the 360-degree wrapped delta — this decides how the interpolation wraps around the 0/360 boundary.
