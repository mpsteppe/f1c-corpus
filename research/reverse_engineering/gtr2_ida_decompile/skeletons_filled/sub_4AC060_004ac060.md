## sub_4AC060_004ac060 — HandleActionCode

**Summary:** Switches on the action/state code at this+0x360: two large case groups (0x10A–0x115 and 0x12B–0x1C4) query the dword_B6E090 interface's virtual slot +0x1C with argument 10 or 6 respectively, invoking sub_4A0FF0 when the query returns non-zero; afterwards three exact codes (307/427/452) set the flag byte at this+0x330 to 1. Returns 0.

**Called by:** sub_4B1D5C (004b1d5c), sub_4B2950 (004b2950)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x330 | RW | 1 | Flag byte set to 1 when the action code is exactly 307, 427 or 452. |
| this | 0x360 | R | — | Action/state code driving the switch and the flag test. |

**Written-by note (persistence):**
- this 0x330: Written only on the three matching codes (always to literal 1); for any other code the byte is left untouched, so an external poke survives until one of those codes runs.

**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|
| this | 0x360 | == | 307 | Exact action code that sets the this+0x330 flag byte. |
| this | 0x360 | == | 427 | Exact action code that sets the this+0x330 flag byte. |
| this | 0x360 | == | 452 | Exact action code that sets the this+0x330 flag byte. |

**Guard interpretation:** Only action codes in the two switch groups reach the interface query (0x10A–0x115 use argument 10, 0x12B–0x1C4 use argument 6); all other codes fall to default and nothing runs. sub_4A0FF0 is called only when the query result is non-zero. The this+0x330 flag is set to 1 only for codes exactly 307, 427 or 452 — every other code leaves it unchanged.
