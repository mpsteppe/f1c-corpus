**Guard interpretation:** If the list head (v27) is null the whole row build is skipped and only dword_BE1BD0 is updated. If sub_48F670() returns < 1 the mode flag a1+0x258 is cleared. Numeric columns are left blank unless their value is positive and above the per-item threshold; the weight column uses the kg format unless dword_B72454 == 1, which switches to pounds (x2.2). A row is only added when the a1+0x25C/0x260 conditions pass and sub_4CE310 returns 0. The final ordering section branches on the caller's mode value (0 vs 1) combined with `*(int *)(a1 + 0x258) <= 0`, issuing different sub_4D41C0 column-order pairs in each case.

**String literals referenced (deterministic):**
