## sub_433900_00433900 — Car setup file writer (garage save)

**Summary:** Serializes the car's complete garage setup into the setup file: the [GENERAL] notes, [BASIC] sliders, and all sectioned suspension/engine/driveline/controls/pitstop/per-wheel settings, enforcing an ascending chain on the gear values. On success it clears the object's modified flag; on open failure it logs "Failed to open %s for writing".

**Written-by note (persistence):**

- this 0x0: written to 0 only on a successful save (after the file is written); an external poke of nonzero forces one save and is then cleared.
- this 0x1744: conditionally rewritten on each save (raised to the gear 1 value when smaller); a poke survives only while it is >= the preceding gear value.
- this 0x1784: conditionally rewritten on each save (raised to the gear 2 value when smaller); survives while >= the chain value.
- this 0x17C4: conditionally rewritten on each save (raised to the gear 3 value when smaller).
- this 0x1804: conditionally rewritten on each save (raised to the gear 4 value when smaller).
- this 0x1844: conditionally rewritten on each save (raised to the gear 5 value when smaller).
- this 0x1884: conditionally rewritten on each save (raised to the gear 6 value when smaller).

**Guard conditions:** The function returns early (0) when it is not forced (a5 == 0) and the modified/dirty byte at this+0x0 is 0 — i.e. only a forced save or a dirty object writes the file. The write path runs only when sub_6146B0 opens the file successfully; otherwise the failure path logs "Failed to open %s for writing" and returns -1. The notes loop repeats while a chunk is still 128 bytes long (breaks when strlen < 0x80), the per-gear loop writes a line only when the byte at the gear block +8 is set (gears 1..7), and the per-wheel loop covers exactly 4 wheels via the jump table cases 0..3. The ascending chain raises each subsequent gear value (0x1744..0x1884) to the previous value whenever it is smaller.
