## sub_521240_00521240 — In-place string title-caser (capitalize word starts)

**Summary:** Walks a NUL-terminated (char) buffer in place: uppercases the first character if it is a lowercase ASCII letter, then for every subsequent character uppercases it when the preceding character is not an ASCII letter and lowercases it when the preceding character is a letter. Net effect: convert a string to title case / "word capitalisation".

| this | 0x1 | RW | — | Second byte of the buffer; serves as loop-start character and the current character position that is conditionally re-cased on each iteration |

**Written-by note (persistence):**

- this 0x1: written conditionally on each loop iteration (only when in 97..122 via −32, or 65..90 via +32). In-place transform of the caller's buffer; an external poke survives until the next call.
