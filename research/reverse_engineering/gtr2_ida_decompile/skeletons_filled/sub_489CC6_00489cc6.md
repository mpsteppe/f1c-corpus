## sub_489CC6_00489cc6 — crt_isalpha

**Summary:** CRT character-classification helper equivalent to `isalpha`: refreshes the thread locale when the passed locale pointer differs from the current one, then tests the character against the _ISALPHA bit mask (0x103) either via the single-byte ctype table or the multithreaded __isctype_mt path. Classic MSVC CRT isalpha implementation.

**Guard interpretation:** If the incoming locale pointer `a1 != *dword_16C9A50`, `__updatetlocinfo()` is invoked first (locale refresh — does not block anything). Then `*(a1+0x28) <= 1` PASSES the single-byte path: returns `table[a2] & 0x103` (_ISALPHA mask). Otherwise the call is diverted to `__isctype_mt(a1, a2, 259)` (0x103) for the multibyte/threaded case. Result is the character's alpha classification mask (nonzero = isalpha).
