## sub_6A309B_006a309b — InstantiateFourSlotObject

**Summary:** Allocates and initializes a fixed 4-slot object (init flag 0x10000004), rebinds entries of the this[5] array whose owner field equals this[33] so they point at the new object, allocates 4 child slots via sub_681AAA, registers the object via sub_681997, then remaps slot indices back to original indices inside the this[6] entry lists. Part of the object/asset loading system.

**Called by:** sub_6AD36C (006ad36c)

| this | 0xC | R | — | entry count saved into v17; number of this[6] entries processed by the final remap loop |

**Guard conditions:** Allocation/init failures BLOCK: null object after sub_681186 or any sub_681AAA slot returning -1 → release object and return -2147024882 (0x8007000E); negative sub_6811D1 or sub_681997 → release object and return that error. First loop only rewrites entries where entry+4 == this[33]; others are ignored. Remap loop skips null this[6][k], skips entries whose +12 count is 0, and skips entries whose first list element does not belong to this[33]. PASS: all loops complete → return 0.
