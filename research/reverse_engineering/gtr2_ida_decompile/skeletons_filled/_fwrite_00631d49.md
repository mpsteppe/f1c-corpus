## _fwrite_00631d49 — CRT fwrite

**Summary:** ANSI CRT `fwrite`: writes `ElementCount * ElementSize` bytes from a caller buffer to a FILE stream — first into the stream's own buffer, then via per-character helper or a direct OS write for large blocks. Returns the number of complete elements written.

**Called by:** sub_631E50 (00631e50), _fputs (00634eb4)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | R | — | First byte of the caller's source buffer; read for the per-character output path (`sub_637022(*(char *)Buffer, Stream)`) |

**Written-by note (persistence):**
- this 0x0: read-only here — the source buffer is caller-owned and never modified by fwrite; nothing in this function writes it, so any external contents persist untouched.

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 00634487 | __flush | Flushes the stream before the direct-write path; nonzero return aborts with partial count |
| 00635560 | _memcpy_0 | Copies min(requested remaining, Stream->_cnt) bytes from the caller buffer into the stream buffer at Stream->_ptr |
| 00637022 | sub_637022 | Per-character output helper (putc-style): emits one byte to the stream and returns -1 on failure |
| 00638801 | sub_638801 | Direct OS-level write of a block to the stream's file descriptor; returns -1 on error |

**Guard conditions:** `if (!(ElementCount * ElementSize)) return 0;` — zero-size request exits immediately. `(Stream->_flag & 0x10C) != 0` picks `Stream->_bufsiz`, else default 4096. Buffered copy path runs only if `(Stream->_flag & 0x108) != 0` and `Stream->_cnt` is nonzero. Small requests (`v5 < bufsiz`): per-character helper; `== -1` aborts with partial count; after each char `if (!v5) return ElementCount` (full success); a non-positive `_bufsiz` is clamped to 1. Large requests: if buffered (`0x108`) and `_flush` fails → partial count; else direct write of `v5 - v5 % bufsiz` bytes — `-1` sets stream error flag 0x20 and returns partial; otherwise loops. Final returns are `(requested - remaining) / ElementSize` (elements written).
