## sub_67AB08_0067ab08 — PNG signature + chunk reader/dispatcher (IHDR/PLTE/IDAT/IEND/gAMA/sRGB/tRNS)

**Summary:** PNG chunk reader: verifies the 8-byte signature (padding to `this+0x11C` when fewer than 8 bytes are read, raising "Not a PNG file"/"PNG file corrupted by ASCII conversion"), then loops reading 4-byte chunk lengths and 4-byte chunk type tags into `this+0x10C`, dispatching `IHDR`, `PLTE`, `IDAT`, `IEND`, `gAMA`, `sRGB`, `tRNS` and skipping unknown chunks; on `IDAT` it checks that IHDR (`this+0xFC` bit 1) and, for palette type 3, PLTE were seen, sets the "IDAT seen" flag (bit 4 in `this+0x58`) and stores the IDAT length in `this+0xFC`.

**Guard interpretation:** (1) Signature: `v3 = *(this+0x11C)`; only when `v3 < 8` is the padding read (`8 - v3` bytes); `sub_679F8A` mismatch → "Not a PNG file" is raised (and additionally "PNG file corrupted by ASCII conversion" when `v4 < 4` and the secondary compare also fails); then the counter is set to 8. (2) Chunk loop: tag compared in this order — the first handler compares against the 4-byte value at `off_16C9B28` (handler `sub_6BA724`) → `PLTE` (`sub_6BA906`) → `IEND` (`sub_6BAA21`) → after the first loop breaks, `IDAT` (break to the final block); non-IDAT tags go to `gAMA` → `sRGB` → `tRNS` → unknown-chunk skip (`sub_6BADE4`). Dispatch continues until the `IDAT` tag is seen (`if (*v6 == *(_DWORD*)"IDAT") break;`). (3) On IDAT: `(result & 1) == 0` (IHDR flag missing) → "Missing IHDR before IDAT"; `color type == 3 && (result & 2) == 0` → "Missing PLTE before IDAT". (4) Final: `result |= 4`, IDAT length stored to `this+0xFC`, and `result` (the flag dword) is returned.
