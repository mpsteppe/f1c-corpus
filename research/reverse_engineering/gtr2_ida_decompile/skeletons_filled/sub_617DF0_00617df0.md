## sub_617DF0_00617df0 — performance-counter timer initialization

**Summary:** Timer setup using the Windows performance counter: when a2 == 1 and the frequency query succeeds it captures the current counter into +0x18/+0x1C and the frequency into +0x0; then it snapshots that counter pair into +0x20/+0x24, zeroes the elapsed accumulators (+0x28/+0x2C) and the seconds field (+0x10), and stores the reciprocal tick rate (2^32 / frequency) at +0x8. The a2 value is kept at +0x48 as the timer mode.

**Called by:** sub_4787F0 (004787f0), sub_489700 (00489700), sub_4E1950 (004e1950), sub_58FBA0 (0058fba0)

**Written-by note (persistence):**
- this 0x0: Written only when a2 == 1 and QueryPerformanceFrequency succeeds; otherwise stale value reused — an external poke survives when the init branch is not taken.
- this 0x8: Recomputed each call from the frequency value; poke overwritten by the next call.
- this 0x10: Reset to 0.0 on every call; poke overwritten by the next call.
- this 0x18: Written when the init branch runs (a2 == 1 + successful frequency query); poke survives otherwise.
- this 0x1C: Written when the init branch runs; poke survives otherwise.
- this 0x20: Written on every call from the +0x18/+0x1C pair; poke overwritten by the next call.
- this 0x24: Written on every call from the +0x18/+0x1C pair; poke overwritten by the next call.
- this 0x28: Reset to 0 on every call; poke overwritten by the next call.
- this 0x2C: Reset to 0 on every call; poke overwritten by the next call.
- this 0x48: Written from a2 on every call; poke overwritten by the next call.

**Guard interpretation:** The re-capture branch is entered only when a2 == 1 AND QueryPerformanceFrequency returns non-zero; otherwise the existing counter/frequency fields are kept and only the snapshot/scale fields are recalculated. The sign test on this 0x0 costs nothing to branch on either way — when the dword is negative (bit 31 set, i.e. interpreted as unsigned large), 2^32 is added so `4294967296.0 / v5` uses the correct magnitude; non-negative values divide directly.
