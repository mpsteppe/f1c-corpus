**Guard conditions:** The switch value comes from `sub_5A3D10(a2+5, a2[14])`; any value outside 1..15 falls to default and clears the flag. Case 1 gates on: vtable+64 truthy, vtable+164 result `< this[25]`, `this+97` nonzero, the 16-byte id comparison equal, and vtable+120 success; failures return early. Case 2 uses the node from `sub_5A6A00` and updates the ping time to `(now - stored) * 0.5`. Case 3: when a stored name exists (`strlen(this+104)` nonzero) the formatted address is compared with `strcmp`; a mismatch sends type 5 instead of 4. Case 8 loops decoding packet fields until 0; a decode result other than 4 returns early; `sub_5A4330(this) == 4` selects the flag arrangement passed to vtable+180. Case 9 returns early when the packet field is nonzero. Case 12 computes the ping as `(now - field) * 1000 / 2`. Case 14 returns early when the vtable+8 lookup fails.
