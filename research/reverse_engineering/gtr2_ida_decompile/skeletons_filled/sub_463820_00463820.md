## sub_463820_00463820 — key/button code to display-name lookup

**Summary:** Returns a pointer to a name string for the code in a1[1], selected by the group in a1[0]: group 1 uses the 9-byte-stride table asc_757CB0 (codes < 200) and group 0 uses the keyboard tables aPause (16-byte stride) / asc_758958 for high codes or generates an uppercased name via String (sub_45E670 + __strupr). Falls back to WindowName when no entry matches, and returns NULL for any other group.

**Called by:** sub_523AE0 (00523ae0)
