## sub_5D85D0_005d85d0 — Two-path geometry builder with mirror flag

**Summary:** Reads a set of integer geometry values from the object (offsets 0x64–0x78), obtains a float via sub_5E4DB0, and dispatches to one of two builder routines: sub_5ABBA9 when the offset relation `v5 + (v7>>1) == v3 && v22 + (v4>>1) == v6` holds (simple path), otherwise sub_5ABC3F with combined extent arguments. Finally, if flag bit 0x10 of the object byte at 0 is set, the first output float is negated.
