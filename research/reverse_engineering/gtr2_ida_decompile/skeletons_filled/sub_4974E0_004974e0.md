## sub_4974E0_004974e0 — CopyNameToGlobalAndReset

**Summary:** Calls sub_4CE170(this) and, when it returns a non-null string, copies it character-by-character (including the terminator) into the global buffer at byte_B6DC90; then unconditionally zeroes the dword at this+0x254.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x254 | RW | 0 | dword slot (this[149]) reset to 0 after the copy |

**Written-by note (persistence):**
- this 0x254: written unconditionally with 0 at the end of every call; since it is re-zeroed on each invocation, an external poke cannot survive the next call.

**Globals referenced:**

| Address | Name | R/W | Role |

**Functions called:**

|---------|------|---------|
| 004ce170 | sub_4CE170 | called as sub_4CE170(this) — first as the copy gate, again to obtain the string pointer that is copied into byte_B6DC90 |

**Guard conditions:** `if (result)` — the first sub_4CE170(this) result. Non-null PASSES: the second call's string is copied into byte_B6DC90 until the NUL terminator (do/while on the copied char). Null BLOCKS the copy entirely. After the branch, this[149] = 0 is always executed; the function returns the string pointer (or the null gate result).
