## sub_54D140_0054d140 — Normalize axis input and write scaled value into active slot

**Summary:** Stores the raw float argument a2 into this+0xC on every call, and — depending on the mode at this+8 — additionally writes a value into the slot selected by that mode: mode 0 uses the this+0xD4/this+0xD8 pair, mode 1 uses this+0x34/this+0x38. When the sub_405250() predicate returns true, the normalized value (a2 + 1.0) * 0.5 is multiplied by the slot's float coefficient (slot → +0x3C → +0x14) and written as a double at the slot base. Looks like distribution of an axis/control value to a device-side slot.
