## sub_489CE0_00489ce0 — RecursiveListFree3

**Summary:** Recursive destructor for a singly-linked list (same shape as sub_482EE0/sub_489B80): walks the list via the next pointer at offset 0, recursively destroys each node's child object at offset 8, and frees each node with j__free; stops at the first node whose flag byte at offset 0x15 is nonzero. Another instantiation of the list cleanup helper.

**Guard conditions:** Loop continues only while `result == 0`, where `result` is the byte at node+0x15. If the initial node's +0x15 flag is nonzero, the loop body never runs — nothing is freed and the flag value is returned (BLOCKED). Once the next node reached has +0x15 != 0, the loop exits and that flagged node is left allocated (it is never freed because free() happens at the top of the following iteration).
