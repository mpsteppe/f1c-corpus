## sub_5A47F0_005a47f0 — ShutdownThreadAndJoin

**Summary:** Thread shutdown sequence: retries sub_5A4030 (resume/update) up to 10 times with 250 ms Sleep pauses, then if the thread handle at this+0x8 is set it acquires the mutex at this+0x14 (timeout this+0x18), sets the byte flag at this+0x10 to 1 under the lock, releases the mutex, waits for the thread to exit (infinite), closes the handle, and zeroes this+0x8 and this+0xC.

**Called by:** sub_5A01D0 (005a01d0)

| this | 0xC | RW | 0 | Companion thread state dword zeroed on the shutdown path |
| this | 0x10 | RW | 1 | Byte flag set to 1 (under the mutex) on the shutdown path; never cleared here |
| this | 0x14 | R | — | Mutex handle acquired with WaitForSingleObject and released with ReleaseMutex |
| this | 0x18 | R | — | Timeout in milliseconds for the wait on the this+0x14 mutex |

**Written-by note (persistence):**
- this 0x8: Written conditionally (zeroed) only when the thread handle was nonzero and CloseHandle ran; a poke survives calls where the handle is 0.
- this 0xC: Written conditionally (zeroed) only on the shutdown path (thread handle nonzero); otherwise untouched.
- this 0x10: Written conditionally (set to 1) only on the shutdown path inside the mutex; never cleared by this function, so a poke of 0 survives until this shutdown runs again.

**Guard conditions:** (1) Retry loop: up to 10 iterations (`i < 10`); exits early when sub_5A4030 returns nonzero, otherwise Sleep(250) and retry. (2) this+0x8 == 0 (no thread handle) → whole shutdown block SKIPPED and the function returns 0. (3) Mutex: if this+0x14 is null or WaitForSingleObject returns neither 0 nor 128, v6 is set to 0 and the following `*v6 = 1` store is executed on that pointer as decompiled (no guard shown); otherwise the flag at this+0x10 is set under the lock. (4) The mutex is released whenever this+0x14 is nonzero, then the thread join and CloseHandle run unconditionally on the shutdown path, zeroing this+0x8 and this+0xC; the function returns CloseHandle's result.
