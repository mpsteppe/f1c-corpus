## sub_56C5C0_0056c5c0 — Vehicle graphics asset loader (GTR/CAS/MAS resolution)

**Summary:** Loads the vehicle/team graphics assets for the selected car: derives candidate names from the vehicle record, resolves SEARCHPATH/MASfile entries from a vehicle definition file, and opens TEAM.GTR, _TEX/_ULTRA_TEX/_CPIT_ULTRA_TEX GTRs, the car CAS and BMP textures. On failure to open the derived CAS names it logs "Could not open %s" and unwinds all allocations and constructed objects.

**Guard conditions:** The whole body runs only when the first (register) argument v65 is non-null; otherwise the function returns immediately. The track GTR block executes only when the id lookup result (v139 via sub_5529A0 / sub_54B400) differs from -1.0; the ULTRA_TEX load requires byte_B71C00 != 0, the CPIT_ULTRA_TEX load requires byte_B71C18 != 0, and the "_2DW.CAS" suffixed name is only built when byte_B71194 == 0 and the base name is longer than 4 chars. The load aborts with "Could not open %s" when both sub_614460 CAS open attempts fail. In the candidate loop each name is only appended while fewer than 3 were collected (v113 < 3) and the a14 / v140 / STACK[0x1C10] sources are only used when non-empty; the list walk ends when the name matches via _stricmp or the list is exhausted (v140 = 0). Cleanup calls and frees are made only for non-null pointers (a1, a3, a4, Block, v136, v138, v141, vars0). The outer candidate loop is bounded at 81 iterations ((int)(v128 + 1) < 81).
