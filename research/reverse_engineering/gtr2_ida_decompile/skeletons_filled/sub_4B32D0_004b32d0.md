**Guard conditions:** If sub_4735A0() is true, the alternate branch runs: after sub_4744E0 fills the session structure, the caption is set only when sub_473900() is true; with v23 != 0 the laps caption is used, otherwise the "M:SS" time caption; then it returns. Otherwise, if the session-type index (*dword_B72314) equals 1 the WindowName text is displayed and the function returns. The laps branch (v15 = table[index]) runs only when byte_B729E8 != 0 AND byte_B722E4 == 0 AND the index != 4; within it the laps text appears only if the season section exists and "RaceLaps" is found. The time branch uses "RaceTimeScaled" scaled by table[index] when the key parses via sscanf == 1; when neither the season section nor the "DefaultScoring" section provides the key, the fallback table[index] * 120.0 is used. byte_B722E4 != 0 overrides the value with dword_B72A00 * 1440.0. The extra laps override at the end requires index == 4 AND byte_B722E4 == 0 AND "SceneOrder" present AND a valid record (dword_BE1CD8 + 396*dword_BE1CD4) AND its name field found in the section AND "RaceLaps" present.
