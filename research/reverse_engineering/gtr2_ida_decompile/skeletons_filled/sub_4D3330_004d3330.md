## sub_4D3330_004d3330 — HotspotModeSwitch

**Summary:** Reads a current point via sub_4DE540 and tests it against a rectangle derived from sub_4CFCC0/sub_4CFD30; when the point lies strictly inside, updates the mode at 0x10C (case 1→0, case 4 and 5 unchanged, default→1). Then re-applies the mode through virtual slot +0x2C and calls virtual slot +0x90; always returns 0.
