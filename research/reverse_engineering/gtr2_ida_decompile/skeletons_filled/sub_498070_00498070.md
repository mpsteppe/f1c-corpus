## sub_498070_00498070 — PopulateDSFileList (enumerate *.ds files into list control)

**Summary:** Refreshes a UI list control: enumerates files matching `*.ds` from the configured directory, strips extensions, inserts each entry with a type-dependent attribute byte (name length stored/displayed), marks the previously selected file, and stores the new selection back into the control (or resets to the default when nothing matches). Falls back to `WindowName` whenever a path/name is null.

**Guard conditions:** Entry clears `this+0x20C`; the previous selection is only taken when `sub_4CE170(this)` returns nonzero. Path text uses `Block[0]` if set, otherwise `WindowName`; trailing characters are stripped back to the last `\` only when `strlen > 0`. Each enumerated file's extension is stripped (loop stops at `.`); an entry is inserted only if the raw `Buffer` length is nonzero. Classification `sub_41D990(dword_B761EC, Buffer)` returning 3 or 4 switches the attribute byte from -77 to -67. If the new entry text equals the stored selection (`&v22[2]`), the selection is re-stored with the attribute prefix; after the loop, a nonzero selection string is applied via sub_4D4150, otherwise the default is selected via sub_4D4060.
