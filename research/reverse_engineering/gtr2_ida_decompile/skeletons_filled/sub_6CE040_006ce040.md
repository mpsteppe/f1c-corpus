## sub_6CE040_006ce040 — Duplicate per-record buffer edge blocks

**Summary:** For each of `this+0x24` records (stride 84 bytes at this+0xDC) recomputes `count = f1*f2 / this+0x140` and, for both the region A pointer array (this+0x1E4) and region B pointer array (this+0x1E8), walks `count` elements keeping the buffers periodic: copies the block at `count*(divisor+1)` to the start at index `-count`, and duplicates the head block at `count*(divisor+2)`.
