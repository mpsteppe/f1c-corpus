## sub_60AB20_0060ab20 — clear per-entry state fields and flag bits

**Summary:** Walks the fixed-stride entry array (base pointer at +0x16C, count at +0x168, entry stride 108 bytes) and zeroes four dwords in each entry (+0x2C, +0x30, +0x34, +0x38), then clears bits 0x800, 0x1000 and 0x10000 of the flags dword at offset 0.

**Written-by note (persistence):**
- this 0x0: written unconditionally (AND-masked) at the end of every call; bits 0x800/0x1000/0x10000 of an external poke would be cleared on the next call, all other bits survive.

**Guard interpretation:** this+0x168 <= 0 → loop skipped entirely, only the flags-dword bit clearing at offset 0 runs. this+0x168 > 0 → for each entry (counter 0..count-1, pointer advanced by 108 bytes per iteration) the dwords at entry+0x2C, +0x30, +0x34 and +0x38 are set to 0. The inner `counter >= count` tests shown by the decompiler are always false inside this loop (the loop condition guarantees counter < count), so the else path (entry pointer + index base) is always the one used.
