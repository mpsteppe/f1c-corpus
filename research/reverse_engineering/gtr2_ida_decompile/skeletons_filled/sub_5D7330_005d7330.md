## sub_5D7330_005d7330 — Set position and derive translation row

**Summary:** Stores the three input floats into the position slots at 0x48/0x4C/0x50 and then writes the translation row at 0x34–0x40: if the mode field at 0x44 equals 2 the inputs are copied straight through, otherwise the translation is computed as the rotation matrix (0x4–0x2C) multiplied by the stored position vector. Homogeneous element 0x40 is always set to 1.0.

**Guard interpretation:** If `this+0x44 == 2`, the PASS branch copies the raw inputs a2/a3/a4 directly into the translation slots 0x34–0x3C (no rotation applied). Any other value takes the else branch, which computes translation = rotation block · position vector (0x4/0x14/0x24 times 0x48, 0x8/0x18/0x28 times 0x4C, 0xC/0x1C/0x2C times 0x50).
