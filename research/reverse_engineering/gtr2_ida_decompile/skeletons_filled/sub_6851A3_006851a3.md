## sub_6851A3_006851a3 — 4-slot grid cell assignment for node quad

**Summary:** Takes up to 4 node indices (a3, -1-terminated) and a per-node bitmask array (a4), validates the masks against options in this+0x6C, then scans 16-byte cell records at a2 for a cell whose 4 slots can host the nodes: masked nodes are placed at their bit position (weight must match if occupied) and unmasked nodes at a weight-matching or free slot. Finally rewrites a3[0..3] with the placed values, invoking sub_685050 to resolve nodes that differ from the cell's stored slots. Returns 0 on success, 0x80004005 (E_FAIL) on validation failure.

**Called by:** sub_693B65 (00693b65)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x14 | R | — | pointer to the node struct array; node weight doubles read at node+0x20 (this[5]) |
| this | 0x6C | R | — | option/flag word (this[27]): bit 1 (&2) and bit 2 (&4) select mask-processing and zero-mask marking behavior |

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 00685050 | sub_685050 | grid cell resolver: called as (this, a2, v31 cell index, slot n, v30[n]) when the placed slot value differs from the cell's stored value; returns the node index to store in a3[n] |

**Guard conditions:** Leading count v36 = number of non -1 entries in a3 (max 4); if v36 == 0 → return 0 immediately. If (this[27] & 6) == 0 → masks cleared via memset and validation skipped. Otherwise: all-same-weight nodes collapse to one entry; when (this[27] & 4) and zero-masks exist: more than one zero-mask → E_FAIL; a mask already containing bit 8 → E_FAIL; the single zero-mask gets bit 8. Overlapping bits across masks → E_FAIL; v4 (zero-mask count) + number of distinct set bits > 4 → E_FAIL. Cell acceptance: masked nodes fit only if every set-bit slot is empty or holds an equal-weight node; unmasked nodes need an equal-weight slot or a free slot; any failure moves to the next cell (++v31); when all placed the cell loop breaks and the four a3 slots are finalized.
