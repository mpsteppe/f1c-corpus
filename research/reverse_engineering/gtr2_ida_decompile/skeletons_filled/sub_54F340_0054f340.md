## sub_54F340_0054f340 — Build 104-byte slot list from both tables and sync shadow copy

**Summary:** Serializes up to 104 slot bytes: first the primary table entries (base this+0x348, count this+0x688, byte flagged with 0x40 when its per-ID record flag is set), then the secondary table entries (base this+4, count this+0x344, byte flagged 0x80/0xC0). The bytes go either into a local stack buffer or into a rotated shared global buffer (off_9034A4, 848-byte slots, counter capped at 1023), initialized via sub_51B2A0. Afterwards the shadow copy at this+1680 is compared byte-by-byte; every difference (and any change of the total count at this+0x6F8) stamps the timestamp float at this+0x68C with dbl_FB1D18. Returns the number of bytes written (v2).

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x344 | R | — | Entry count of the secondary table (loop bound for the second fill pass) |
| this | 0x688 | R | — | Entry count of the primary table (loop bound for the first fill pass) |
| this | 0x68C | RW | — | Timestamp/dirty float: stamped with dbl_FB1D18 on any byte difference or total-count change |
| this | 0x6F8 | RW | — | Last total count: compared with v3 (count A + count B); stored when different |

**Written-by note (persistence):**
- this 0x68C: written only on change events (byte mismatch in the shadow compare or total-count change); an external poke survives until the next change event.
- this 0x6F8: written only when the newly computed total v3 differs from the stored value; an external poke survives until the total changes.

**Guard conditions:** 
- Buffer choice: `sub_4735A0() != 0` → local stack buffer v19 and mode flag 3; else shared buffer off_9034A4 and mode flag 0. The rotation (`++dword_82F4A0`, `off_9034A4 += 848`) happens only while `dword_82F4A0 < 1023`.
- Both fill loops break once `v2 >= 104` — at most 104 bytes are emitted.
- Table reads clamp out-of-range indices to -2 (`i < 0 || i >= count` → -2) instead of reading the table.
- The 0x40 / 0x80 / 0xC0 bits are OR-ed in only when `byte_925105[22616 * id]` is non-zero; otherwise the raw low byte (or 0x80 for pass 2) is stored.
- Shadow sync: a byte and the this+0x68C stamp are written only when the new byte differs from the shadow copy at this+1680; this+0x6F8 (and the stamp) are written only when it differs from v3; sub_4745E0 is called only when sub_4735A0() is true.
