## sub_4E2A20_004e2a20 — clear list: pop and virtual-call each node

**Summary:** Iterates a singly-linked list whose head lives at this+0x0: on each iteration it captures the current node, advances the head to the node's +0x68 link, and invokes the node's virtual function (vtable slot 0) with arguments (node, 1) — the classic "delete every remaining element" loop. Called from the destructor body sub_4E2110.

**Called by:** sub_4E2110 (004e2110)

**Written-by note (persistence):**
- this 0x0: Written every loop iteration (head advanced to the next node) and ends at 0 once the list is drained — an external poke to the head does not survive while a list remains; after the loop the field deterministically holds 0.

**Guard interpretation:** While the head pointer (this+0x0) is NON-ZERO the loop PASSES and processes the node: it loads node+0x68 into the head, then calls the node's virtual function (vtable[0])(node, 1). When the head is ZERO the loop is BLOCKED/finished and the function returns the last computed result. Because the check is re-evaluated each iteration, the loop drains the whole chain down to a null head.
