## sub_56D417_0056d417 — Build node/vertex acceleration tables and overlap lists

**Summary:** Two-part builder. First it allocates a per-node record array (12-byte records: node pointer, vertex count, 64-byte vertex entry array) for every node of the scene object passed via a3, fills each vertex entry with position data plus an initial/minimum potential value taken from the a2 point list (with optional scene-relative translation and a radius test), then links entries to triangles: after an array-processing pass, it binary-searches the entries on their Z component for each triangle's Z band, tests the normal side and neighbour normals, and stores a triangle pointer into the entry's +36 slot array. Second it allocates the 24-byte entry array (count a2[3], source a2[4]) and, in a two-pass count-then-fill scheme, gives each entry a pointer list of overlapping child records (sum-of-radii test). Called from sub_56D410.

**Guard interpretation:** Stage 1 runs only when node count (this[2], copied from scene+544) > 0; each node is located through the linked list at scene+532 and its 12-byte record and vertex array are allocated (allocation failure stores 0 via the operator new check). Per vertex, the a2 point list (count a2[1], stride 20 at a2[2]) is scanned: an entry only adopts a lower value when `dist² < *(v22+12)` (radius) AND the current value `> *(v22+16)` — so only smaller, in-radius candidates pass. Triangle linking is bounded: the Z binary searches restrict to entries with +12 in [minZ-0.005, maxZ+0.005], the Y test requires `v77[8]+0.005 >= fabs(v77[5]-v37[1])`, the side test requires the normal dot `> 0.0`, and the neighbour scan stops at 7 entries (v42 < 7) or on the first differing/equal normal. Stage 2: when this[4] (= a2[3]) <= 0 the loop is skipped and this[6] = 0; otherwise each 24-byte entry copies 6 floats (then forces float[4] = 0.0), is optionally translated, and in a two-pass scheme first counts matches (`dist² < (sqrt(child+16)+sqrt(v50[3]))²`, i.e. sum-of-radii overlap) and then allocates and fills the pointer list; the loop ends by zeroing this[6].
