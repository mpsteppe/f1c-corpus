## sub_60BB00_0060bb00 — unlink block from intrusive lists or free it

**Summary:** Destruction helper for a block: if the block has flag 0x40000 set, walks up to three intrusive lists (heads at this+0x2A0, +0x2B4, +0x2F0) looking for the block pointer and removes it via LinkedListNodeRemovalByValue; if the flag is clear the block is simply freed with j__free.

**Guard conditions:** Block == 0 → nothing happens. (*Block & 0x40000) != 0 → the three-list unlink path runs: each list is searched by walking node pointers; when the node equals Block it is removed via sub_59F730 and the remaining lists are skipped; when a list is empty or exhausted the search falls through to the next list; after list 3 the function returns. Flag clear → j__free(Block).
