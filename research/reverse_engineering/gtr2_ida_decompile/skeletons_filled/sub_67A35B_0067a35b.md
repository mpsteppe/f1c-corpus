## sub_67A35B_0067a35b — periodic PNG IDAT interval flush

**Summary:** Mid-image IDAT flush for the PNG writer: when a row threshold is hit but rows remain, it sync-flushes the zlib deflate stream (flush mode 2), emits the accumulated compressed bytes as IDAT chunks, resets the rows-since-last-IDAT counter, and invokes the flush/emit callback registered on the struct. Returns the current row number (or the callback's result when it flushes).

**Written-by note (persistence):**
- this 0x70: reassigned to the zbuf base every time a full buffer is written; recomputed during each flush, so an external poke would not survive a flush.
- this 0x74: reset to the zbuf size on each buffer flush; likewise overwritten during flushing.
- this 0x128: written to 0 only on the flush path (when row number < total rows); normally incremented per row by caller sub_6B7D98, so a poke survives until that path runs.
