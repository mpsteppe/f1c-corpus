## sub_55219D_0055219d — WriteSlotResultSummary (dump per-slot race result)

**Summary:** Writes a per-slot race result summary (driver, vehicle, team, lobby username, penalty, qualifying, laps, per-lap times, best lap, race time/DNF/DQ with reason, fines) into a result file for the slot selected by `a2+8` in the network season arrays. Skips entirely when the slot is invalid (`-1` marker) or the file name is empty, and honors session-type flags for penalty and per-lap listing.

**Guard conditions:** Name selection: `a2+12` nonzero → this+0xC0, else this+0xB8; null → `WindowName`. The whole dump is skipped when `dword_923E84[slot] == -1` (invalid slot), when the file-name buffer is empty (`strlen == 0`), or when the `a2+12` flag is clear and `v10[41] <= 0` and `a2+16` is zero. Writing starts only when `sub_614810(name, 0, 1, 1) == 1` (file opened). The lobby-username line requires `byte_B6CBC3`. The penalty line is written only when `!sub_4735A0()` or neither sub_4745A0 nor sub_473630 succeeds. `QualTime` only when `v10[12] > 0`; `BestLap` only when `v10[41] > 0`; per-lap lines only when `byte_B72D9C` or sub_473630; `Total Fines` only when `v10[58] > 0`. The `RaceTime` line switches on `v10[27]`: 0/2 → DNF + `Reason=%d` (v10[28]); 1 → formatted finish time; 3 → DQ; default → nothing.
