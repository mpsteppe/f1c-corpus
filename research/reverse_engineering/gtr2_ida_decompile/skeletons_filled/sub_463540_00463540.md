## sub_463540_00463540 — decode pending input event to key-name string

**Summary:** Consumes the pending-event data of the input object: requires the gate byte at this+0x280 (bit 0) and a positive dword at this+0xC8C, then reads the code byte at this+0xC90, writes it to *a3, and copies a 16-byte fixed string from the key-name tables (aPause or asc_758958, depending on code range) into a2 — or generates an uppercased name via sub_45E670/String for the mid-range codes. Returns 1 when a name was produced, 0 otherwise.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x280 | R | — | gate byte; bit 0 must be set for the function to do anything |
| this | 0xC8C | R | — | pending-event dword (first event slot of the queue filled by the input poll); must be > 0 |
| this | 0xC90 | R | — | event code byte read as v3 and written out through *a3 |

**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|

**Guard interpretation:** Entry requires BOTH (this+0x280 byte & 1)!=0 AND (this+0xC8C dword) > 0, otherwise return 0 with a3 untouched. The code byte v3=(this+0xC90) then routes: v3==0/1/14/15/28/29/42 copies &aPause[16*v3]; v3 in 2..53 (other) generates the name via String (sub_45E670 + __strupr) and copies it; v3 in 54..89 copies &aPause[16*v3]; v3 in 90..128 returns 0 (blocked by the (unsigned)v3 >= 0x5A test); v3>128 copies from asc_758958[16*(v3-128)] only when v3-128 < 0x58 (88), else returns 0. All successful routes return 1; every blocked route leaves a2 without a name.
