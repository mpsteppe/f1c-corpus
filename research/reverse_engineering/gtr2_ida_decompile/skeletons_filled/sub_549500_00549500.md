## sub_549500_00549500 — SpecialFX::Init (load specialfx.tec, build effect lists)

**Summary:** Initializes the track `SpecialFX` system (specialfx.cpp): builds the `specialfx.tec` path from the current track directories, parses its sections (`[TRACKVARS]`, `[FEEDBACK]`, `[LOOSE]`, `[LENSFLARE]`), allocates and fills the feedback (104-byte) and effect/texture (116-byte) entry arrays, caches pointers to known entry types, loads `STEX.GTR`, collects `LPTREE` scene objects into the light-tree array and the `MARBLES` effect handles, and reads the AI/player grip/wear multipliers.

**Guard interpretation:** The file open (`sub_614460(Buffer, 1)`) gates the whole parse: when it fails the function jumps straight to the scene/effect lookup part. Feedback entries are accepted only when `v15` stays true — every `INCLUDETRACKS` line must match via sub_616480, or any `EXCLUDETRACKS` match clears `v15`; the parsed key must be shorter than 32 bytes. Missing `INCLUDETRACKS`/`EXCLUDETRACKS` handling aside, the per-entry loops (entry count `this[0x10] > 0`) run the 3-pass type switch, and the cached-pointer assignments for types 14/15/1/3/4/5/16/17/18/19 happen only if such entries exist. The STEX.GTR load runs only when the grip value (sub_5529A0 / optional sub_54B400 override when byte_FADD28 is set) is not -1.0. Each grip/wear multiplier is overwritten only when its key lookup (`sub_53A2B0`) succeeds.
