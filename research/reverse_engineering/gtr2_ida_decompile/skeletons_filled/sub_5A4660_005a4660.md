## sub_5A4660_005a4660 — CloseHandlesIfFlagged

**Summary:** Cleanup helper that closes two optional Win32 handles: if the flag byte at this+0x24 is set it closes the handle at this+0x1C, and if the flag byte at this+0x14 is set it closes the handle at this+0xC; each handle is zeroed only when CloseHandle succeeds.

**Called by:** (none static — top-level or indirect-only)

**Struct fields accessed:**

| this | 0xC | RW | 0 | Handle closed via CloseHandle; set to 0 when the close succeeds |
| this | 0x14 | R | — | Byte flag: when nonzero the handle at this+0xC is closed |
| this | 0x1C | RW | 0 | Handle closed via CloseHandle; set to 0 when the close succeeds |
| this | 0x24 | R | — | Byte flag: when nonzero the handle at this+0x1C is closed |

**Written-by note (persistence):**
- this 0xC: Conditionally written — zeroed only when its flag byte (this+0x14) is set AND CloseHandle succeeds; otherwise the value is left untouched.
- this 0x1C: Conditionally written — zeroed only when its flag byte (this+0x24) is set AND CloseHandle succeeds; otherwise the value is left untouched.

**Guard conditions:** Two independent conditional blocks, no early return. Block 1: byte this+0x24 must be nonzero AND CloseHandle(this+0x1C) must succeed (&& short-circuit) — otherwise this+0x1C is left unchanged; only on PASS is this+0x1C zeroed. Block 2: byte this+0x14 must be nonzero — otherwise the handle at this+0xC is not closed at all; on PASS CloseHandle(this+0xC) runs and zeroes the field only if it succeeds.
