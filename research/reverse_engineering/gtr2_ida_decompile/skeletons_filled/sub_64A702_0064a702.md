## sub_64A702_0064a702 — DDS/texture resource loader by resource type

**Summary:** Loads a texture/image resource from a DDS file into a CDX texture container: picks a format descriptor by resource type (a3), allocates per-node pixel storage, creates the surface via D3DXCreateTextureFromFileInMemoryEx with a fixed flag set, then dispatches to the per-type decode helper (2D/cube/3D/volume/DXT) and finalizes the load. Part of the DDS/CDX texture loading system.

**Guard conditions:** Switch on a3 selects the descriptor: 0/6→unk_913B10, 1→unk_913B6C, 2→unk_913B60, 3→unk_913B74, 4→unk_913B90, 7/8→unk_913B84; any other a3 falls to the error return with v11 = -2005530516 (D3DERR/loader not initialized class). Lookup result v7 == 0 also fails to the error return; `v7 == *v4` skips the re-create block (LABEL_21) and goes straight to parsing. Per node: operator new failing destroys v34 and returns -2147024882 (out of memory); sub_64E329 < 0 frees the block and exits. The existing buffer is freed only when `v10[1] && v10[14]`. Parse failure (v12 < 0) exits before setlocale work; `strcmp(Locale,"C")` decides whether to restore the saved locale. Decode context result v43 < 0 fails; when `a4 == 2`, sub_677265 failure sets the return code; on success the destination's vtable-slot-12 pointer receives a memcpy of v17 bytes from the source's slot-12 pointer.
