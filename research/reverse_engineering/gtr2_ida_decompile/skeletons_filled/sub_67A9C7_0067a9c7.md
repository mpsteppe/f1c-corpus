## sub_67A9C7_0067a9c7 — info-setter: transparency (tRNS)

**Summary:** Records tRNS transparency data on the PNG info structure: an optional palette-transparency byte-array pointer at info+0x30, optional 16-bit color values copied from a 10-byte struct into info+0x34, the transparency count as a 16-bit value at info+0x16 (defaulted to 1 when the count is 0 and color values are given), and validity bit 0x10 at info+8. Requires both the png struct and the info pointer to be non-null.

**Guard conditions:** A single combined check: if a1 (png struct) or a2 (info structure) is 0 nothing is written. Otherwise: if a3 (palette transparency array) is nonzero it is stored at info+0x30; if a5 (16-bit color struct) is nonzero its 10 bytes are copied to info+0x34 (two dwords at +0x34/+0x38, word at +0x3C) and, if a4 == 0, the count is forced to 1. Then, unconditionally, validity bit 0x10 is OR-ed into info+8 and the count is stored as a 16-bit value at info+0x16. Note the validity bit and count are written even when both optional pointers are NULL.
