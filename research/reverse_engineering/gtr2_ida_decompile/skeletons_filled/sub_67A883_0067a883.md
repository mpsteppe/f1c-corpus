## sub_67A883_0067a883 — info-setter: gamma (gAMA)

**Summary:** Records an image gamma value into the PNG info structure: sets validity bit 0x1 (gAMA) in the flag word at info+8 and stores the caller's double, narrowed to a 32-bit float, at info+0x28. Silently does nothing when either the png struct or the info pointer is NULL.

**Called by:** sub_648585 (00648585), sub_67A98E (0067a98e), sub_6BAA69 (006baa69)

**Guard conditions:** Two NULL checks gate all writes: if a1 (png struct) is 0 the function returns immediately; inside, if a2 (info structure) is 0 it also returns. Only when both are nonzero does it set the gAMA validity bit (info+8 |= 0x1) and store the value at info+0x28. The gamma value itself is not validated or range-checked — any double is converted to float and stored.
