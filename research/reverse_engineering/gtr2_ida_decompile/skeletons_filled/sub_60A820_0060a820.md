## sub_60A820_0060a820 — attach/detach reference setter (registers object with global manager)

**Summary:** Setter for the object pointer at this+0xD0. When a new non-null object is supplied it registers that object with a global manager object (dword_FB40C8 vtable call) keyed by this+0xCC, and stores a back-pointer into the new object at +0x70; when null is supplied it unregisters through the same manager call and clears the field.

**Called by:** sub_5F30A0 (005f30a0), sub_5F3730 (005f3730), sub_60AA40 (0060aa40), sub_60D760 (0060d760), sub_60DF60 (0060df60), sub_60E1A0 (0060e1a0), sub_6103F0 (006103f0), sub_610E20 (00610e20), sub_611660 (00611660), sub_611840 (00611840)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0xCC | R | — | key/identifier passed to the global manager's vtable method (0x104) and copied into the new object's +0x70 back-pointer |
| this | 0xD0 | RW | 0 | currently attached/registered object pointer; compared against the argument, set to the new object or cleared to 0 |

**Written-by note (persistence):**
- this 0xD0: conditionally written — only when the argument differs from the stored pointer; a call with the same pointer is a no-op, so an external poke would survive until the next attach/detach call with a different value, but it would desynchronize this field from the global manager registry.

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|
| 00fb40c8 | dword_FB40C8 | R | pointer to a global manager object; its vtable slot +0x104 is called as manager(this, this[0xCC], handle) to register or unregister the object |

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 005e7150 | sub_5E7150 | converts the new object with selector 8 and returns the handle/value passed to the manager's registration call |

**Guard conditions:** a2 == this[0xD0] (already-current pointer) → entire body skipped, result = current pointer, no writes. a2 != 0 → takes the register path: manager vtable call with the handle from sub_5E7150, stores this[0xCC] into a2[0x70], sets this[0xD0] = a2. a2 == 0 → takes the unregister path: manager vtable call with 0, sets this[0xD0] = 0.
