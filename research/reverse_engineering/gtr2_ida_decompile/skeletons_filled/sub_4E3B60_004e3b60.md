## sub_4E3B60_004e3b60 — Opcode/command dispatcher (switch on this+0x0)

**Summary:** Dispatches a command selected by *this (opcode 1/4/5/6/7) against the manager object referenced through a2+48; cases 1 and 6 resolve a name string (falling back to WindowName) and case 5 writes the global dword_75B17C = -1. Unknown opcodes fall through and return (*this)-1.

**Called by:** sub_4CDEE0 (004cdee0)

| this | 0x4 | R | — | name string used by case 1; null falls back to WindowName |
| this | 0xC | R | — | name string used by case 6; null falls back to WindowName |

**Guard conditions:** Switch on this+0x0: case 1 → name-string action; case 4 → manager action; case 5 → global write; case 6 → name lookup, and only if the lookup returns non-null are the virtual calls (vtable slots 132/136) and the Setter performed; case 7 → parameter action. Any other opcode hits `default` and returns (*this)-1 without side effects (BLOCKED). Case 6's inner `if (v3)` gates the follow-up calls — a failed lookup is skipped.
