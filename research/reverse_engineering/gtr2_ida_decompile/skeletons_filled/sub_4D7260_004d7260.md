## sub_4D7260_004d7260 — Text-field render (masked/caret, width trim, entry draw)

**Summary:** Renders an editable text field: optionally draws the current list entry, builds the field string from this+0x31C (masking with '*' when this+0x10E is set, otherwise copying up to 255 chars), appends a blinking '_' caret when this+0x10C/0x10D are set and the global blink counter is on an odd phase, measures the text, trims leading characters until it fits the horizontal span between virtual slots +0xC and +0x4, and finally draws it through virtual slot +0x8, writing bounds results into the caller's four outputs.

**Guard conditions:** this+0xF4 != 0 → the name is applied and the current entry is drawn; the latter additionally requires sub_4E29F0(0) to return non-null. The caret append requires byte this+0x10C and byte this+0x10D both set and the doubled dbl_FB1D18 value to be odd. this+0x10E selects the '*' masking loop (stops at the source NUL or 256 chars) versus the 255-char copy. The trim loop runs only when the measured width v33[0] exceeds (slot+0xC − slot+0x4) and stops early once the measured width fits or after 255 iterations. The final draw plus the four output writes happen only when the remaining string length is non-zero.
