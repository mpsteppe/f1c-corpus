## sub_5373C0_005373c0 — 6-state sequencer / phase advance

**Summary:** Small state machine driven by a counter at `this+0x175FC`: states 1..5 advance the counter one step and clear the byte at `this+0x17600`; in state 6 it performs the terminal action by calling sub_535B50(this, a2) and sub_530500(), then still clears the byte. Any other value falls through to the default path, which clears the byte without changing the counter.

**Called by:** sub_4EB200 (004eb200), sub_4EC440 (004ec440)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x175FC | RW | 6 | Sequencer state (95740): read, used to pick the switch arm, and incremented in states 1..5; value 6 is the terminal state |
| this | 0x17600 | RW | 0 | Byte flag (95744) cleared to 0 on every reachable path — per-call reset of a pending/flag field |

**Written-by note (persistence):**
- this 0x175FC: written conditionally — only in states 1..5 (incremented by 1). State 6 and all other (default) values are left untouched. An external value in 1..5 is advanced one step per call until it latches at 6; a poke of 6 (or any value outside 1..5) survives indefinitely.
- this 0x17600: written (to 0) on every call through all switch arms and the default, i.e. re-cleared each invocation; an external poke is overwritten on the next call.

**Guard conditions:** Switch on `*(_DWORD*)(this + 0x175FC)`: values 1,2,3,4,5 each set the state to itself+1 and clear `this+0x17600`; value 6 runs sub_535B50/sub_530500 then clears the byte; any other value (0, 7+, negative) goes to the default arm, which only clears `this+0x17600` and leaves the state unchanged.
