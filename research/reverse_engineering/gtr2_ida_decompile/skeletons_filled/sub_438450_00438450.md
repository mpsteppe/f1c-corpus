## sub_438450_00438450 — Reset object state

**Summary:** Resets a manager/creator object: if the pointer at this+0xC is non-null it performs a virtual call through that object's vtable (second argument 1, deleting-destructor style) and clears the slot, then zeroes the object's state fields, sets the byte at this+0x1 to 1, and tail-calls the global function pointer off_16C97A4.

**Written-by note (persistence):**

- this 0x1: unconditionally written to 1 on every reset call; a poke of any other value survives until the next reset call.
- this 0x2: unconditionally written to 0 each call; poke survives until next reset.

**Guard conditions:** One branch: v2 = this+0xC. If non-null, the virtual call `(**v2)(v2, 1)` executes and the slot is cleared (PASS); if null, the call and that clear are skipped (BLOCKED).
