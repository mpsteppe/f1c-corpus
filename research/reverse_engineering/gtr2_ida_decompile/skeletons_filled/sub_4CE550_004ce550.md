## sub_4CE550_004ce550 — Recompute ratio-derived value

**Summary:** Recomputes the stored value at this[0x22C] as round((this[0x230] / this[0x234]) * this[0x240]) — a ratio of two counts scaled by a third quantity. Resets the target to 0 first, so it always reflects the current inputs.

**Called by:** sub_4D0B20 (004d0b20), sub_4D4750 (004d4750)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x22C | RW | 0 | Result slot: reset to 0, then conditionally set to the rounded scaled ratio |
| this | 0x230 | R | — | Numerator count used in the ratio |
| this | 0x234 | R | — | Divisor count; must be > 0 or no ratio is computed |
| this | 0x240 | R | — | Scale/total quantity (v1) multiplied by the ratio; 0 disables the computation |

**Written-by note (persistence):**
- this 0x22C: recomputed on every call (zeroed, then conditionally overwritten) — an external poke is lost on the next invocation.

**Guard conditions:** If this[0x240] (v1) is 0, the result stays 0. Otherwise, v2 = (double)this[0x234]; only when v2 > 0.0 is the result written as (int)((double)this[0x230] / v2 * (double)this[0x240] + 0.5) — i.e. a zero/negative divisor blocks the computation and leaves 0.
