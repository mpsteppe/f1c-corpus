## sub_6186F0_006186f0 — encryptomatic_decipher_buffer

**Summary:** Inverse byte-processing loop of the Encryptomatic V1.0 component (decryptor twin of sub_618610): for each of `a3` bytes at `a2` it subtracts the `Block` substitution-table byte indexed by the state at +0xC, re-seeds the RNG worker with the low nibble of that intermediate byte, subtracts the worker's nibble-masked result, optionally maps resulting byte 10 (0x0A) to 0 when `a4` is set, then advances counter (+0x8, mixed into state via XOR) and doubles state (+0xC) with sign-bit feedback. Returns the output buffer pointer (+0x10).

**Guard interpretation:** `this+0xC >= 0` PASSES with plain doubling (`state = 2 * state`); a negative state (bit 31 set) is doubled then incremented by 1, feeding the shifted-out bit back. Additionally, inside the loop, when `a4` is non-zero AND the finalized byte equals 10 (0x0A), the byte is replaced by 0 — i.e. in the `a4`-enabled mode a decrypted line-feed becomes NUL. With `a4 == 0` that substitution is skipped. The outer loop runs only while `v5 < a3`.
