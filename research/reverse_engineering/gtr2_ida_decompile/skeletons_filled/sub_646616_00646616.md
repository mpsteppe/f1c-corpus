## sub_646616_00646616 — Find first line-feed (0x0A) in buffer

**Summary:** Scans a byte buffer for the first LF (0x0A) character and returns its offset, bounded by the given length. Returns 0 when the length is zero, when no LF is found, or when the LF sits at offset 0.

**Guard conditions:** `a2` (buffer length) == 0 → immediate `return 0` without touching the buffer. Otherwise the loop advances the index while the byte ≠ 10 (LF); if the index reaches a2 without a match → `return 0`. A match PASSES and the matching offset is returned. Note: a LF at offset 0 and a not-found result are indistinguishable (both return 0), so callers must treat 0 as "no terminator found" for this helper's purpose.
