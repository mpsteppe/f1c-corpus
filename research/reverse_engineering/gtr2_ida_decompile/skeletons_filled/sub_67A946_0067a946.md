## sub_67A946_0067a946 — info-setter: palette (PLTE)

**Summary:** Records the palette into the PNG info structure: stores the palette pointer at info+0x10, the entry count as a 16-bit value at info+0x14, and marks the PLTE chunk valid with flag bit 0x8 in the word at info+8. No-op when the png struct or the info pointer is NULL.

**Guard conditions:** Two NULL checks gate the writes: if a1 (png struct) is 0 the function returns immediately; inside, if a2 (info structure) is 0 it returns as well. Only when both are nonzero does it set the PLTE validity bit (info+8 |= 0x8), copy the palette pointer to info+0x10 and store the entry count as a 16-bit value at info+0x14. Neither the pointer nor the count is validated.
