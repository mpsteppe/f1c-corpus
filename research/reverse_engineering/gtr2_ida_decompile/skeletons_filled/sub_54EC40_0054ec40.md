## sub_54EC40_0054ec40 — Index-to-ID lookup across two tables with validity gating

**Summary:** Resolves an index argument to a non-negative ID: first tries the primary table (base this+0x348, stride 2 DWORDs, count stored at this+0x688); if the index is out of range there or the stored value is negative, falls back to a secondary table (base this+1, stride 2 DWORDs, count at this+0x344). Negative arguments and negative stored values yield 0 (invalid).

**Guard conditions:** 
- `a2 < 0` → return 0 (blocked).
- Primary lookup: if `a2 >= this[0x688/4]` (out of range) or the stored value `this[2*a2 + 210] < 0` → fall through to the fallback table.
- Fallback lookup: if `a2 >= this[0x344/4]` → return 0; else read `this[2*a2 + 1]`; if that value is negative → return 0.
- Success returns the first non-negative ID found, preferring the primary table.
