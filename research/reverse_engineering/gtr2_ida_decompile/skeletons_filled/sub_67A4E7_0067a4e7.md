## sub_67A4E7_0067a4e7 — PNG filter-heuristic configuration

**Summary:** Configures the PNG writer's adaptive row-filter heuristics: validates and stores the heuristic method and weight count, lazily allocates the previous-filter, weight and cost tables, and converts caller-supplied double weights/costs into the fixed-point 16-bit factors used by filter selection.

**Called by:** sub_67A6F8 (0067a6f8)

| this | 0x180 | RW | — | heuristic method byte (0 = default, normalized to 1; 1 = unweighted; 2 = weighted; values ≥ 3 rejected) |
| this | 0x181 | RW | — | number of weights; forced to 0 when the input is invalid or the method is unweighted |
| this | 0x184 | RW | — | previous-filter array: one byte per weight column, allocated once and filled 0xFF (no previous filter) |

**Written-by note (persistence):**
- this 0x180: rewritten with the normalized method on every call — an external poke would not survive a call to this function.
- this 0x181: rewritten on every call (0 on invalid input or unweighted method).
- this 0x184: allocated only while NULL; its bytes are all rewritten to 0xFF at allocation, otherwise untouched.
- this 0x188: allocated only while NULL; entry k is overwritten on each call where weight ≥ 0.0.
- this 0x18C: allocated only while NULL; entry k is overwritten on each call where weight ≥ 0.0.
- this 0x190: allocated only while NULL; entries overwritten on each call to 8 or cost*8 depending on the cost value.
- this 0x194: allocated only while NULL; entry k is overwritten when cost ≥ 1.0 (8.0/cost) or reset to 8 when cost < 0.0 / cost pointer NULL.

**Guard conditions:** The method argument must be < 3; a value ≥ 3 dispatches "Unknown filter heuristic method" and returns without writing anything. Method 0 is normalized to 1. The weight count is forced to 0 when the size argument is negative, the weight array pointer is NULL, or the method is 1 (unweighted). Arrays are allocated only once (when their pointer is NULL): prev-filters filled 0xFF, weights defaulted to 256, costs defaulted to 8. Per-entry updates: weights with value ≥ 0.0 set both weight tables, negative weights fall back to 256; costs set only when ≥ 1.0, values < 0.0 or a NULL cost pointer reset entries to 8, and costs in [0.0, 1.0) leave the existing entry unchanged.
