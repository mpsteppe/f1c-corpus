## sub_5F15F0_005f15f0 — Texture format → bits-per-pixel/code mapper

**Summary:** Maps a texture format identifier (compressed DXT1..DXT5 fourccs and integer format IDs 20-41) to two outputs: through a2 the bits per pixel (1 for the DXT families, 8/16/24/32 for integer formats) and through a3 an internal format code (3-14, or 255 for unrecognized IDs). Returns the a3 pointer (null when a3 was null).
