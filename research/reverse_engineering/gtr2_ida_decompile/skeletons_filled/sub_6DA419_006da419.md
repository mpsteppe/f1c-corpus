## sub_6DA419_006da419 — bi_flush — flush bit accumulator

**Summary:** Pushes pending bits of the deflate bit accumulator out to the output: with exactly 16 valid bits it writes both accumulator bytes and resets accumulator and count to 0; with 8..15 bits it writes one byte, shifts the accumulator right by 8 and subtracts 8 from the count; fewer than 8 bits produces no output. Called by sub_6DA8F7 (_tr_align).

**Called by:** sub_6DA8F7 (006da8f7)

**Written-by note (persistence):**
- this 0x16B0: conditional — cleared or shifted only when at least 8 bits are pending; with fewer bits it is left untouched. An external poke is consumed/overwritten as soon as a flush with >= 8 pending bits occurs.
- this 0x16B4: conditional — set to 0 (16 bits) or reduced by 8 (8..15 bits); untouched below 8. A poke survives until the next flush that has >= 8 pending bits.

**Guard conditions:** valid-bit count (0x16B4) == 16 → write low byte at buf[counter], then high byte at buf[counter+1], counter += 2, accumulator = 0, count = 0.
