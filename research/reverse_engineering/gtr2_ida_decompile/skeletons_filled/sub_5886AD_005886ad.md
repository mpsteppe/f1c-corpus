## sub_5886AD_005886ad — ParseVehicleSetupFile (vehload.cpp setup/SVM parser)

**Summary:** Parses a vehicle setup file (`.SVM`, per the `vehload.cpp` diagnostics) line by line, dispatching on section headers (`[GENERAL]`, `[FRONTWING]`, `[REARWING]`, `[BODYAERO]`, `[DIFFUSER]`, `[SUSPENSION]`, `[CONTROLS]`, `[ENGINE]`, `[DRIVELINE]`, `[FRONTLEFT]`, …) and reading key=value entries into the setup object (`this`/a1) and the vehicle garage/display object (v10 = a2[3]). It also validates setup-file content (mode a2[4]==1 rejects non-setup lines), resolves referenced auxiliary files (`.HDC` tire compound, `.DMG`, `.ENG`, `.GRB`, PhysicalModel), and seeds default pitstop blocks.

**Called by:** (none static — top-level or indirect-only)

- this 0x14E0: recalculated each time `UpshiftAlgorithm` is parsed
- this 0x1500: only ever cleared to 0 (per `UndertrayNN` key); an external poke of nonzero survives unless undertray keys are parsed
