**Guard interpretation:** The parameter-list branch requires a3 nonzero AND the current token's first byte at this+620 to be 40 ('(') AND the cursor start `<` end; otherwise control goes to the LABEL_29 branch that consumes tokens until class 12/13 and then runs MultiTableCoordinateSearch. In the parameter loop the lexer result must be >= 0 to continue; token class 9 (identifier) enters the duplicate-name comparison; token class 1 must be "," or the newline string or it falls to the generic error. Every allocated parameter node must be non-null (else error -2147024882). On the LABEL_29 branch the token class must be 12 or 13 to finish the definition, else a node is built and the loop continues.
