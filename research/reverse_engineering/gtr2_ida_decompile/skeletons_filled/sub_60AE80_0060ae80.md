## sub_60AE80_0060ae80 — translate flag bits to a new mask

**Summary:** Reads the flag dword at a1+0 and translates it bit by bit into a result mask: bits 1/2/4/0x10/0x20 are copied through, bit 0x40 is remapped to 0x1000 and bit 8 to 0x8000.

**Called by:** sub_608640 (00608640), sub_60FE30 (0060fe30)

**Guard conditions:** each bit is tested independently: bit 0x1 → result |= 1 (via `(flag & 1) != 0`), bit 0x2 → |= 2, bit 0x4 → |= 4, bit 0x10 → |= 0x10, bit 0x20 → |= 0x20, bit 0x40 → |= 0x1000; if bit 0x8 is set the function returns result | 0x8000 immediately (same value as the fall-through would add). No combinations are rejected — every input produces the OR of its translated bits (0 if no bits set).
