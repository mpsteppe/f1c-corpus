## sub_484D30_00484d30 — TransitionToMainWindow

**Summary:** UI transition helper: if the manager's window-state field (offset 0x350) is not already 2, hides the window mapped from the old state and shows the saved main-window handle (SW_SHOW), records state 2, then under a mutex posts state 3 into a shared flag. Part of the dialog/window management layer.

**Guard conditions:** The show/hide block runs only when `*(manager + 0x350) != 2` (state already 2 → skipped entirely, nothing shown/hidden, state not rewritten). Inside: main window shown with `ShowWindow(dword_B6CE68, 5)` only if `dword_B6CE68 != 0`; the state-mapped window hidden (`ShowWindow(v2, 0)`) only if `v2 != 0`. The mutex write `*v4 = 3` is reached only when `hMutex != 0` and `WaitForSingleObject(hMutex, dwMilliseconds)` returns 0 or 128; on failure v4 points to 0 (write proceeds through the null pointer). ReleaseMutex runs only if `hMutex != 0`.
