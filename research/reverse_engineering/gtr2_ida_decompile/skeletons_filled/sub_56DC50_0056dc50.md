## sub_56DC50_0056dc50 — Insert/refresh a record in the 20-entry key table

**Guard conditions:** Dedupe: only when a record's nine dwords all compare equal to a2's does the function return early via sub_56A0D0(this, a2[1], -1) — a partial match does not. Full-table handling: entered only when `count == 20` (v4 != 20 jumps straight to the sorted insert). Eviction score: default 1.7014117e38 (= +huge float, i.e. never chosen) — replaced by field 0x3C for key 0; for key 1, a score of -1.0 requires the previous record's key to be 1 or 2; for key 2, -1.0 requires either index 0 or that the previous key is 2.
