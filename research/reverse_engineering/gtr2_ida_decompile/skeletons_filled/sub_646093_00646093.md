## sub_646093_00646093 — Conditional deleting destructor (cleanup + optional free)

**Summary:** Scalar-deleting-destructor pattern: runs the inner cleanup (sub_673A96) and, when bit 0 of the flags argument is set, frees the object block with j__free; returns the block pointer. Standard MSVC `new/delete`-style teardown.
