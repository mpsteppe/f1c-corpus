## sub_5A3F90_005a3f90 — SuspendThreadGuarded

**Summary:** Suspends the thread stored at this+0x8 while holding the mutex at this+0x24: it waits on the mutex with timeout this+0x28, runs a bounded SuspendThread retry loop (up to 50 attempts with increasing Sleep backoff), sets the "suspended" byte at this+0x20 on success, always releases the mutex, and returns 1 on success or when no thread exists, 0 if suspension could not be achieved.

**Guard conditions:** (1) this+0x8 == 0 (no thread) → early return 1, nothing suspended. (2) Mutex path: if this+0x24 is null or WaitForSingleObject returns neither 0 nor 128, the flag pointer v9 is set to 0. (3) If *v9 is nonzero (already suspended) the suspend loop is SKIPPED. (4) Suspend loop: retries while SuspendThread returns -1 (failure) or 0; breaks successfully when it returns a nonzero count other than -1; after 50 attempts (v2 >= 50) it gives up, sets v8 = 0 and returns 0 — suspension BLOCKED. On success sets *v9 = 1. The mutex is released whenever this+0x24 is nonzero, regardless of outcome.
