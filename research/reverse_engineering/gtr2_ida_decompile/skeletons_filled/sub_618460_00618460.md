## sub_618460_00618460 — rng_work_thread

**Summary:** Background worker thread: waits on two events and, while the first (request) event is signaled, reseeds the CRT RNG with the global `Seed`, iteratively computes a value `dword_FB4164 = (rand() + acc)^2` repeated `Seed % 10` times plus one final `rand()`, then signals the completion event `hEvent`. Exits the loop when the second event is signaled (or on wait failure) and returns 0.
