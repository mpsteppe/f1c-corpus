## sub_67A840_0067a840 — set write function (I/O registration)

**Summary:** Registers the struct's output I/O: stores the I/O context pointer, the write callback and the flush callback. If a read callback was previously installed on the same struct, it is cleared and a two-part warning is dispatched, since the struct is write-only.

**Guard interpretation:** The read_data_fn value is tested before the new pointers are stored. If it was 0 (no read callback), the registration passes silently: the new write/flush callbacks are active and a4 is returned.
