# GenericRuntimeObjects

Scope: `generic_runtime_objects`  
Trust: `GUESS`

Reconstruction of generic runtime objects from 33 validated function IR records. No packet function has a proven owner, so every grouping below is a proposal: MSVCJmpBuf is the one class with provable shared layout (the setjmp3 write side 0x0058A7EC and the longjmp read side 0x0058A770 operate on the same jmp_buf at identical offsets +0x0/+0x14/+0x18/+0x1C/+0x20/+0x24, including the signature cookie 1447244336). The remaining functions are grouped into ten interfaces by shared callees, shared globals, and ABI shape: SynchronizedIndirectDispatch (critical-section slot release + callback/indirect trampolines), MSVCCRTSehDispatch (SEH unwind/dispatch, MSVC C++ exception magic 0xE06D7363), CRTFloatToStringConversion (locale-aware number formatting with sign/width handling), CRTFloatMathHelpers (x87 exponentiation, rounding-mode, NaN/Inf and pow special cases), LocaleRuntime (resolution, enumeration callbacks, cached lookup over the shared 0x008D3F98 global block and 0x005E6D60 static table), LocaleStringParsing (hex parse + alphabetical count), StringScanHelpers, RenderArgsDispatch, SystemTimeTickProvider and StubRegistry. The two lock/unlock thunks 0x0058A323/0x0058A32A are mis-decoded frames and their exchange-and-invoke semantics are unresolved; the pow identification is DERIVED from structure, not confirmed.

- `0x00589D7D` **SynchronizedIndirectDispatch** — Iterator that walks a contiguous array of void function pointers from a1 to end address a2 and invokes every non-null entry; called by sub_589C77 and sub_589CC6. The this:0x0 field is a spurious template artifact.

- `0x0058A323` **SynchronizedIndirectDispatch** — Atomically exchanges the return-address slot with v3 via _InterlockedExchange then invokes the swapped-out value as an indirect function pointer and returns its result. The frame is mis-decoded, so which real values flow through the exchange and the dispatch target are unresolved; reached from sub_5939F9 and SEHWrappedRenderDispatchCall.
- `0x0058A32A` **SynchronizedIndirectDispatch** — Same atomic exchange-and-invoke shape as 0x0058A323 (frame mis-decoded); the jump-table dispatch interpretation rests only on the legacy ABI name and is not visible in the raw body.

- `0x0058A4E5` **MSVCCRTSehDispatch** — Exception-frame dispatch helper: on ExceptionFlags & 0x66 it sets TargetFrame[9] to 1 and returns 1 (continue unwind); on the normal path it calls the per-frame handler sub_593446, then SEHUnwindHandler (0x0058A331) unless TargetFrame[9] was set by the handler, then calls the stored continuation at TargetFrame[6] and returns its result.
- `0x0058A6D5` **MSVCCRTSehDispatch** — Magic-number dispatch check on a double-indirect pointer: dereferences a1 to an object (this:0x0), compares the object's first DWORD (obj:0x0) with magic -529697949 (0xE06D7363, the MSVC C++ exception signature); on match dispatches to an SEH wrapper handler (target not statically resolved), otherwise returns 0.
- `0x0058A770` **MSVCJmpBuf** — MSVC CRT longjmp over the jmp_buf at a1: reads the saved target (a1[0], this:0x0) and saved frame (a1[6], this:0x18); when the saved frame differs from FS:0 calls GlobalUnwind2; when the saved frame is non-null either runs the cookie-validated cleanup handler at a1[9] (this:0x24; cookie validated via EmptyStub_3d53 and a1[8]==1447244336 at this:0x20) or unwinds the SEH scope table via MSVCRTSEHFrameUnwinder(v3, a1[7], this:0x1C); then restores context via sub_58893A(a1[5], a1[0], 0) and jumps through a1[5] (this:0x14).
- `0x0058A7EC` **MSVCJmpBuf** — MSVC CRT __setjmp3: saves the non-volatile registers (EBP, EBX, EDI, ESI), stack pointer, return address, the current SEH exception list, and the jmp_buf signature 1447244336 into a5; records either the previous exception handler or a caller-supplied handler plus up to 6 trailing varargs dwords depending on the mode operand a6; returns 0.
- `0x0058B59F` **SystemTimeTickProvider** — Captures the current UTC system time via GetSystemTimeAsFileTime, folds the two 32-bit FILETIME halves into a 64-bit tick (Allmul shifting the high word by 0x100000000), stores the tick to global qword_8D3EC0 (upper dword overlapping 0x008D3EC4) and returns it; straight-line, no conditional branches.

- `0x00590246` **LocaleRuntime** — Locale enumeration callback: parses a hex locale string via HexStringToIntParser, queries locale info through the function pointer dword_8D3FB8, compares the current language string (dword_8D3FA8) and on match (subject to three-letter flag dword_8D3FA4, charset-mode dword_8D3FA0, and sub_59045F validation) commits the validated locale ID into dword_8D3FB4 and Locale (0x008D3F98) with validation flag bit 2 set in dword_8D3FB0; returns ((~dword_8D3FB0 >> 2) & 1), or clears dword_8D3FB0 and returns 1 when the info query fails.

## Proposed classes

### MSVCJmpBuf

MSVC CRT jmp_buf record shared by the __setjmp3 write side (0x0058A7EC) and the longjmp read side (0x0058A770). Both functions operate on the identical layout at identical offsets: saved register/target state at +0x0, final jump slot at +0x14, saved SEH exception-registration frame at +0x18, saved trylevel at +0x1C, signature cookie at +0x20 (validated against 1447244336), and optional cleanup handler at +0x24.

Methods: `0x0058A770`, `0x0058A7EC`

- `this+0x00000000` `int saved_target` (read, DERIVED)
- `this+0x00000014` `function pointer final_jump_slot` (read, DERIVED)
- `this+0x00000018` `pointer saved_frame_ptr` (read, DERIVED)
- `this+0x0000001C` `int saved_trylevel` (read, DERIVED)
- `this+0x00000020` `int signature_cookie` (read, DERIVED)
- `this+0x00000024` `function pointer cleanup_handler` (read, DERIVED)

## Compatibility contracts

- **MSVCJmpBufLayout** — The jmp_buf record consumed by the setjmp3/longjmp pair carries the saved register/target state at +0x0, the final jump slot at +0x14, the saved SEH exception-registration frame at +0x18, the saved trylevel at +0x1C, the signature cookie 1447244336 at +0x20, and an optional cleanup handler at +0x24. A replacement must write this layout in __setjmp3 and consume it in longjmp, including validating the cookie before invoking the stored cleanup handler and unwinding the SEH scope table to the saved trylevel.
- **CriticalSectionSlotReleaseContract** — ReleaseLockByIndex releases critical-section lock slot index 13 via CritSectLeave and propagates its result unchanged; callers sub_587AC0 and sub_589CC6 depend on the slot being released when control returns.
- **MSVCCppExceptionMagicDispatchContract** — StreamMagicNumberCheck dereferences a1 once to an object pointer (this:0x0) and compares the object's first DWORD (obj:0x0) with magic -529697949 (0xE06D7363), the MSVC C++ exception signature; on equality it dispatches to an SEH wrapper handler, otherwise it returns 0.
- **LocaleStateGlobalsContract** — The locale runtime keeps its resolved state in a compact global block: Locale at 0x008D3F98, region flag at 0x008D3F9C, charset-mode at 0x008D3FA0, three-letter flag at 0x008D3FA4, current language string pointer at 0x008D3FA8, region string pointer at 0x008D3FAC, validation flags at 0x008D3FB0 (bit 2 = matched/committed, 0x104 = user-default resolved), resolved locale ID at 0x008D3FB4, and the locale-info function pointer at 0x008D3FB8. The enumeration callbacks commit by setting bit 2 and storing the ID; GetUserDefaultLocale stores the LCID and sets the 0x104 bits.
- **LocaleInfoCacheTableContract** — GetLocaleInfoCached binary-searches a static locale table whose entries are 11 dwords wide starting at dword_5E6D60, with per-LCType cached string columns (LCType 1, 3, 7, 0xB, 0x1001, 0x1002, 0x1004), a hard-coded table bound of 26 entries, and a GetLocaleInfoA fallback on any miss. A replacement must preserve the column-to-LCType mapping, the length-limited copy via sub_587DD0, and the fallback.
- **FloatFormattingOutputContract** — The float-to-string family formats doubles using the locale decimal separator byte at 0x005E6BD8, treats ASCII '-' (code 45) as the negative-sign marker for width and draw-position adjustment, emits the exponent marker 'E' (69), and writes exponent digits onto pre-initialized '0' characters; the shared scratch record carries the sign flag at offset 0, a digit-count/width quantity at offset 1, and exponent/leading-digit state at offset 2. A replacement must reproduce these output conventions for the CRT float conversion callers, including the CfltcvtCRTFloatConversionDispatch stage entry at 0x0058C07F.
- **PowSpecialCaseResultContract** — The pow special-case classifier writes one of three result constants to *a3 depending on the base/exponent special cases: dbl_5E7718 (the +infinity / greater-than-1.0 family result), dbl_5E7720 (the exact |base| == 1.0 result, returned with flag 1), and dbl_5E7738 (the odd-integer negative-infinity result); the literal 1.0/0.0 complete the result set, and the function returns a flag marking the |base| == 1.0 case. A replacement must keep the same special-case result selection and return-flag contract.
- **SystemTimeTickGlobalContract** — GetSystemTimeAsFileTimeTo64BitTick stores a FILETIME-derived 64-bit tick into global qword_8D3EC0 (its upper dword covering 0x008D3EC4) and returns the same value; any consumer of qword_8D3EC0 depends on this write being performed with the combined 64-bit value.

## Unresolved

- 0x0058A323 / 0x0058A32A (atomic lock/unlock thunks): both frames are mis-decoded ('positive sp value has been detected'), so which real values flow through the _InterlockedExchange of the return-address slot and through the indirect call is unresolved; the legacy jump-table interpretation for 0x0058A32A rests only on the ABI name and is not visible in the raw body.
- MSVCJmpBuf: the literal 1447244336 at +0x20 is the deterministic cookie guard value; its textual meaning is not decoded and it was preserved as a decimal literal per the packet. The a2 parameter of crtLongjmp appears nowhere in the body and is unaccounted for; the mode operand a6 and dual-role a8 of __setjmp3 are only partially inferred.
- 0x0058A770 (crtLongjmp): the a1[8] cookie comparison consumer side (which code validates the cookie at setjmp time) is not visible in the packet; the setjmp/longjmp contract at the three callers is not established.
- field:this:0x00000000 is a spurious template-generated field on the __cdecl helpers callAllNonNullCallbacks (0x00589D7D) and FormatDoubleWithTruncation (0x0058BFEC); both have no `this` in their raw source, and the packet field list is misattributed for 0x0058BFEC.
- 0x0058A6D5 (StreamMagicNumberCheck): the SEH wrapper dispatch target is not present as a callee in the packet and is source-backed only; obj:0x0 and this:0x0 alias at the same offset because of the double dereference.
- LocaleRuntime: the 0xF002/0xF005 flag masks and the +4097/+4098 info-query subtypes are only inferable from the locale-info API contract, not from this packet; the function pointer dword_8D3FB8 and region pointer dword_8D3FAC identities are defined elsewhere; the writers of dword_8D3FA0/dword_8D3FA4 are not visible here.
- 0x005904F7 (GetLocaleInfoCached): the 11-dwords-per-entry table layout is evidenced only through indexing arithmetic, not by a struct definition; the table bound (v5=26) is a hard-coded count with no evidenced table-length symbol.
- 0x0058DE2C (PowSpecialCaseClassifier): the identification as pow special-case handling is DERIVED from the classification structure, not confirmed by packet evidence; globals dbl_5B8C80 and dbl_5B8CC8 are read but absent from the pseudocode (presumed folded comparison constants); the FPU sign flag v6 producer is unknown.
- 0x0058B59F: two TLS bytes at 0xFF00000000005394 and 0xFF00000000005395 are listed as read but do not appear in the raw body; their role is unknown. GetSystemTimeAsFileTime is an IAT import pointer whose module binding is not reconstructed.
- 0x0058DC40 (CRTFloatPassthroughWrapper): the real implementation at jump target 0x58DC60 is outside this packet, so the actual float operation is unknown; the caller at 0x0058DD89 is not in the allowed evidence set.
- 0x0058DCE5 (FloadWithFBFloatLoadWithNaNCheck): the purpose of the left-shift-by-11 transform for Inf/NaN inputs is unknown; the a1 argument is unused and its caller-side role is unresolved.
- 0x0058BE2E (sub_58BE2E): the struct at a4 (exponent value at +4, leading-digit flag at +12, sign flag at +0) is only partially characterized and its owning type is unknown; buffer chars at v6[1..4] are assumed pre-initialized '0' by the caller; global aE000 (0x005B8D80) appears in the index as the exponent template but is not referenced in the body.
- 0x0058A40A (RenderArgsDispatch): the semantics of the two literal-zero arguments and of the a2 element slots (indices 2/3/4) are not evident from this wrapper alone; the behavior and prototype of sub_593446 are unknown at this layer.
- StubRegistry (0x0058DCB5 / 0x0058FB7E): whether the empty/constant-0 bodies are placeholders or deliberate no-ops cannot be determined from the packet; the ABI names carry LEGACY trust and are not runtime-confirmed.
- X87FPExponentiation (0x0058DCA0): the frndint rounding mode is assumed round-to-nearest and is not fixed by the source; whether the helper is shared math infrastructure or subsystem-specific is unknown.
- GetUserDefaultLocale (0x005903C0): the meaning of the 0x104 flag bits and the distinction between the Locale global and dword_8D3FB4 are not established from this packet.
- General: the interface groupings for CRTFloatMathHelpers, StringScanHelpers, RenderArgsDispatch and StubRegistry are GUESS proposals from ABI shape and shared callees; no packet evidence proves a common owning object, and equal byte offsets across different functions are not treated as shared fields except for the jmp_buf layout proven by the setjmp3/longjmp pair.
- No evidence in the packet establishes runtime truth; every class and interface here is a DERIVED or GUESS proposal and must not be promoted to CONFIRMED or FACT without independent static or runtime evidence.
