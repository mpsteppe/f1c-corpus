# GenericRuntimeObjects

Scope: `generic_runtime_objects`  
Trust: `GUESS`

Thirty-one validated functions reconstructed into eight GUESS-level runtime-object classes (plus one DERIVED ownership, TirePhysicsComponent from the caller name PhysicsTireSystemConstructor) and thirteen unknown-owner helpers. The most defensible group is the particle object: ParticleInstanceUpdate (0x004CC1D0) and ScoringGateTimeoutCheck (0x004CDAD0) share the particle array fields (count this+0x64, element array this+0x68), are both gated on the global scoring flag dword_8AB6E4 == 2, and both delegate to the scoring system 0x004B9CE0 with the address of dword_8AB6EC. ScoringPositionUpdate (0x004D1D80) forms a standings/proximity monitor (threshold +0x100, flag +0x104, timer +0x120, counter +0x124, order array +0x128) on the active-vehicle grid. A replay-object pair (0x004DB420 factory, 0x004DB4E0 destructor) shares a 24-byte vtable-object layout. A UI-text family (0x004D7FA0, 0x004D8130, 0x004DB7F0, 0x004DB9A0, 0x004DBB60) is grouped by the shared UITextRenderWithScale call path but the members are free helpers with no shared receiver. InitializeObjectDefaults (0x004DCF80) and SetTwoFieldsAndReturnSecond (0x004DD010) share the scale fields +0x30/+0x34. AllocateAndInitializeObject (0x004DC220) and FixedNodeAllocatorConstructor (0x004DC290) are structurally identical 16-byte vtable-object constructors with different vtables and +4 literals. The tire component (0x004DFBB0, 0x004E38D0) shares the counter at +0xBA8 and the 187-dword record stride. All packet owners except 0x004DFBB0 are UNKNOWN; class identities and field meanings are GUESS proposals only. Seven globals read by the fact table but absent from the raw source remain unresolved.

## Proposed classes

### ParticleObject

Object holding a dynamic particle array (count at this+0x64, element pointer array at this+0x68) whose instances are updated and swept by two shared-path methods: ParticleInstanceUpdate (0x004CC1D0) interpolates and writes per-particle positions and a packed ARGB alpha with optional driver collision, and ScoringGateTimeoutCheck (0x004CDAD0) removes particles whose stored time exceeds the current time. Both are gated on the global scoring flag dword_8AB6E4 == 2 and delegate to the scoring system 0x004B9CE0 with &dword_8AB6EC, which is the common-ownership evidence. The base position this+0xC/0x10/0x14 and the time-scaled multipliers this+0x18/0x1C/0x20 are read only by ParticleInstanceUpdate. The particle descriptor layout beyond the array fields is not packet-evidenced.

## Compatibility contracts

- **ParticleArrayLifetimeContract** — Replacement must preserve the particle container contract: a particle object keeps a dynamic array with count at this+0x64 and element pointer array at this+0x68, and particles are removed through ArrayElementRemoval (0x004CB5A0) when the current time leaves their lifetime window (0x004CC1D0 compares descriptor window fields, 0x004CDAD0 removes elements whose float at element+8 exceeds the current time; the two element layouts are not reconciled by this packet).
- **ScoringSystemDelegationContract** — Replacement must preserve the scoring gate: when the global scoring flag dword_8AB6E4 equals 2, particle update and timeout paths delegate to the scoring system (0x004B9CE0) passing the address of dword_8AB6EC; otherwise the default simulation time from dbl_8AFEA0 is used.
- **DriverStandingOrderUpdateContract** — Replacement must reproduce the standings/proximity update cadence: on a countdown expiry (timer at this+0x120 reset to 0.25f via dbl_8AFE98) the monitor iterates the active vehicle array (dword_7C54F0, count dword_5C329C), computes per-vehicle position-change gaps, and when the proximity flag at this+0x104 toggles encodes a type-33/type-34 enter/leave event into the ring (head dword_8AAE64 bounded by dword_83EE60 below 1023, stride 432) with the dbl_8AFEA0 timestamp; when the sorted standing-order array at this+0x128 changes it resets the counter at this+0x124 and encodes a type-7 order-change event.
- **TextRenderPathContract** — Replacement must keep the text-render path: assembled text is drawn through UITextRenderWithScale (0x004D7E40), string building uses StringFormatWithBufferOverflowCheck (0x0058815F), and render/resource context selection routes through SwitchBasedGlobalLookup (0x004D7FA0), which returns one of the four contiguous dwords at 0x008AD388..0x008AD394 selected by the switch argument.
