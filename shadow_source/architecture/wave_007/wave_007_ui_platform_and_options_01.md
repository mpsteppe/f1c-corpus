# UiPlatformAndOptions

Scope: `ui_platform_and_options`  
Trust: `GUESS`

Proposes six class boundaries over the 37 validated functions. UiSubObjectStringAccessor (DERIVED) is the strongest: its three members share the identical this+0xC8 sub-object access pattern, the same default-path fallback global byte_5EA438, and the same caller UILargeRender (0x00496930). InflateWindowRingBuffer (DERIVED) documents the six-field circular output-window layout of InflateCopyWindowToOutput (0x0052A5D7). CpuidFeatureProbe (GUESS) groups two CPUID EAX=1 / EDX-bit-23 (mask 0x800000) probes. Eleven functions stay ownerless (UnknownObject) because the packet evidences no shared layout; the input-device, options, and compression contracts are recorded as compatibility contracts rather than class claims.

## Proposed classes

### UiSubObjectStringAccessor

Three string-path accessors (UIStringAccessor, UIStringAccessorAt0x20, UIStringAccessorAt0x38) that all read the sub-object pointer at this+0xC8, return 0 when it is null, and otherwise return one of that sub-object's string members (sub+0x18 / sub+0x20 / sub+0x38), falling back to the global default path byte_5EA438 when the member is null. All three are called by UILargeRender (0x00496930) while rendering the large UI layer. The sub-object member offsets are recovered from the raw source only; the packet carries no this-relative evidence for them, and the this-relative fields 0xE0 / 0xE8 / 0x100 are left unresolved.

### UiObjectLifecycle

Family of UI-object construction and destruction helpers sharing the vtable-at-this+0x0 layout and the MSVC scalar-deleting destructor convention (install a base vtable, run a cleanup step, then free this via FreeWrapper_7bcf exactly when the a2 flag bit 0 is set, returning this). ## Compatibility contracts

- **UiScalarDeletingDestructor** — UI-object destructors in this family must install the base vtable at this+0x0, run their cleanup step (releasing owned children at +0xEC / +0x174 only when non-null), and free the object memory via FreeWrapper_7bcf exactly when the a2 flag bit 0 is set; they must return the this pointer unchanged.
- **BooleanToIntPointerPresenceProbe** — The input-device registration thunks (RegisterInputDevice0-5) and UIDelegateUnregistration must return the result of BooleanToIntConversion applied to the int-cast address of their respective global function-pointer slot; the conversion reduces the pointer's presence/nullness to a 0/1 integer and the thunks must have no other side effects.
- **UiStringPathAccessWithDefault** — String path accessors must return 0 when the sub-object pointer at this+0xC8 is null, the requested sub-object string member when present, and the global default path byte_5EA438 when the member is null; UILargeRender (0x00496930) consumes these results while rendering the large UI layer.
- **CommandLineOptionKeywords** — Command-line/config parsing must set byte_7CE268 to 1 when the input contains the 'altosc' keyword and dword_7CE264 to 2 when it contains 'skipoptions'; the two checks are independent and both can trigger, and the function returns the result of the 'skipoptions' check.
- **DeflateCodeLengthTreeErrorContract** — InflateBuildCodeLengthTree must return 0 on success, -3 on a code-length-tree error (writing 'oversubscribed dynamic bit lengths tree' or 'incomplete dynamic bit lengths tree' into the stream error slot a5+24), and -4 when the workspace allocation fails; the stream slot roles (a5+24 error string, a5+32 allocator, a5+36 deallocator, a5+40 owner) are inferred from usage.
