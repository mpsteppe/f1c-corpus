# R0 pipeline proof, not real reconstruction work

These `pit`-subsystem packets/launchers were generated only to prove the
index -> plan -> packets -> launchers chain works end to end against the
real corpus. `pit` was picked because it was the largest pre-tagged
subsystem in `recovery_index.json`, not because it is a Phase R2 target.
No worker was ever launched against them. Archived here (not deleted) per
the non-negotiable rule to preserve session output rather than discard it
silently.
