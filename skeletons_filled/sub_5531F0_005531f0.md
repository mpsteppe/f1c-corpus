## sub_5531F0_005531f0 — FontStringMeasure

**Summary:** Measures rendered width and height of a text string. Height from scale factor at offset 0x5C (or a5). Width by summing per-glyph widths from the lookup table at this+8*char-148, filtered to printable chars (>= 0x20) and valid glyph range (< offset 0x44). Scales final width by the same factor. Outputs via pointers a3 (width) and a4 (height).
