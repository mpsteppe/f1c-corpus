## sub_552BA0_00552ba0 — FontTextureSheetAnalyzer

**Summary:** Analyzes a font texture sheet to compute glyph cell layout. Locks the texture surface, scans pixel data to find horizontal and vertical divisions (glyph cell boundaries) by searching for sentinel color values. Computes cell stride and count, builds a per-cell lookup table (glyph index → sheet position, row/column), and adjusts pixel transparency (alpha key) based on comparison with key colors.
