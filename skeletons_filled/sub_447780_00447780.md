**Guard interpretation:** Function requires sub-object count > 0 to copy input transforms. Force computation uses mode selector (0x1E14): mode 0 averages front-left and front-right (offsets 0x348, 0x3EC), mode 1 averages all four corners, mode 2 averages only front pair. Suspension output (0x1C5C) is clamped against lower bound computed from damper factor (0x1C84) and tire index (0x1C88). If clamped result falls below minimum threshold (0x1CDC), position/lap state is forced to tire index 0; otherwise uses computed tire index. Final output is replicated to four suspension state words (0x1E38-0x1E44) and three shadow copies (0x7736-0x7748). Sub-object update loop iterates 2 sub-objects, skipping any whose pointer is null or whose byte at +100 is set.
