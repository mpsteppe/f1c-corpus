## sub_58BB68_0058bb68 — MemoryBlockSizeQuery

**Summary:** Returns the usable size of a memory allocation. On OS version 3, reads size from allocation header (*(lpMem - 1) - 9) via sub_593E1B region lookup. On OS version 2, reads pool block size (16 * *v3) via MemoryRegionValidationHeapLookup. Falls back to HeapSize if region lookup fails or OS version is neither 2 nor 3.
