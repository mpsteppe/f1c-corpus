## sub_42C440_0042c440 — DriverAssistInputHandler

**Summary:** Per-frame input processor for in-game driver assists — reads input device action codes and toggles steering assist, traction control, ABS, auto-shifting, brake bias, and other driving aids. Also handles session transitions, visual state changes, and suspension vibration triggers. Part of the gameplay input/control subsystem.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** MainGameTickUpdate (0042c690)

**Guard conditions:** Vehicle-loaded check: if PlayerVehiclePtr+13000 is zero (vehicle not loaded) → skip all processing. HUD-disabled check: if byte_7CE254 (DisableHUDFlag) is set → skip all input processing. Track-visual guard: dword_7CC394 (TrackSelectedIndex) must be non-zero AND byte_7C9081 (EngineModeFlag) must be set AND byte_7C74A4 must be zero for VisualStateChange to trigger. Renderer guard: dword_7CC704 (RendererStateFlag) must be non-zero before VehicleActive/SuspensionVibration are called. Input-device loop: iterates up to dword_7CB218 count, dispatching each action code via switch. Unknown action codes fall through (no-op).
