**Guard interpretation:** If stream flags at this+0xC lack read-mode bits (0x83) or have EOF flag (0x40), returns -1 (not readable). If write flag (0x02) is set without read, sets error bit (0x20), returns -1. If stream has no own buffer (flags lack 0x10C), allocates one via MemoryAllocatorInit. If sub_58C9B4 read returns NULL → set EOF flag (0x10); returns -1 → set error flag (0x20). If handle is -1, uses default buffer descriptor for text-mode checks. If buffer size is 512, flags have setvbuf (0x08) and not large-buffer (0x400), auto-grows to 4096.
