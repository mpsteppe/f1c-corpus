## sub_58CA19_0058ca19 — _read: file read with text-mode translation

**Summary:** CRT `_read` implementation that reads bytes from a file handle via ReadFile with text-mode translation (\r\n → \n, Ctrl-Z EOF handling, pushback character support). Handles pipe break and access-denied error mapping.

**Frame-path:** ON_FRAME_PATH

**Guard conditions:** If nNumberOfBytesToRead == 0, returns 0. If handle's EOF flag (bit 1 at critical section +4) is set, returns 0 (already at EOF). If text-mode flag (bit 6) and pushback-present flag (bit 3) are set, uses pushback character at +5 first. On ReadFile failure: ERROR_ACCESS_DENIED (5) → errno=9; ERROR_BROKEN_PIPE (109) → return 0; other → ErrorIDLookupTable. In text mode (bit 7 set at +4), translates \r\n → \n, treats Ctrl-Z (0x1A) as EOF.
