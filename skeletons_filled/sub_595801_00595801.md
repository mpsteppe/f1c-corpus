## sub_595801_00595801 — AllocateFileSlot

**Summary:** Allocates a file slot from the global file descriptor array (dword_8D4920, 32 slots per group, 36 bytes each). Scans for free slot (bit 0 clear), initializes per-slot critical section if needed, marks slot in-use. If no slot found, allocates new group. Returns slot index or -1 on failure.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** sub_595AF9 (00595af9), sub_59B650 (0059b650)
