## sub_59797B_0059797b — FileTruncateOrExtend

**Summary:** Truncates or extends a file to a specified size (lDistanceToMove). Saves current position, seeks to end to get file size, then either truncates via SetEndOfFile (if shrinking) or extends by writing zeros in 4096-byte chunks (if growing). Restores original file position on completion.

**Guard conditions:** Saves current position, seeks to end. If target size == current size, does nothing. If shrinking, seeks to target, sets end of file. If growing, writes zeros in 4096-byte blocks. On read error during extension where TLS error is 5 (access denied), sets TLS error 13. Restores original position. PASSES: 0 on success, -1 on failure.
