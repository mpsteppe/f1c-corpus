## sub_54C0E0_0054c0e0 — Test visibility/classification mask against render state

**Summary:** Tests whether this object's visibility/classification mask (at this+0x38) is compatible with the current renderer visibility state. Returns TRUE if mask is 0 (unconditional pass) or if all bits of the mask are contained in the intersection of global render visibility mask (dword_8B8E34) and the target object's mask (a2+0x84). Used as a visibility filter during scene traversal.

**Guard conditions:** If `this[0x38]` (mask) is 0 → unconditionally returns TRUE (passes all categories). Non-zero mask: returns TRUE only if `(global_mask & this_mask & object_mask) == this_mask` — all bits of this object's category must be present in both the global render state and the target object's mask.
