## sub_591FA1_00591fa1 — LocaleMapStringWithCodePageConversion

**Summary:** Performs locale-sensitive string mapping (LCMapString — upper/lower case, sortkey, etc.) with automatic code-page conversion. Detects WideChar mode at runtime; in mode 2 calls LCMapStringA directly; in mode 1 converts ANSI→Wide→LCMapStringW→Wide→ANSI (or LCMapStringW→sortkey). Returns mapped length or 0 on failure.
