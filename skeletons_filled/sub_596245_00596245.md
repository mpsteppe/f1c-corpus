## sub_596245_00596245 — CRTStringToFloatParser

**Summary:** Parses a decimal/hexadecimal floating-point string into a packed 96-bit representation with sign, exponent, and mantissa. Handles leading whitespace, sign, integer/fractional digits, exponent suffix (e/E), and optional hex prefix. Returns classification code (0-4) indicating result type (zero, normal, overflow, underflow, NaN/etc).
