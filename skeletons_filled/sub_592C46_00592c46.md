**Guard interpretation:** If current char is 34 (double-quote), token is parsed in quote mode scanning until closing quote or NUL (PASS). If char is 32 (space) or 9 (tab), token boundary reached (BLOCKED: argument separator). If char is 92 (backslash) and next is 34, backslash escapes the quote. If in quoted mode and two consecutive quotes (v8[0]==34, v8[1]==34), it represents an escaped literal quote. Non-whitespace chars > 0x20 are normal argument characters. NUL byte terminates all parsing.
