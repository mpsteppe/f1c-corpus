**Guard conditions:** Implicit gate — results file is only written when:
- `byte_7D0B28` (MultiplayerFlag) is non-zero **OR** `dword_7C56A4` (SessionType) == 7
Additional gate: `sub_566940(v6, 0, 1, 1) == 1` (file open must succeed).

**Guard interpretation:** **BLOCKED (no file write, cleanup only):** when `MultiplayerFlag == 0` AND `SessionType != 7` — jumps to LABEL_46, skips all file writing, only frees the path string. **PASSES:** when `MultiplayerFlag != 0` (writes timestamped multiplayer results file) OR `SessionType == 7` (writes "RaceResults.txt"). Within the passed path, if `sub_566940` (file open) fails, the inner block is also silently skipped.
