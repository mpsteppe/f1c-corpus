## sub_534D50_00534d50 — File header/protocol parser (stream reader)

**Summary:** Reads and validates a 2-byte protocol magic from a buffered stream, then parses block header (size, flags) and skips content based on flag bits (0x4, 0x8, 0x10, 0x2). File I/O/stream parsing system.

**Guard interpretation:** First loop reads 2 magic bytes from stream comparing against `dword_5DA780`. If mismatch before 2 bytes match → early exit. If first byte read returns -1 (EOF) → also handle backout. After magic validated, 3rd byte `v6` flag bits are checked: bit 1 (0x2) → read 2 more bytes; bit 2 (0x4) → read 2-byte length then skip that many bytes; bit 3 (0x8) → skip until zero byte; bit 4 (0x10) → skip until zero byte. Final result: `this[14] = this[15] != 0 ? -3 : 0`.
