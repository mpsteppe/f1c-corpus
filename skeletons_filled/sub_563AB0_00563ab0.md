## sub_563AB0_00563ab0 — Network Audio Stream Receiver and Socket Manager

**Summary:** Manages a UDP socket array for receiving and processing real-time audio stream packets. Polls up to 64 sockets non-blocking via select(), feeds received data through an audio mixer, detects "final" completion markers to trigger callbacks, times out idle sockets after 3 seconds, and dynamically activates new sockets from a LinearInterpolation pool with sendto() handshake.

**Guard interpretation:**
- `this+0x6C (socket count) > 0`: **PASSES** when sockets exist in the array — enters select/recv, timeout, and send phases. **BLOCKED** when count is 0 — all network phases skipped, function returns 0.

Additional significant guards from code:
- `entry[1] (active flag) != 0` in select build loop: **PASSES** for active sockets; inactive sockets skipped.
- `active_count < 64` (fd_set limit): **PASSES** for first 64 active sockets; excess sockets excluded from poll.
- `select() == -1`: **BLOCKED** on Winsock error — receive processing skipped entirely.
- `select() == 0` (no data): **BLOCKED** when no sockets have pending data — receive loop skipped.
- `__WSAFDIsSet(socket, &readfds)`: **PASSES** per socket when data is available for reading.
- Source address match (`from.addr == expected_addr && from.port == expected_port`): **PASSES** when datagram comes from expected peer. **BLOCKED** (packet silently ignored) when from unknown source.
- `recvfrom() == -1`: **BLOCKED** on receive error — socket deactivated (active flag set to 0).
- `sub_587C20(buf, "final") != 0`: **PASSES** when "final" completion marker found — triggers completion callback and deactivates socket.
- `GetTickCount() - entry_timestamp > 3000` (0xBB8 ms): **PASSES** when socket idle exceeds 3 seconds — socket deactivated.
- `*(this+116) != 0 || (*(this+112) >= total && active_socket_count == 0)`: **PASSES** for cleanup — either shutdown flag set or all packets sent with no active sockets remaining. Triggers NetworkSocketArrayCleanup and AudioValueSetterCall.
- `*(this+112) < total` in activation loop: **PASSES** when more sockets need to be activated. Gets next from pool, sets up address/port, and sends initial datagram via sendto.
