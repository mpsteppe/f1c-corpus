## sub_598569_00598569 — MbStrChrWithDBCS

**Summary:** Searches for a character value in a multibyte string, handling DBCS lead bytes properly. If code page tables are uninitialized (dword_8D46CC == 0), delegates to a simple fallback. Otherwise uses character classification table to skip DBCS lead/trail byte pairs and compares against the target character. Under critical section. Part of CRT multibyte string handling.

**Guard conditions:** If dword_8D46CC == 0 (code page tables not initialized), skips direct table logic and uses fallback sub_589DB0. Otherwise enters critical section, iterates string: if current byte is DBCS lead byte (bit 4 flag in byte_8D47E1), extracts 16-bit character and compares against a2; otherwise compares single byte against a2. Returns pointer to match or 0 if not found.
