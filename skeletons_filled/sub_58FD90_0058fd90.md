## sub_58FD90_0058fd90 — LocaleResolveAndValidate

**Summary:** Resolves a locale from language/region strings. Initializes locale info function pointer based on OS (GetLocaleInfoA on NT, sub_5904F7 on Win9x). Performs binary search matches of language string (a1) and region string (a1+64) against locale tables. Validates resulting code page and locale. Fills output structure with locale ID, language ID, and code page. Returns 1 on success, 0 on failure.
