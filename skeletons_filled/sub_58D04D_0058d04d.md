## sub_58D04D_0058d04d — fprintf: formatted output to file stream

**Summary:** CRT `fprintf`/`printf` core implementation. Parses a format string with full specifier support (flags `#+-0`, width, precision, size prefixes `h/l/w/I64`, conversion characters `d/i/o/u/x/X/c/s/p/n/e/E/f/g/G/Z/C/S`) and writes formatted output to a file stream. Uses a state machine driven by format-classification table byte_5B8D88.

**Guard conditions:** If format string is empty, returns 0 immediately. Format characters outside ASCII range [32,120] are treated as invalid (skipped). State machine dispatches via byte_5B8D88 transition table: case 1=end, 2=flags, 3=width, 4=dot/precision, 5=precision, 6=size prefix, 7=conversion type. Non-graphic characters are output directly via StreamByteOutputWithBufferManagement. On invalid format specifier, behavior depends on state — unknown conversions silently fall through.
