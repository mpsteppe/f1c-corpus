**Guard conditions:** The main guard chain controls anti-roll force distribution: (1) If suspensionTravel is zero, damper scale factor is reset to 1.0 and a damper decay is computed; if damper crosses a threshold, a HUD damage warning is triggered. (2) If antiRollDistributionMode is non-zero AND suspensionTravel > 0, the anti-roll force is distributed: mode 0 = rear wheels only (0.5 each), mode 1 = front wheels (0.25 each) + rear wheels (0.25 each), mode 2 = all four wheels equally (0.25 each). If distribution mode is zero or travel is zero, no anti-roll forces are written.
