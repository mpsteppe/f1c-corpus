## sub_4A3570_004a3570 — PitOpCountdownAndDeltaUpdater

**Summary:** Dual-mode pit operation element updater. When flag bit 0 is set, decrements a countdown timer and resets each array element's float at offset +68 to -1.0f and calls sub_4A2840 with 0.0. When flag bit 1 is set, computes delta `a2 - this[1]` and calls sub_4A2840 on each element with the delta. Both modes are independent and can execute in the same tick.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** ConditionalDispatch_55a0 (004a55a0)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | R | — | Flags field; bit 0 = countdown-active flag, bit 1 = delta-update flag |
| this | 0x4 | R | — | Previous/reference float value used to compute delta for mode 2 |
| this | 0x8 | RW | — | Countdown counter; decremented each tick when bit 0 is set |
| this | 0xC | R | — | Number of elements in the array |
| this | 0x10 | R | — | Pointer to base of 120-byte-element array |

**Written-by note (persistence):**
- this 0x8: recalc every frame — external poke does NOT persist

**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|
| this | 0x0 | & | 1 | Bit 0 of flags — countdown mode enable |
| this | 0x0 | & | 2 | Bit 1 of flags — delta-update mode enable |
| this | 0x8 | > | 0 | Countdown counter; actions skipped when counter ≤ 0 |

**Guard interpretation:** Bit 0 (countdown) block: PASSES only when byte at offset 0 has bit 0 set AND counter (offset 8) > 0. Bit 1 (delta) block: PASSES only when byte at offset 0 has bit 1 set. Each block is independent.
