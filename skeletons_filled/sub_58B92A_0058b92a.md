## sub_58B92A_0058b92a — DriveLetterPathResolution

**Summary:** Resolves a file path to its full path. If FileName is provided, validates it via sub_58B9FF, prepends a drive letter (v3+64 = 'A'-'Z'), prepends ":.\", and calls GetFullPathNameA. If FileName is NULL, uses GetCurrentDirectoryA. Returns result in caller-provided buffer or newly allocated memory via sub_58FCA0.
