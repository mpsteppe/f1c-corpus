## sub_596089_00596089 — WideCharToMultiByteSingle

**Summary:** Converts a single wide character (WideCharStr) to multi-byte via WideCharToMultiByte using the default CodePage. If no locale is set (dword_8D3F38 == 0) and the character is <= 0xFF, does a direct truncation. Returns byte count written, or -1 (TLS error 42) on failure.
