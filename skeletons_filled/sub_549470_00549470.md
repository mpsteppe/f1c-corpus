## sub_549470_00549470 — Compute OBB and bounding sphere from scene mesh data

**Summary:** Three-pass computation of oriented bounding box (OBB) and bounding sphere from vertex data in scene graph. First pass accumulates covariance matrix from all vertices and calls QRDecomposition to derive orientation axes. Second pass transforms vertices through resulting rotation matrix via D3D device wrapper and computes axis-aligned bounding box in local frame. Third pass computes farthest vertex distance for bounding sphere radius. Final loop builds 8 OBB corner points with axes and half-extents. Stores results in `this` offsets 0x18 (sphere radius), 0x1C-0x70 (OBB corners via D3D transforms), 0x7C-0x84 (center), 0x8C-0xE8 (OBB axes/half-extents). Called during audio engine initialization for spatial audio geometry.
