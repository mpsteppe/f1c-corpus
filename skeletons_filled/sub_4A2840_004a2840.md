## sub_4A2840_004a2840 — KeyframeAnimationUpdater

**Summary:** Updates keyframe-driven animation state: iterates through keyframe segments (7 floats each), interpolates output value based on input parameter a2, calls listener callbacks when value changes. Tracks last value for change detection. Part of animation/UI system (pit crew/animation).

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** sub_4A3390 (004a3390), sub_4A3570 (004a3570), F_3DDistanceCheckAccumulate (004d0b20)

**Guard conditions:** Guard at this+0x6C (listener array): if NULL, skip entire update. Guard at this+0x70 (segment count): if <= 0, skip. Keyframe search: linear scan segments; if a2 > segment.max, advance; if a2 <= segment.max, perform interpolation (block after returning). If loop completes without match, clamp to last segment's output max. If a2 < first segment min, clamp to first segment's output min.
