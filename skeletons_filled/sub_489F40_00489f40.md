## sub_489F40_00489f40 — Screen coordinate to list index conversion

**Summary:** Converts screen y-coordinate (a2) to list item index using layout parameters: (coord - offset_horizontal - column_offset - start) / item_height + scroll_offset. Clamps result within scroll bounds and item count. Used for mouse click hit-testing.
