## sub_595AF9_00595af9 — CRTFileOpenCreate

**Summary:** CRT file open/create wrapper around CreateFileA. Parses flag field (a2) into access mode, share mode, creation disposition, and flags-and-attributes; allocates a descriptor slot via sub_595801, assigns the handle via sub_595924, optionally reads first byte for EOF marker (0x1A) detection, and returns the file descriptor index or -1 on error.
