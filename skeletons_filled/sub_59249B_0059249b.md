## sub_59249B_0059249b — Daylight Saving Time (DST) Transition Check

**Summary:** Determines whether a given timestamp falls within Daylight Saving Time by checking against the Windows TIME_ZONE_INFORMATION structure. If the year has changed since last configuration, re-computes DST start/end transition dates via sub_592647.

**Guard conditions:** First guard: `if ( !dword_5E775C ) return 0;` — if DST is globally disabled (BLOCKED), return FALSE immediately (not in DST). Second guard: `if ( v2 != dword_5E77F0 || v2 != dword_5E7800 )` — if the input year differs from either cached DST start year or cached DST end year (year rollover detected, PASSES), calls sub_592647 to recompute DST transition dates for the new year, then falls through to day-of-year range check. Third guard: day-of-year range check — if `dword_5E77F4 < dword_5E7804` (Northern hemisphere: start < end), checks if day-of-year is within [start, end] inclusive, with edge cases at the exact boundaries comparing time-of-day in milliseconds. If the range is inverted (Southern hemisphere: start > end), checks if day-of-year is outside the [end, start] gap. Returns 1 (TRUE = in DST) or 0 (FALSE = not in DST).
