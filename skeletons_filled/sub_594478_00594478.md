## sub_594478_00594478 — SlabHeapAllocateNewSlab

**Summary:** Allocates a new slab (32KB block) for the custom heap allocator. Grows slab descriptor array via HeapReAlloc if capacity exhausted. Allocates bitmap/free-list metadata (0x41C4 bytes) via HeapAlloc and slab memory (1MB reserve) via VirtualAlloc. Initializes descriptor fields and bitmap. Returns descriptor pointer or 0 on failure.
