## sub_54A870_0054a870 — Load and register mesh file from disk/paths

**Summary:** Loads a mesh file referenced by string name. Validates filename starts with "mts_", then attempts to open the file directly or via registered search paths (byte_8B5A3C array, stride 0x84). On failure, searches object linked list at dword_8B8F14 to find mesh data. Reads file contents via sub_54AC70 into buffer. On success, stores context pointer in loaded data (v16+312), optionally passes mesh dimensions to sub_54B4D0 based on flag bit at this+0x3C bit 4, registers mesh via sub_54B570 and LinkedListAppend_abe0, and clears flag bit 15 at this+0x3C. Returns 0 on success, -1 on failure with error message.
