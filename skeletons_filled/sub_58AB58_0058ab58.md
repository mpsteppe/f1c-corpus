## sub_58AB58_0058ab58 — Aligned counted-element allocator with debug heap retry

**Summary:** Multi-strategy memory allocator (count * size) with 16-byte alignment and zero-initialization. Dispatches to pool allocator (Win2K or WinXP style) or HeapAlloc based on OS version and size. Retries via debug heap callback when CRT_DebugHeapFlag is set and primary allocation fails.

**Guard conditions:** If total (a2*a1) > 0xFFFFFFE0, skips 16-byte alignment. Checks OSVersionCode==3 for WinXP path: uses pool alloc if size <= HeapMaxAllocSize, else HeapAlloc. Checks OSVersionCode==2 and size <= PoolAllocMaxBlock for Win2K pool path. All pool allocations zero-filled via sub_58BB10. On pool alloc failure, falls back to HeapAlloc with HEAP_ZERO_MEMORY (flag 0x8). If primary alloc fails and CRT_DebugHeapFlag is set, retries via GlobalCallbackDispatcherWithNullCheck; returns NULL if debug alloc also fails.
