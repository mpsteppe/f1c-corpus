## sub_4D59B0_004d59b0 — TelemetryOptionFlagsPacker

**Summary:** Packs 11 option/settings flags into a bitfield (2 bits each) plus multiplayer option flag, tire model mode, player vehicle mode flag, and input mode flag. Writes the packed bitfield and several physics globals (rain fade, track grip, temperature offsets, brake balance) through sub_4D5BE0 debug data writer.
