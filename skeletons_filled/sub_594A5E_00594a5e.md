## sub_594A5E_00594a5e — SlabBuddyAllocatorDestroy

**Summary:** Destroys a slab buddy allocator context. Releases committed virtual memory via VirtualFree, unlinks from allocator linked list, frees context structure via HeapFree (for dynamic pools) or resets HeapMarker to static pool mode. Handles both dynamic and static pool contexts.
