## sub_553370_00553370 — RenderBufferInitByType

**Summary:** Initializes a render vertex buffer for type 1 (384-byte, 24-byte source stride) or type 2 (448-byte, 28-byte source stride with brightness/volume scaling). Allocates buffer descriptor and vertex memory, copies source vertex data with layout transformation (24→28 or 28→24 byte conversion depending on type). Sets primitive type (34), vertex count (16), and stride (322/324).
