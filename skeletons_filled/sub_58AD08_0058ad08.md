## sub_58AD08_0058ad08 — File stream position with text-mode newline adjustment

**Summary:** CRT file stream position/remaining-bytes calculator. Queries file size, accounts for buffered read position, and adjusts for text-mode newline (0x0A) expansion. Sets errno to EINVAL (22) on invalid mode flag combination.

**Guard conditions (deterministic — field vs literal):**

|------|--------|------|-------|-----------------|

| this | 0x4 | < | 0 | File position is negative |

**Guard interpretation:** If position (this+0x4) is negative, clamp to 0. If stream flags at this+0xC lack (0x108) — binary mode + EOF — return file_size - position directly. In text mode ((flags & 3) != 0), count embedded newlines in buffer to adjust remaining count. If read flag bit (0x80) is clear in non-text mode, set errno=22 and return -1 (invalid mode). When position != 0 and stream is unbuffered ((flags & 1) != 0), recalculate accounting for text-mode newline expansion or fall back to buffer-size estimate.
