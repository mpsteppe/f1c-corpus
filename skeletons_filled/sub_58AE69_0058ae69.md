## sub_58AE69_0058ae69 — _fdopen: file descriptor to FILE stream with mode parsing

**Summary:** CRT `_fdopen` implementation that allocates a FILE stream structure for an open OS file handle and parses the mode string ("r", "w", "a" with modifiers "+tbcnSRTD"). Increments global file open count.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** BinaryDataDeserialization (004054e0), sub_534B10 (00534b10)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|
| 008d3ec8 | dword_8D3EC8 | W | Global file open count, incremented on stream creation |
| 008d41bc | dword_8D41BC | R | Default mode flags ORed into every stream's flags |
| 008d4920 | dword_8D4920 | R | Critical section array for file handle locking |
| 008d4a20 | uNumber | R | Maximum number of open file handles |

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 0058c203 | AddressRangeCriticalSectionLeave | Leave critical section guarding the stream structure |
| 0058c5ac | sub_58C5AC | Allocate a new FILE stream structure from internal pool |

**Guard conditions:** If a1 >= uNumber (max open files), returns 0. If critical section entry for handle at bit 0 is unset (handle not open), returns 0. If sub_58C5AC stream allocation fails, returns 0. Mode string first character must be 'r' (read), 'w' (write), or 'a' (append); otherwise returns 0 (invalid mode).
