**Guard conditions:** The function is structured as a 4-level dispatch tree: (1) Major type extracted from bits 29-31 of `*(DWORD*)this`. Cases: 1, 2, 3, 4, 6 (default returns). (2) Within each major type, sub-type extracted from bits 18-23 (6-bit field, values 0-63). (3) Most handlers also check vehicle index (bits 0-7) < 0x68 (104 vehicles max). (4) Some handlers additionally check vehicle state fields: for type 1 sub-types 0,7 — vehicle field at offset 0x6F0 must be 2; for type 1 sub-types 1-6 — vehicle field at offset 0x32C8 must be 2; for type 6 sub-type 1 — vehicle field at offset 0x32C8 must be 2. (5) Type 2 sub-type 2 checks vehicle field >= 2 and additionally checks sub-field bits 0x3FF00 == 0x600 to clear fields at this+0xE and this+0x10. (6) Type 3 sub-type 6 skips sound if byte_7CE254 (HUD disable) is non-zero. (7) Type 4 sub-type 20 skips pit timer if dword_8AB6E4 (scoring gate) == 2.
