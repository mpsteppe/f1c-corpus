## sub_59416F_0059416f — SlabHeapAllocateBlock

**Summary:** Allocates a block from the custom slab buddy allocator. Rounds request size up to 16-byte boundary, searches slab descriptors for suitable free block (wrapping cursor), splits remainder, updates two-level free bitmap and free lists. Returns pointer to allocated memory or 0 on failure.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick
