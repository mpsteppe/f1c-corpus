## sub_41AC50_0041ac50 — GearBasedEventDispatch

**Summary:** Handles gear-related and retirement commentary events for AI vehicles during championship weekend (session type 7). Event type a2 determines category: 0=generic vehicle event (208), 2=gear-specific events (211-217 based on current gear), 3=retirement event (220). For non-player, non-finished vehicles only.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** EngineStressSimulation (0043ef20), FuelConsumptionAndWear (004ed960)

| this | 0x4064 | R | — | FinishState — must be 0 (not finished) to proceed |
| this | 0x489C | R | — | Driver ID — used as context index for event entry |

Must NOT be player vehicle (dword_7C54E8 null or != a1). FinishState (this+0x4064) must be 0 (not finished). Event type a2 must be 0, 2, or 3; a2==2 requires valid gear mapping via switch.
