## sub_594C12_00594c12 — SlabBuddyAllocateMemory

**Summary:** Allocates memory from the slab buddy allocator system. Iterates existing allocator contexts searching for a free block of sufficient size via sub_594E1A. If none found, creates a new context via SlabBuddyAllocatorInitialization. Returns allocated pointer or 0 on failure.

**Frame-path:** ON_FRAME_PATH
