## sub_55E320_0055e320 — 3D Mesh Vertex Transform & Color Lighting Pipeline

**Summary:** Performs per-vertex 3D transformation, lighting, and color computation for a mesh. Reads vertex positions from scene data, applies world-to-screen transforms (frustum culling), computes specular lighting via lookup table, handles MMX-accelerated color packing (packuswb), and writes transformed vertices + lighting colors to output buffer.

**Guard interpretation:** When light count (0x124) > 0, the dynamic lighting loop executes: iterates over each light source, computes distance falloff, accumulates diffuse color contribution per vertex. When 0, dynamic lighting is skipped — only base diffuse color (packed via MMX packuswb) is written. Additionally, bit 0x100 in this[0] gates vertex relocation pass (reads from mesh at 0x128+272 and transforms positions). Bit 0x40 in flags gates diffuse color read from this[1]+100..108. Bit 0x4000 gates alpha scaling. Bit 0x80 (specular enable) gates the specular lighting pass (face-normal dot light calculation with TableLookupScale).
