## sub_49A5D0_0049a5d0 — UICommandDispatch

**Summary:** Dispatches UI actions based on a command ID at offset 0x00. Cases 1-6 perform list navigation (search by name, utility action with varying parameter, set current page string). Case 7 searches list items and performs linked list search. Case 9 copies string parameters. Case 0xA triggers polling loop. Case 0xB sets global multiplayer active flag to -1 (shutdown). Case 0xC sets up a rendering context and calls vtable methods. Cases 3-6 optionally use offset 0x14 as a TwoFieldSetter parameter.
