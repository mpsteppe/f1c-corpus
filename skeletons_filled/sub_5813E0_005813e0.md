## sub_5813E0_005813e0 — Transfer context lookup-or-create from parsed request

**Summary:** Parses incoming binary packet via BinaryPacketFieldParser, searches linked list of transfer contexts at this+0xAC8 for matching ID (node+0x14). Found: copies parsed data into existing node via ObjectInitWithCopy. Not found: allocates new node+link wrapper, appends to list, increments count. When context type==2 and output condition met (a4 flag or MutexProtectedPointerReadRelease==3), copies sockaddr and calls sub_57DD40 to send response.
