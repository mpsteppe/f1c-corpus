## sub_58F939_0058f939 — CodePageCharTypeTableInit

**Summary:** Initializes character type tables for the current code page. If dword_8D3F38 (DefaultLocale) is nonzero, queries code page info via GetCPInfo, builds 256-entry SBCS/DBCS character maps, converts to type tables via sub_595DC8/sub_596A2E, marks lead byte ranges with flag 0x8000 for DBCS, and stores in off_5E69C8/off_5E69CC. If zero, uses static table word_5E69D2.
