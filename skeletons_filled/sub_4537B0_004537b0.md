**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|
| this | 0x1180 | & 1 != 0 | 1 | state block 0 enable flag; bit 0 enables float clamping + byte dispatch + dword comparisons |
| this | 0x157C | & 1 != 0 | 1 | state block 1 enable flag; same control as 0x1180 but for second block of channels |

**Guard interpretation:** Two independent enable masks control whether vehicle state is broadcast. `this[0x1180] & 1` gates block 0 (offsets 0x1140-0x117C) covering 8 float channels + 16 byte flags + 4 dword comparison tiers. `this[0x157C] & 1` gates block 1 (offsets 0x153C-0x156B) following identical pattern. Within each block, bit 7 (sign) of the mask enables dword equality comparisons, and bits 8 (0x100), 9 (0x200), 10 (0x400) cascade to deeper comparison tiers. PASSES: mask bit is set → data broadcast to globals. BLOCKED: mask bit is zero → entire block skipped, no state published.
