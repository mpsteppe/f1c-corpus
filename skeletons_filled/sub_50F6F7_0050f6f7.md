**Guard interpretation:** SOF marker type 3 (baseline DCT): validates component count (this+0x100/0x106/0x107) and color space (IDs from frame header at this+0xC4). If header IDs match RGB (82='R', 71='G', 66='B') → set sub-state 2. If IDs are 1,2,3 (YCbCr) → sub-state 3. Invalid IDs → error 107 reported via callback. SOS marker type 4: if components present and component ID valid (==2) → sub-state 5, else stays at 4. All paths then initialize quantization scale (1.0), reset MCU counters, and configure restart parameters.
