**Guard conditions:** Returns 0 (error) if the block is in use (bit 0 of header size is set) OR if the requested aligned size `v4` exceeds the block's total available space `v6 + v7`. If `v4 <= v6`, the block is split into an allocated part and a free remainder — the remainder is inserted into the free list at the appropriate size class. If `v4 > v6` (and block is free with sufficient total space), the block is coalesced with its buddy, merged into a larger free block, and the bitmap tracking is updated accordingly.
