## sub_552D70_00552d70 — FontTextureSheetAnalyzer32

**Summary:** 32-bit RGBA variant of font texture sheet analysis. Locks texture surface, scans 32-bit pixel data to find horizontal and vertical cell divisions via sentinel color comparison. Builds per-cell lookup table for glyph positions. Replaces key colors (transparency sentinel) with 0xF0F0F0 and adds full alpha (0xFF000000) to non-key pixels. Mirrors sub_552BA0 but operates on 32-bit pixel format (7 or 8).
