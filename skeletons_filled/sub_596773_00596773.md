## sub_596773_00596773 — MultiByteToWideCharSingle

**Summary:** Converts a single multi-byte character to a wide character. If no locale is set (dword_8D3F38 == 0), does direct byte-to-wchar assignment. Otherwise uses CharTypeTable to check lead byte, then MultiByteToWideChar with the default CodePage, handling lead-byte sequences via cbMultiByte. Returns number of bytes consumed or -1 (TLS error 42) on failure.
