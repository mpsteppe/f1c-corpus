**Guard interpretation:** The entire update block runs only when the countdown at this+0x120 <= 0 (timer expired). Per-vehicle: skip vehicles in state 2 (retired). The active flag (v4) is set for vehicles whose position delta is within threshold range; transitions from active/inactive are logged. Sorted order is logged when it changes, or every 16 ticks even if unchanged.
