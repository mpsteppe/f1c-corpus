## sub_594529_00594529 — SlabHeapInitBitmapAndFreeLists

**Summary:** Initializes a newly allocated slab for first use. Commits 32KB slab virtual memory via VirtualAlloc, initializes 64 free-list heads, sets up per-block header linked lists (free block chain), configures bitmap tracking entries, and updates slab descriptor flags. Returns slab size class index or -1 on VirtualAlloc failure.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick
