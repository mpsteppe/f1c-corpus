## sub_4A3390_004a3390 — PitCrewAnimationStateProcessor

**Summary:** Processes pit crew animation state: iterates through child animation entries (stride 120 bytes), updates keyframe animations via sub_4A2840, manages visibility/flag bits based on active state, and triggers UI widget update when detail level >= 2. Part of pit crew rendering system.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** PitstopStateTransition (004a5600), AIStateMachineWithModeDispatch (004a5d10)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | RW | — | Initialized flag (bit 0: set to 1 after first run to prevent re-execution) |
| this | 0xC | R | — | Number of child animation entries to process |
| this | 0x10 | R | — | Child animation entry array pointer |
| this | 0x14 | R | — | UI widget activation guard (non-zero enables recursive UI update) |

**Written-by note (persistence):**
- this 0x0: recalc every frame — external poke does NOT persist

**Functions called:**

|---------|------|---------|
| 004a2840 | sub_4A2840 | Update keyframe animation for child entry (reset to 0.0) |

**Guard conditions:** Bit 0 check at this[0]: if already set (executed once), BLOCK entire function (skip animation processing). Loop guard: if this[3] (child count) <= 0, skip. Per-child guard: if child[100] == 0 (inactive), skip that child. Guard on a2 flag and child byte at +3: if a2 set AND child byte 3 is clear, skip bit update. Guard on child[72] != -1 AND child[100] != 0: triggers resource cleanup.
