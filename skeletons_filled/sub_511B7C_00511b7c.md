**Guard interpretation:** The switch on field 0x114 (Adam7 pass index 0-6) determines which bit mask from field 0xD4 is checked against the pass threshold. Field 0xB8 holds the row count available for the current pass; when it falls below the per-pass threshold (5, 3, or 2), the pass is considered complete and decoding moves to the next phase. This implements the Adam7 interlace row-completion logic where each pass processes progressively fewer rows.
