## sub_403640_00403640 — Nearest-neighbor spatial query with plane test

**Summary:** Finds the closest physics strut or collision node to a query point using both Euclidean squared-distance and a signed-distance plane-proximity score. When a starting node is provided, walks its linked collision geometry lists to find the nearest neighbor; then scans all active struts to find the globally closest candidate that passes the plane test.
