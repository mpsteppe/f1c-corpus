**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|
| this | 0x105B | == | 0 | tire-slip sentinel: when zero, blocks the grip-condition evaluation branch (no slip correction applied) |
| this | 0x32BC | == | 2 | physics mode: when mode==2, PASSES into extra angular-velocity integration loop (applies frame-delta damping to wheel angular state) |

**Guard interpretation:** Guard at 0x105B==0 BLOCKS the tire-grip threshold evaluation branch — when the sentinel is clear, grip/slip correction logic is skipped. Guard at 0x32BC==2 ENABLES the angular velocity accumulation sub-path within the simplified physics path (case 2 only), adding per-wheel angular damping accumulation not present in case 1.
