## sub_581940_00581940 — Linked list node removal by ID with vtable release

**Summary:** Searches linked list for node whose data pointer matches a2, unlinks it, updates head/tail/cursor/count. Optionally clears node's release-flag (node+8) based on a3. If release-flag is set, calls vtable entry 1 (offset +4) on data object with refcount 1. Frees node wrapper via FreeWrapper_7bcf. Returns 1 if found and removed, 0 otherwise.
