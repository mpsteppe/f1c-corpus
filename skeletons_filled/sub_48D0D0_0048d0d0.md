## sub_48D0D0_0048d0d0 — ListScrollCentering

**Summary:** Computes which list item index should be centered in visible area based on scroll position (this+0x334) and offset. Steps one-by-one toward target index via vtable[46] callback. Used for list/gallery scrolling with centering.

**Guard conditions:** If visible range (vtable[8] - vtable[6]) <= 0 → BLOCKED: no centering computed. If total range (step * count) <= 0 → BLOCKED: scroll skipped. The computed target index v11 is clamped to [0, count-1]. If v11 equals current target this[206] → BLOCKED: no stepping (loop body skipped). Otherwise loop calls vtable[46] repeatedly until target reached.
