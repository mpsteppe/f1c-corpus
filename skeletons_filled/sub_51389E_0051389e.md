**Guard interpretation:**

- this+0x61 & 0x10 → if set, enters first transform block; inside, this+0xF8 == 3 routes to sub_512E1A deinterlace, else this+0x10A != 0 routes to BitmapDecompression with row params, else BitmapDecompression with null params

- this+0x61 & 0x04 → BIT EXPAND: calls BitExpandDecompress

- this+0x60 & 0x04 → UNPACK: calls BitPackingUnpacking
- this+0x60 & 0x01 → SWAP: calls sub_5123E0
- this+0x61 < 0 (bit 0x80) → EXPAND: calls PixelFormatExpansion
- this+0x60 & 0x10 → INVERT: calls sub_5123B3
