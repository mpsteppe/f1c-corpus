**Guard interpretation:** The compound-match blocks are enabled when the sign bit of the gate dword is set (value < 0). When the sign bit is clear (>= 0), the entire nested if-chain is skipped — no compound-matched IDs (70-85 for batch 1, 86-101 for batch 2) are produced. Within each enabled chain, additional bitmask tests (0x100, 0x200, 0x400) on the same gate dword control sub-levels of value matching. Simple checks (ConstraintForceEval, SweptAABBOverlapDetection, and byte flags) run unconditionally regardless of gate state.
