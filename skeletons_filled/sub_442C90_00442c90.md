**Guard conditions:** Four loops iterate over 4 wheels (index 0-3). Each wheel's data block starts at `this + 1040 + wheel*1124`. The flag at `*(v2 + 124)` (wheel-state active flag) is checked; if non-zero, the wheel is skipped (inactive). After the main loop, three anti-roll-bar blocks check bypass flags: `this+0x48C` (front), `this+0x8F0` (rear upper), `this+0xD54` (rear lower) — if zero, the ARB torque is computed. Also checks `dword_7CE958` (TireModelMode) before accumulating angular velocity. The final loop checks `*(v30 + 160)` per wheel — if zero, angular momentum and cross-product forces are accumulated.
