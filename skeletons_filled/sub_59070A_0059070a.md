**Guard conditions:** If `dword_8D3E40` (MathErrHandlingFlag) non-zero, returns result immediately (BLOCKED: math error handling disabled). If FPU status byte is 0, falls through to precision flag check. If status is -1 (underflow) and exponent is 0, scales up and clamps to zero if below denormal threshold.
