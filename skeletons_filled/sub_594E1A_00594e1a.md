## sub_594E1A_00594e1a — SlabSubAllocatorCarveBlock

**Summary:** Carves a block from a pre-committed slab region using a bump/sub-allocator with byte-size headers. Tries the current cursor first; if insufficient space, scans previously allocated blocks for free gaps. Returns pointer to allocated memory or 0 if no fit.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** sub_594C12 (00594c12)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| obj | 0x0 | RW | — | cursor pointer (next allocation position within slab) |
| obj | 0x1 | RW | — | byte header of current block (size byte, 0 = free) |
| this | 0x0 | RW | — | cursor pointer (next allocation position within slab) |
| this | 0x4 | RW | 0 | remaining free bytes at current cursor position |
| this | 0x8 | RW | — | start of slab data area (where block headers begin) |
| this | 0x9 | R | — | first byte-size header in data area (indicates first block size) |

**Written-by note (persistence):**

**Guard conditions:** Three failure cases return 0: (1) remaining space at cursor (`v4 = *(a1+4)`) < `a3` → falls through to scan; (2) scan of data area from start fails to find contiguous free gap ≥ a3 → return 0; (3) remaining capacity `a2` exhausted during scan (`a2 < a3`) → return 0.
