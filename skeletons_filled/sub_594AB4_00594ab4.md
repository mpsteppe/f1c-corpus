## sub_594AB4_00594ab4 — TrimAllocatorFreePages

**Summary:** Walks the allocator context linked list and decommits free pages (state 240) via VirtualFree, up to a given page limit. Updates live page counter and lowest-free pointer. If all 1024 pages in a context become free, destroys the entire context via sub_594A5E.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** CounterThreshold (00594bcd)

| 005e796c | off_5E796C | R | MemMgr_HeapFreeListHead [DERIVED] — head of allocator context linked list |
| 008d41b8 | dword_8D41B8 | W | LivePageCounter [DERIVED] — decremented for each freed page |

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 00594a5e | sub_594A5E | destroy entire allocator context when all pages freed |

**Guard conditions:** Per-context guard: if `v1[4] == -1` (no valid arena base) → skip context. Per-page guard: if `*v2 != 240` (not free) or `VirtualFree` fails → skip page. Limit guard: outer loop breaks when `a1 <= 0` (page limit reached). After scan: if pages freed AND all 1024 page entries are -1 → destroy context.
