**Guard conditions (deterministic — field vs literal):**

| Base | Offset | Test | Value | Field / meaning |
|------|--------|------|-------|-----------------|
| this | 0x13D4 | == | 0 | depth/stencil format D16 available; if 0 → select format 2 (D16), else format 1 (D24S8) |
| this | 0x13E0 | == | 2 | depth/stencil mode; if 2 (D24S8 mode active) → override format to 1 |

**Guard interpretation:** Two depth/stencil format selection guards. First (0x13D4 == 0): checks whether D16 depth format is available; if not, selects D24S8. Second (0x13E0 == 2): if D24S8 mode was previously set, forces depth format to 1 regardless of the first check. Also, the multisample selection logic at the top probes D3D for 23/24/25 multisample quality levels, choosing the highest supported MSAA level. The display mode branch (v51 == 16 / 24 / 32) selects color depth: 16-bit → checks 0x1000000/0x4000000/0x2000000 caps bits for 23/24/25 formats; 24/32-bit → checks 0x8000000/0x20000000/0x10000000 for 20/22/21 formats. Presentation interval flags (a7 & 0x100560) select swap effect and present interval (IMMEDIATE=0x20, DEFAULT=0x100, ONE=0x40, TWO=0x400, etc.).
