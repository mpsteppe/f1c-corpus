## sub_58A973_0058a973 — OS-version-conditional aligned memory allocator

**Summary:** Internal CRT memory allocator dispatching between pool allocator and HeapAlloc based on OS version code (2=Win2K pool path, 3=WinXP sub-allocation path, else HeapAlloc). Rounds allocation size up to 16-byte alignment.

**Guard conditions:** Checks dword_8D4908 (OSVersionCode) == 3 for WinXP path: enters if a1 <= HeapMaxAllocSize, allocates via pool sub-allocator; falls through to HeapAlloc on oversized or failure.
