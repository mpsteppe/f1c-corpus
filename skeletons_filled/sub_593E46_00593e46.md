## sub_593E46_00593e46 — SlabHeapFreeCoalesceBlock

**Summary:** Coalesces and frees a block in a custom slab buddy allocator. Merges adjacent free blocks, updates two-level free block bitmap (64 size classes), updates free-list pointers. Deallocates entire slab via VirtualFree/HeapFree when slab becomes empty. Updates allocator metadata globals.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** sub_58AA6F (0058aa6f), sub_58B5D4 (0058b5d4)

| this | 0x4 | RW | — | upper bitmap flags (size classes 32-63) for slab allocator |
| this | 0xC | R | — | slab base address (used to compute slab index from pointer) |
| this | 0x10 | R | — | pointer to bitmap + free-list descriptor array for this slab |
