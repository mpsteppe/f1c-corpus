**Guard interpretation:** *(this+0x6E4) null → skips all save logic entirely (BLOCKED: no file handle open). this+0x700 == 1 → main replay save path: loops 104 physics steps, pops queue, conditionally writes if session != 4 AND time delta > 0 AND a2 flag set (PASSES: active replay recording). this+0x700 != 1 but this+0x6D0 non-zero → secondary file write path: clears flag, writes with different file path and mode 4 (PASSES: one-shot file dump). Neither condition → only closes file handle (BLOCKED: fallback, no save action). After any path, this+0x700 always reset to 0.
