## sub_5919DA_005919da — FpuExceptionHandlerByControlWord

**Summary:** Checks FPU exception code bits (a1, lower 5 bits) against FPU control word mask bits (a3). For each masked exception (divide-by-zero, denormal, underflow, overflow, inexact), applies the appropriate result value based on rounding mode and clears the bit. Returns TRUE when all exception bits are consumed/handled.

**Guard conditions:** Each of the 5 exception bits is independently guarded by the FPU control word mask: (a1 & 8) && (a3 & 1) → divide-by-zero; (a1 & 4) && (a3 & 4) → denormal; (a1 & 1) && (a3 & 8) → underflow; (a1 & 2) && (a3 & 0x10) → overflow; (a1 & 0x10) && (a3 & 0x20) → inexact.
