## sub_58E290_0058e290 — _write: file write with text-mode newline translation

**Summary:** CRT `_write` implementation that writes bytes to a file handle. In text mode, translates \n (0x0A) to \r\n (0x0D 0x0A) via 1024-byte chunks. Handles append-mode seeking, ERROR_ACCESS_DENIED mapping to EBADF, and returns ENOSPC (28) on empty write without error.

**Guard conditions:** If nNumberOfBytesToWrite == 0, returns 0. If text-mode append flag (bit 5 at handle tracking +4) is set, seeks to end of file first. In binary mode (bit 7 clear), writes directly via WriteFile. In text mode (bit 7 set), translates \n→\r\n in 1024-byte max chunks. On access-denied (error 5), sets errno=9 (EBADF). On other errors, maps via ErrorIDLookupTable. On zero bytes written with EOF+Ctrl-Z condition, returns 0. On zero bytes with no error, sets errno=28 (ENOSPC).
