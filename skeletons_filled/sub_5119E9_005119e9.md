**Guard interpretation:** Main parse loop matches chunk type tag at this+0x10C against known fourcc strings. On IDAT chunk: if IHDR bit (bit 0 of this+0x58) not set → fatal "Missing IHDR before IDAT". If IHDR seen but color type is 3 (indexed, this+0x116==3) and PLTE bit (bit 1) not set → fatal "Missing PLTE before IDAT". After IDAT processing, sets bit 2 (this+0x58 |= 4) to mark IDAT in progress.
