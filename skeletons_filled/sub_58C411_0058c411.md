## sub_58C411_0058c411 — File stream buffer deallocation on close

**Summary:** Frees the allocated buffer of a FILE stream if the stream owns it (flag 0x08 set). Clears buffer ownership flags and zeroes buffer pointers. Part of CRT stream close/teardown.

**Frame-path:** ON_FRAME_PATH  
**Call frequency:** per-frame tick

**Called by:** MSVCCRTFileClose (00587d33), sub_59BB00 (0059bb00)

**Struct fields accessed:**

| Base | Offset | R/W | Init (literal → value) | Purpose |
|------|--------|-----|------------------------|---------|
| this | 0x0 | RW | 0 | Buffer start pointer; zeroed after free |
| this | 0x4 | RW | 0 | Buffer length/count; zeroed after free |
| this | 0x8 | RW | 0 | Allocated buffer pointer; freed via sub_58AA6F then zeroed |
| this | 0xC | RW | — | Stream flags; buffer-ownership bits cleared after free |

**Written-by note (persistence):**
- this 0x0: recalc every frame — external poke does NOT persist
- this 0x4: recalc every frame — external poke does NOT persist
- this 0x8: recalc every frame — external poke does NOT persist
- this 0xC: recalc every frame — external poke does NOT persist

**Globals referenced:**

| Address | Name | R/W | Role |
|---------|------|-----|------|

**Functions called:**

| Address | Name | Purpose |
|---------|------|---------|
| 0058aa6f | sub_58AA6F | OS-version-dispatched memory free for the buffer allocation |

**Guard conditions:** Only frees the buffer if stream flags (this+0xC) have I/O bits (0x83) AND own-buffer bit (0x08) both set. Otherwise returns without action.
