**Guard conditions:** Checks segment direction length: if zero, returns first waypoint distance. Checks projected position against segment bounds: if projection < 0, interpolates with reverse ratio between two endpoint distances; if beyond segment end, returns last distance or interpolates forward. Session state flag adjusts distances for lap wraparound (flag 0: subtract SessionMaxTime for finished laps; flag 2: add SessionMaxTime for incomplete laps).
