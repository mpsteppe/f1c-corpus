**Guard interpretation:** Top-level branch on this+0x20 bit 0 vs bit 1 selects between two nearly identical mesh build paths (differ in index pattern layout). Bit 7 (sign of this+0x20) controls whether source index array is copied in full (gridWidth * gridHeight * 2) or truncated. The byte at this+0x21 bit 1 controls a variant in the index pattern (additional triangle pairs for mode A). On allocation failure, sub_53C590 logs error and returns -1.
