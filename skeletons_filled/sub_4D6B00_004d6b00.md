**Guard conditions:** No simple single-field guard. Function loops reading key-value pairs via ConditionalDispatchBasedOnFlag until EOF or error (token type 1 or 4). Inside loop, each recognized key string (Front, Rear, DryLatLong, etc.) triggers a corresponding parser. If "Front" matches, v3 = this+24 (front block); if "Rear" matches, v3 = this+352 (rear block). All subsequent numeric field parses write to v3-relative offsets. The loop body (v4==0 case) handles all tire parameter fields.
