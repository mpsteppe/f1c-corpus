# inputs/ — Immutable Ground-Truth Inputs (FACT)

Raw inputs captured from the game/binary. Not regenerated by the pipeline; these
are source material other data is derived from.

| Dir | Content |
|-----|---------|
| `memory_dumps/` | `driver0/1/2.bin` + `driver0.CEM` — F1CUI runtime struct memory dumps. Parse with `tools/parse_struct_dump.py`. |
| `raw_strings/` | `strings_raw.txt` — flat string dump from the exe (contains the "Entered Class::Method()" trace strings used for identity recovery). |

FACT tier. Trust these over derived interpretations.
