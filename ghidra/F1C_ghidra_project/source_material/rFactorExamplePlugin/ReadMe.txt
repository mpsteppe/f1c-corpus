Quick Start:

Copy the example plugin in \ExamplePlugin\VC7\Release\ExamplePlugin.dll 
into the simulation's \rFactor\Plugins directory.
Run rF Config.exe and make sure you choose a resolution that is less than
your current desktop resolution and ensure the check box for windowed
mode is checked. Then start rFactor and enter a race. Once the track has
loaded click on the drive button. You will see the console this example
plugin uses come alive. There will also be a test file in the root directory
of the simulation that has captured telemetry data. If you see this file called
ExampleInternalsOuput.txt then you have successfully installed the
example plug in.

See \Docs\rFactorInternalsPlugin.pdf for more detailed information.
