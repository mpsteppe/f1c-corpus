## Overview

HTree Terrain File Format Loader (FUN_0044be70) reads a compiled terrain height/vertex file with header "Ver 0.06 This file is automatically generated". Parses 46-byte header, reads vertex/face/edge counts, allocates arrays with stride 0x5c (vertex), 0x10 (face), 0x10 (edge), and processes faces via FUN_0044a700 (Collision Tree Node Deserializer). File I/O uses thread-safe wrappers with critical section locking.

## Step-by-Step Trace

### Level 0: FUN_0044be70 — HTree Terrain File Format Loader

**Trigger:** Terrain/scene loading — called during track load
**Called by:** Not in callers.json (likely called from track/scene loader)
**Purpose:** Read compiled terrain binary file, construct collision geometry

**Key actions:**
1. Open file via FUN_005668b0, check via FUN_00566b20
2. Read 46-byte ASCII header: verify "Ver 0.06" version string at offset 0
3. Read 4 string fields A/B/C/D (8 chars each at param_1+2, param_1+4, param_1+6, param_1+8)
4. Read vertex count (stride 0x5c), face count (stride 0x10), edge count (stride 0x10)
5. Allocate arrays via operator_new for each
6. If face_count > 0: call FUN_0044a700 (Collision Tree Node Deserializer) for face processing
7. Free resources, close file

**Format:**
- 46-byte header (version string)
- 8+8+8+8 chars: 4 field names
- 4 bytes: vertex count
- 4 bytes: face count
- 4 bytes: edge count
- Vertex data (stride 0x5c), face data (stride 0x10), edge data (stride 0x10)
