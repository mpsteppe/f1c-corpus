## MAJOR DISCOVERY: Original Source Tree Structure

F1 2002 Demo uses `D:\Dev\Common\Source\` paths. F1C uses `D:\dev\F1_1999_2002\Source\`.
This reveals the ISI development structure:

```
D:\Dev\
  Common\Source\              -- 25 SHARED isiMotor1 engine files
    ai_db.cpp
    camera.cpp
    dynman.cpp
    game.cpp
    garage.cpp
    hdvehicle.cpp
    htree.cpp
    hwinput.cpp
    NetComm.cpp
    osman.cpp
    pitcrew.cpp
    render.cpp
    searchgrid.cpp
    setup.cpp
    sound.cpp
    specialfx.cpp
    tire_manager.cpp
    util.cpp
    vehgfx.cpp
    vehload.cpp
    vidman.cpp
    weather.cpp
    O_BaseGz.cpp
    Replay.cpp
    config.cpp (F1C only - not in demo)

  F1_2002\Source\              -- 4 GAME-SPECIFIC files
    onscreen.cpp
    options.cpp
    plrfile.cpp
    steward.cpp

  F1_1999_2002\Source\         -- F1C forked all files here (both common + specific)

  AudioDev\Shared\Engine\Dev\  -- Shared audio/video library
    LbMpeg.cpp

  CONFIG\Debug\                -- 3DConfig tool source (DEBUG BUILD!)
    3DConfig.pdb               -- PDB exists! (may or may not ship with demo)
```

### Implications

1. **25 files are shared engine code** (Common\Source) used across ALL isiMotor1 titles.
   These same files exist in Sports Car GT, F1 2001, NASCAR Thunder, etc.

2. **Only 4 files are game-specific** (F1_2002\Source). The steward, onscreen display,
   options, and player file are the only things that change per game title.

3. **F1C forked everything** into a single directory (`F1_1999_2002\Source`), merging
   common + specific. This is a typical end-of-life codebase consolidation.

4. **config.cpp appears only in F1C**, not in F1 2002 Demo — new file added for the
   multi-season "Challenge" feature.
